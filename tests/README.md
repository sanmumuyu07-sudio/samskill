# 测试说明

## 机械发布校验

```bash
python3 scripts/validate_public_release.py
```

安装、冲突备份、重复安装与可恢复卸载回归：

```bash
python3 -m unittest tests/test_release.py -v
```

它检查：

- 18 个 Skill 是否齐全。
- frontmatter、目录名和 JSON 是否有效。
- 输入卡、用户模板、默认提示与 eval 是否存在。
- 用户输出是否混入机器状态。
- 是否存在个人绝对路径与 `.DS_Store`。
- 触发测试是否至少包含 10 条正例和 10 条反例。
- 安装器是否拒绝静默覆盖，并能备份冲突目录。
- 卸载器是否识别安装后修改，避免误丢用户更改。
