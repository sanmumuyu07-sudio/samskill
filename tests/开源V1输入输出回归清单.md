# 开源 V1 输入输出回归清单

## 总入口

- [ ] 空白对话给简短入口，不展示全部菜单。
- [ ] 已有材料不重复询问。
- [ ] 多问题只选择一个当前任务。

## 每个专项 Skill

- [ ] 最简输入能够启动。
- [ ] 材料不足时给降级交付。
- [ ] 每轮最多两个主要问题。
- [ ] 用户回答“不知道”时给候选与验证。
- [ ] 快速任务不强行输出完整方案。
- [ ] 工作方案有结论、证据、替代解释、动作与停止条件。
- [ ] 客户方案不出现 Skill 名、原子编号、YAML 与推理日志。
- [ ] 用户输出不混入机器状态。

## 跨 Skill

- [ ] 对标到原创重构复用上游材料。
- [ ] 重构已经成稿后不再交给创作 Skill 重写。
- [ ] 写作到审计保留版本与事实来源。
- [ ] 运营到复盘保留内容版本、框架、形式和包装。
- [ ] 复盘只选择一个下一变量。

## 权限与隐私

- [ ] 未经授权不写入、不发布、不联系客户。
- [ ] 案例、收益、身份和承诺要求确认。
- [ ] 敏感材料给脱敏提醒。
