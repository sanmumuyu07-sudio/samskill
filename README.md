# Samskill

> 从项目判断、人群定位到内容生产、获客承接与数据复盘的一人媒体 Agent Skill 系统。

[![Release](https://img.shields.io/github/v/release/sanmumuyu07-sudio/samskill?include_prereleases&label=release)](https://github.com/sanmumuyu07-sudio/samskill/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-6f42c1.svg)](LICENSE)
[![Status: Public Beta](https://img.shields.io/badge/status-public%20beta-f59e0b.svg)](#开源状态)

Samskill 面向正在做个人 IP、一人媒体、自然流短视频、内容获客、知识产品或专业服务的人。

它不是一个只负责“写文案”的提示词合集。

它会先判断你当前真正卡在哪个环节，再调用对应的专项 Skill，给出结论、依据、行动方案、验收标准和下一步。

**当前版本：[`v1.0.0-beta.3`](https://github.com/sanmumuyu07-sudio/samskill/releases/tag/v1.0.0-beta.3)**

[三分钟开始](docs/01_三分钟开始.md) · [安装说明](docs/02_安装升级与卸载.md) · [任务地图](docs/05_任务与Skill对照.md) · [交付示例](examples) · [提交反馈](https://github.com/sanmumuyu07-sudio/samskill/issues)

Samskill 由 [Samstudio](#关于-samstudio) 发起并持续维护。

## Samskill 是什么

一个真实的自媒体项目，很少只缺一篇文案。

内容没流量，可能是选题问题，也可能是人群太泛、作者没有进入权、账号定位混乱，或者内容与产品根本没有连接。

有流量没成交，也未必应该继续改开头。问题可能出在产品、承接、销售、交付或用户预期。

Samskill 把这些问题放进同一条工作链：

```text
项目诊断
→ 市场与产品
→ 人群与定位
→ 对标与研究
→ 内容战略与选题
→ 写作、修改与审计
→ 拍摄、发布与运营
→ 线索、成交与交付
→ 数据复盘与数字资产
```

这不是要求每个用户机械地跑完十八步。

总入口只识别你现在最该解决的一项任务；专项 Skill 负责把这一项做深，再把有效结果交给下一环节。

## 它适合谁

- 已有专业能力、产品或服务，想通过内容建立稳定获客入口的人。
- 正在从零搭建个人 IP、一人媒体或自然流短视频账号的人。
- 负责账号定位、选题、文案、运营或商业承接的操盘手。
- 已经能获得播放或咨询，但不知道问题出在流量、产品还是转化的人。
- 想把个人经验、内容素材和项目反馈沉淀成长期数字资产的人。

它不适合：

- 只想输入一句话，就得到无需核对、必然爆款内容的人。
- 希望复制他人标志性表达，或规避版权与平台检查的人。
- 不愿提供任何真实项目信息，却要求系统替自己确认事实和承诺的人。

## 你可以用它完成什么

Samskill 包含一个总入口和 17 个专项 Skill。

### 1. 先判断项目，而不是急着写内容

| 你正在解决的问题 | 使用 | 主要得到什么 |
|---|---|---|
| 不知道先做什么，多个问题混在一起 | `$samskill` | 当前任务识别、路由与开始方式 |
| 判断项目阶段和真正卡点 | `$sam-project-diagnosis` | 阶段结论、主问题、优先级与行动方案 |
| 判断市场、需求和交易条件 | `$sam-business` | 市场判断、有效需求、竞争替代与验证动作 |
| 设计产品、价格、交付和变现 | `$sam-product` | 产品结构、承诺边界、价格逻辑与最小验证 |

### 2. 搞清楚为谁做、凭什么是你

| 你正在解决的问题 | 使用 | 主要得到什么 |
|---|---|---|
| 深描用户并建立定位 | `$sam-position` | 人群图谱、现实处境、决策机制与定位方案 |
| 拆解账号、内容或商业案例 | `$sam-benchmark` | 成立机制、适用条件、不可照搬部分与迁移方案 |
| 研究陌生问题并核验事实 | `$sam-research` | 证据分层、关键事实、争议、反例与研究简报 |

### 3. 建立可以持续运行的内容系统

| 你正在解决的问题 | 使用 | 主要得到什么 |
|---|---|---|
| 规划长期命题、栏目和内容组合 | `$sam-strategy` | 阶段目标、长期命题、栏目职责与更新节奏 |
| 判断一个具体选题值不值得做 | `$sam-topic` | 选题结论、用户处境、核心判断与内容任务 |
| 提炼作者自己的表达方式 | `$sam-style` | 语言选择、句法节奏、案例习惯与禁用规则 |
| 写短视频、图文、长文或产品说明 | `$sam-write` | 框架选择、完整初稿、标题与发布配套 |
| 修改已有完整稿件 | `$sam-edit` | 问题诊断、修改稿、关键改动与保留边界 |
| 发布前做最终检查 | `$sam-audit` | 事实、逻辑、传播、版权、平台与商业风险清单 |

### 4. 合理参考，而不是机械换词

| 你正在解决的问题 | 使用 | 主要得到什么 |
|---|---|---|
| 保留参考稿有效机制进行改写 | `$sam-reconstruct` 参考型改写 | 参考判断、迁移边界、方向确认、大纲与新稿 |
| 借材料形成新的问题和独立论证 | `$sam-reconstruct` 独立原创重构 | 新选题、独立主张、论证结构、新稿与重合审计 |

Samskill 不把所有“洗稿”请求强制改成同一种方式。

它会先确认目标人群、作者身份、真实案例和产品承接，再决定哪些机制可以参考、哪些表达不能复制。

### 5. 让内容连接现实结果

| 你正在解决的问题 | 使用 | 主要得到什么 |
|---|---|---|
| 安排拍摄、剪辑、包装和发布 | `$sam-operations` | 发布包、制作标准、分工、库存和异常回退 |
| 检查咨询、成交、交付和复购链路 | `$sam-relationship` | 漏斗诊断、断点、证据与承接实验 |
| 复盘平台数据与业务结果 | `$sam-retro` | 事实层、解释层、下一轮实验与停止条件 |
| 建立 AI 协作、知识库和数字资产 | `$sam-assets` | 项目 Brief、权限、真源、资产目录和交接规则 |

完整字段请查看 [18 个 Skill 详细输出框架](docs/08_18个Skill详细输出框架.md)。

## 三分钟开始

### 第一次使用

不知道该选哪个 Skill，直接复制：

> 使用 `$samskill` 帮我判断下一步。我正在做【项目】，最近发生【结果】，现在最卡【问题】，已有材料是【】。

新项目可以复制：

> 使用 `$sam-project-diagnosis` 诊断这个项目。我是【本人／负责人／运营】，未来 30—90 天希望【】，已有【能力／产品／账号／结果】，最近一次动作和结果是【】。

已有明确任务，也可以直接说自然语言：

- 帮我全景拆解这个账号，并判断哪些机制适合迁移到我的项目。
- 根据这份用户材料，完成人群研究和定位方案。
- 判断这个选题值不值得做，不要直接写稿。
- 修改这篇口播稿，保留我的核心判断，但降低理解成本和 AI 味。
- 复盘这二十条视频，区分事实、解释和下一轮实验。

更多提示词见 [三分钟开始](docs/01_三分钟开始.md) 与 [脱敏交付示例](examples)。

### 不需要先填完一张大表

材料不足时，Samskill 应该：

1. 先使用当前对话和已有材料。
2. 明确现在能判断什么、不能判断什么。
3. 最多追问两个会改变结论的问题。
4. 给出候选答案、补证办法或降级方案。

每个专项 Skill 的 `assets/input-card.md` 都写明最低输入、增益材料和缺失材料时的处理方式。

## 安装

### Codex

推荐先安装固定版本，方便复现测试结果：

```bash
git clone --depth 1 --branch v1.0.0-beta.3 https://github.com/sanmumuyu07-sudio/samskill.git
cd samskill
python3 scripts/install.py --target ~/.codex/skills --dry-run
python3 scripts/install.py --target ~/.codex/skills
python3 scripts/verify_install.py --target ~/.codex/skills
```

安装后重启或重新加载 Codex。

### Claude Code

```bash
git clone --depth 1 --branch v1.0.0-beta.3 https://github.com/sanmumuyu07-sudio/samskill.git
cd samskill
python3 scripts/install.py --target ~/.claude/skills --dry-run
python3 scripts/install.py --target ~/.claude/skills
python3 scripts/verify_install.py --target ~/.claude/skills
```

### 通用 Agents 或项目级安装

```bash
# 用户级通用目录
python3 scripts/install.py --target ~/.agents/skills --dry-run
python3 scripts/install.py --target ~/.agents/skills

# 或安装到当前项目
python3 scripts/install.py --target /你的项目路径/.agents/skills
```

安装器不会静默覆盖同名 Skill。

只有显式使用 `--force`，旧目录才会先备份、再替换。完整的升级、冲突处理和可恢复卸载方式见 [安装、升级与卸载](docs/02_安装升级与卸载.md)。

## 你最终会得到什么

Samskill 根据任务复杂度提供三种交付密度：

- **快速判断**：一屏左右，适合先明确方向。
- **工作方案**：默认档，包含结论、依据、行动、验收与待确认边界。
- **专业全景**：用于重要项目、团队方案或内部审计，展开完整研究和判断过程。

普通用户结果不会默认展示 YAML、机器状态或内部交接字段。

系统不会只给模糊建议。

只要输入允许，它应当明确：现在的判断是什么、为什么、先做什么、做到什么算完成、什么情况需要回退。

## Samskill 和普通写作工具有什么区别

- **先诊断，再执行**：不把所有问题都误判为文案问题。
- **每项任务可以独立进入**：不必跑完整流程，也不必先学会 18 个名字。
- **分析与交付分层**：后台可以完整，用户只看到当前决策需要的信息。
- **证据与判断分开**：事实、解释、假设和行动不会混成一句“底层逻辑”。
- **内容连接商业承接**：播放不是终点，还会检查咨询、成交、交付和复购。
- **结果回填数字资产**：有效判断、内容、案例和负反馈可以进入下一轮，而不是每次从零开始。
- **不依赖私有外部 Skill**：公开包可以独立运行，不要求用户额外安装旧工具链。

## 开源状态

Samskill 当前处于 **Public Beta**，可以安装和试用，但还不是经过大规模陌生用户验证的稳定版。

### 已经完成

- 一个总入口和 17 个专项 Skill，共 18 个独立 Skill 包。
- 每个 Skill 均包含最低输入、增益材料、降级规则和用户输出模板。
- 根级发布校验、18 个独立包校验、路径与隐私泄漏扫描。
- 正反触发测试、输出质量断言和安装／升级／卸载回归测试。
- 同名目录冲突保护、升级前备份、安装记录和可恢复卸载。
- MIT 许可证、贡献指南、安全说明、Issue 模板和 CI 校验。

### 正在验证

- 陌生用户是否能在不了解系统结构的情况下完成首次安装。
- 最低输入卡是否足够容易填写，又能支持可靠判断。
- 18 个 Skill 在不同项目中的路由、交接和输出稳定性。
- 三个真实项目从诊断到复盘的完整前向结果。
- 哪些判断可以跨赛道复用，哪些必须根据平台、行业和产品重新校准。

### 当前不宣称

- 不宣称“已经被市场验证的正式稳定版”。
- 不保证流量、成交、收入或平台审核结果。
- 不替用户确认身份、案例、数据、资质和产品承诺的真实性。
- 不把单条爆款、单次成交或单一相关性当作稳定规律。
- 不用通用模型知识替代当期平台规则、法律意见或专业判断。

自动测试通过，只代表结构、路径、安装行为和当前规则符合发布门禁，不等于真实业务效果已经得到证明。

更完整的证据与限制见 [开源发布审核](OPEN_SOURCE_AUDIT.md)、[发布门禁](RELEASE_CHECKLIST.md) 和 [原子库与标准完整度审计](docs/09_原子库与标准完整度审计.md)。

## 公开包包含什么

公开仓库包含从叁木方法论和原子库编译出的运行子集：任务规则、输入卡、输出合同、参考资料、测试集和安装工具。

它不是完整私人原子库、客户资料或项目档案的镜像。

这不会导致公开包必须依赖私有资料才能启动；公开版的运行资料已经随各 Skill 自包含。后续会根据真实测试，持续补充脱敏案例、失败样本和跨场景校准规则。

## 隐私、安全与版权

- 提交聊天记录、后台截图、合同、付款、客户或未成年人资料前，先脱敏。
- 不要把客户原文、个人联系方式或未授权材料粘贴到公开 Issue。
- `sam-reconstruct` 不执行逐句同义替换、标志性表达复制或规避版权检测。
- 医疗、金融、法律、税务等高风险内容，需要核对当期权威来源和专业人士意见。

详见 [隐私、安全与权限](docs/04_隐私安全与权限.md) 与 [安全说明](SECURITY.md)。

## 关于 Samstudio

Samstudio 是由叁木发起的一人媒体与 AI 内容协作实验室。

我们研究的不是怎样让 AI 批量生成更多内容，而是怎样把市场判断、人群理解、内容表达、自然流运营、商业承接和项目复盘，变成个人与小团队能够实际运行、持续校准和长期积累的系统。

Samskill 是 Samstudio 的第一个开源项目。

在 GitHub，我们开放可以安装、检查和共同改进的 Skill、文档与测试；在叁木的内容账号，我们继续讲清这些方法为什么成立、在真实项目里怎样使用，以及哪些判断在测试后需要被推翻。

如果你想了解 Samskill 背后的方法论、真实测试和后续更新，可以在抖音搜索 **「叁木」**。
