# 三分钟开始

## 不知道先做什么

复制：

> 使用 `$samskill` 帮我判断下一步。我正在做【项目】，最近发生【结果】，现在最卡【问题】，已有材料是【】。

总入口只选择一个当前任务，并立即继续。

## 从零启动

复制：

> 使用 `$sam-project-diagnosis` 诊断这个项目。我是【本人／负责人／运营】，未来 30—90 天希望【】，已有【能力／产品／账号／结果】，最近一次动作和结果是【】。

## 已有具体任务

直接说自然语言也可以：

- 帮我判断这个市场。
- 深描这类用户。
- 全景拆解这个账号。
- 判断这个选题。
- 写一篇完整稿。
- 修改这篇文案。
- 审计最终版本。
- 复盘这批数据。

如果想提供更完整的材料，打开对应 Skill 的 `assets/input-card.md`。

## 材料不足

不需要先填完整表。

系统应当：

1. 先利用已有材料。
2. 说明当前能判断什么。
3. 最多问两个会改变结论的问题。
4. 给候选答案和验证办法。

## 你会看到什么

- 快速判断：一屏左右。
- 工作方案：可以执行和验收。
- 专业全景：完整研究、客户方案或内部审计。

普通回复不会默认显示 YAML 和内部路由。
