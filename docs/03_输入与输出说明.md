# 输入与输出说明

## 最简输入

```text
我正在做：
我现在卡在：
我希望得到：
已有材料：有／没有；如有请附上。
```

## 推荐输入

```text
当前项目：
本轮任务：
希望影响的人或现实结果：
已有事实、案例或数据：
不能改变的条件：
结果给谁使用：本人／团队／客户／项目档案。
```

## 信息状态

系统会区分：

- 已确认：可以直接用于结论。
- 暂定：当前较可能，但需要验证。
- 有歧义：存在多个解释，会改变方案。
- 相互冲突：口述、文件或数据不一致。
- 未知：当前没有足够信息，但不一定阻断任务。

## 用户说“不知道”

系统不应只说“请补充”。

它应该给候选答案、各自影响、暂定推荐和最小验证动作。

## 输出深度

### 快速判断

结论、理由、保留、先改、下一动作和关键未知。

### 工作方案

结论、证据、替代解释、专项交付、负责人、产出、完成与停止信号。

### 专业全景

增加取样、口径、证据账本、多方案、反例、不可推出项和风险附录。

## 机器状态

普通用户结果不会默认显示 `state_delta` 和 `handoff`。

只有保存、跨 Skill、团队交接和版本审计时生成。
