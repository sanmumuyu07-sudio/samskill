# 安装、升级与卸载

## 支持方式

Samskill 使用标准 Agent Skill 目录结构。

只要客户端能够发现包含 `SKILL.md` 的 Skill 目录，就可以尝试使用。

不同客户端的发现路径和刷新方式可能不同。

## 安装

### 推荐：使用安装器

先预览所有动作：

```bash
python3 scripts/install.py --target ~/.codex/skills --dry-run
```

确认没有冲突后安装：

```bash
python3 scripts/install.py --target ~/.codex/skills
```

安装完成后校验：

```bash
python3 scripts/verify_install.py --target ~/.codex/skills
```

如果目标目录存在同名 Skill，安装器会停止，不会直接覆盖。

确认需要升级时才使用：

```bash
python3 scripts/install.py --target ~/.codex/skills --force
```

旧目录会先移动到 `.samskill-backups/时间戳/`。

安装记录会写入 `.samskill-installations/`。

### 手动安装

### Codex 用户目录

把 `skills/` 下的 18 个目录复制到：

```text
~/.codex/skills/
```

### 通用 Agents 目录

支持通用目录的客户端，可以复制到：

```text
~/.agents/skills/
```

### 项目级安装

需要项目隔离时，复制到项目自己的：

```text
.agents/skills/
```

项目级 Skill 可能覆盖同名用户级 Skill。

安装前确认你信任该目录中的脚本与资料。

## 安装后检查

1. 重启或重新加载 Agent。
2. 确认能看到 `samskill` 和 17 个 `sam-*` Skill。
3. 输入：

> 使用 `$samskill` 帮我判断下一步。

4. 如果没有触发，检查目录名、`SKILL.md` frontmatter 和客户端发现路径。

## 升级

1. 备份当前版本。
2. 不要把新版本直接覆盖到仍在修改的自定义副本。
3. 比较 `CHANGELOG.md`。
4. 使用安装器的 `--force`，或手动替换同名 Skill 目录。
5. 重新运行发布校验并重启客户端。

用户自己的项目资料、案例和状态不应存放在 Skill 安装目录内。

## 卸载

推荐先预览：

```bash
python3 scripts/uninstall.py --target ~/.codex/skills
```

确认后执行：

```bash
python3 scripts/uninstall.py --target ~/.codex/skills --apply
```

卸载器不会直接删除，而是把本次安装的 Skill 移动到 `.samskill-trash/时间戳/`。

如果安装后修改过 Skill，卸载器会停止，避免误丢修改。

手动卸载时，只处理安装目录中的：

- `samskill/`。
- 所有 `sam-*/`。

卸载 Skill 不应删除用户项目资料。

处理前先确认路径，避免误删整个 Skills 目录。
