# 常见问题

## 我需要记住 18 个 Skill 名吗？

不需要。

使用 `$samskill` 或直接说当前任务。

## 我没有数据，可以开始吗？

可以。

但结论会降级为暂定判断、关键未知和取证动作。

## Samskill 会自动把整条流程跑完吗？

不会预设固定长链。

每次只处理一个当前最必要任务，再根据真实结果判断下一步。

## 能预测一条内容会不会爆吗？

不能给确定预测。

可以检查内容成立性、传播机制、证据、平台条件和历史基线，并设计验证。

## “洗稿”会不会只做同义替换？

不会。

但它也不会把所有参考任务都强制改成另一篇从零原创。

系统会先判断：

- **参考型改写**：你认可原稿的问题、观点和逻辑，只需要把身份、案例、数据和表达换成当前作者真实拥有的版本。
- **独立原创重构**：你只是借参考内容研究问题，需要建立新命题、新论证和独立贡献。

自有或已获授权材料，可以在授权范围内高保真处理。

公开第三方内容可以参考问题、公共方法和功能结构，但不复制高识别度原句、独创名词、专属案例和可识别作者声音。

## 会自动发布或联系客户吗？

默认不会。

发布、联系、付款、签约和承诺需要明确授权。

## 能否直接用于客户正式方案？

可以选择专业全景或客户方案。

客户版不显示 Skill 名、原子编号、内部路由和 YAML。

## 为什么还叫 beta？

结构和测试集已经建立，但真实项目的长期触发率、输出盲测和跨赛道回归仍需积累。
