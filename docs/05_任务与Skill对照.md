# 任务与 Skill 对照

| 你现在要解决什么 | 使用 |
|---|---|
| 不知道项目阶段，多个问题混在一起 | `$sam-project-diagnosis` |
| 判断市场、行业、需求和商业条件 | `$sam-business` |
| 设计产品、价格、交付和变现 | `$sam-product` |
| 深描用户、人群图谱和定位 | `$sam-position` |
| 拆解账号、内容、产品或商业案例 | `$sam-benchmark` |
| 保留原稿开头、观点、重点和逻辑来改写 | `$sam-reconstruct` 的参考型改写 |
| 借参考材料建立新问题、新论证和原创新稿 | `$sam-reconstruct` 的独立原创重构 |
| 研究陌生问题、核验事实 | `$sam-research` |
| 规划长期内容、栏目和节奏 | `$sam-strategy` |
| 判断具体选题 | `$sam-topic` |
| 建立作者表达标准 | `$sam-style` |
| 写完整初稿 | `$sam-write` |
| 修改已有稿件 | `$sam-edit` |
| 判断最终稿能不能发布 | `$sam-audit` |
| 安排拍摄、剪辑、包装和发布 | `$sam-operations` |
| 检查线索、成交、交付和复购 | `$sam-relationship` |
| 复盘平台与业务数据 | `$sam-retro` |
| 建立 AI 协作和数字资产 | `$sam-assets` |

不知道选哪个，使用 `$samskill`。

一次只处理一个当前任务。
