# 隐私、安全与权限

## 提交材料前先脱敏

删除或替换：

- 姓名、电话、微信、邮箱和地址。
- 身份证、护照、学号、合同编号和付款凭证。
- 未成年人及监护人信息。
- 客户公司内部信息和商业秘密。
- API 密钥、Cookie、Token 和后台账号。

## 高风险材料

以下内容需要更严格处理：

- 医疗、法律、金融与税务。
- 收益、成交与成功案例。
- 未成年人、家庭关系和心理健康。
- 版权、商标、素材授权与引用。
- 对外产品承诺、退款和合同。

Samskill 只做辅助分析，不替代持证专业意见。

## 默认权限

未经明确授权，Samskill 不应：

- 写入用户项目。
- 覆盖旧结论。
- 发布内容。
- 投放广告。
- 联系客户。
- 收款、退款或签约。
- 替用户确认身份、案例真实性和结果承诺。

## 本地文件

本地 Markdown、JSON 和日志通常没有自动加密。

不要把敏感信息直接写进公开仓库或 Skill 安装目录。
