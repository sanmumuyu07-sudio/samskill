# 叁木选题与内容研究项目记录

## 原始材料

叁木选题池、内容生产核心、六种需求分类、爆款方法、咨询与搜索材料、四项目内容记录。

## 能支持什么

- 咨询、评论、搜索、项目失败和行业变化都能成为选题入口。
- 选题需要同时服务传播、账号承诺和业务结果，但单条内容不必承担全部任务。
- 选题池必须保留来源、假设、内容任务和发布结果。
- 同一问题可形成系列，而不是不断换题。

## 不能支持什么

- 固定三维分数或 40/30/20/10 配比适用于所有账号。
- “有用、有趣、有共鸣至少二项”是爆款充分条件。
- 冲突、情绪、用户原话必然带来流量。
- 搜索联想、爆款标题或高赞评论能单独证明真实需求。

## 进入叁木系统

保留选题来源、任务和前向回填；固定配比改成根据账号阶段和内容缺口形成的动态组合。
