# 受众会主动选择媒体以满足不同需要

## 原始来源

Elihu Katz、Jay G. Blumler 等，`Uses and Gratifications Research`，Public Opinion Quarterly，1973。

DOI：https://doi.org/10.1086/268109

## 能支持什么

- 受众并非完全被动接受信息。
- 接触、使用和分享媒体可能服务信息、关系、身份、娱乐等不同需要。
- 同一内容对不同用户的使用价值可能不同。

## 不能支持什么

- 每一次观看都能准确归入固定动机。
- 满足情绪就必然长期信任。
- 受众知道并会如实说出全部使用动机。

## 进入叁木系统

传播任务不只写“给用户价值”，还要明确用户为何停留、为何收藏、为何转发，以及这些动作各自满足什么任务。
