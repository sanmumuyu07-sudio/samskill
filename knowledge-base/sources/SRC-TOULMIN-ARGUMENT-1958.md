# 日常论证需要把主张与支撑主张的理由连接起来

## 原始来源

Stephen E. Toulmin，`The Uses of Argument`，1958；Cambridge University Press 更新版。

官方页面：https://www.cambridge.org/core/books/uses-of-argument/26CF801BC12004587B66778297D5567C

## 能支持什么

- 一个主张不能仅凭说话者态度成立，需要材料、推理连接、适用条件与可能例外。
- 不同领域的论证标准不同，不能用同一套证据要求处理所有话题。
- “我有案例”与“这个案例足以支持我的结论”不是同一件事。

## 不能支持什么

- 所有短视频必须完整展示一套学术论证模型。
- 结构完整等于内容必然传播。
- 只要引用权威，主张就自动成立。

## 进入叁木系统

把“观点”拆成主张、根据、连接、边界和反例。短内容可以压缩展示，但创作者在发布前必须补全自己的论证责任。
