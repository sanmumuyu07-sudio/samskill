# OpenAI Skills 官方文档

## 能支持什么

- Skill 是带 `SKILL.md` 清单的版本化文件包。
- Skill 可以保存重复流程和团队规范，并在本地或托管环境复用。
- Skill 负责可执行说明与配套文件，不自动提供业务真理。

## 不能支持什么

- 安装 Skill 就拥有成熟方法论。
- 一个 Skill 应覆盖所有业务问题。
- Skill 的输出不需要现实验证。

## 进入叁木系统

Skill 作为原子库、工具、案例和项目状态之间的编排层，不作为方法论真源。
