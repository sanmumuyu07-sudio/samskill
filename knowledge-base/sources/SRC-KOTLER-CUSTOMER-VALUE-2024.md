# 顾客价值由利益与成本共同决定

## 原始来源

- Philip Kotler、Kevin Lane Keller、Alexander Chernev，`Marketing Management`。
- Pearson 现行版本页面与《营销管理》精读摘要。

## 能支持什么

- 顾客判断的不只是产品功能，也包括心理、社会和货币价值。
- 顾客付出的不只是价格，还包括时间、精力、风险和替代机会。
- 价值主张需要同时说明目标市场、提供的价值和实际供给。

## 不能支持什么

- 价值可以由卖方单方面宣布。
- 只要增加资料数量就能增加价值。
- 高价一定提高用户重视程度。
- 所有产品都应按同一种价值权重设计。

## 进入叁木系统

把“值不值”拆成结果价值、使用成本、风险和替代方案，而不是只看资料数量与标价。
