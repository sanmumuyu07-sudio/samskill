# 从已发生事件中寻找重复动作与适配模式

## 来源

- 《商业模式新生代（个人篇）》第二版，生命线、工作模式画布与验证章节。
- 精读摘要 Skills：`lifeline-sweet-spot`、`work-model-canvas`、`work-model-validation`。

## 能支持什么

- 比起凭空回答“热爱什么”，回看真实高峰、低谷与重复动作更容易获得行为证据。
- 兴趣、能力和个性匹配需要分开。
- 工作模式假设需要外部验证，不能只靠自我描述。

## 不能支持什么

- 主观满意的事情一定有市场。
- 能力先于激情是一条无条件规律。
- 职业画布可以替代真实项目和交易验证。

## 进入叁木系统

生命线只负责发现候选动作模式。

候选能力必须继续经过结果归因、证据分级和最小市场验证。
