# 叁木定位与账号承诺项目记录

## 原始材料

- 三圈定位、人格底色与一句话定位历史课程。
- 叁木、德国留学、菌子、瓷砖等账号定位文件。
- 一人媒体、个人资产、用户任务和产品模块。
- 叁木语言风格、品牌定型与后续方法论迭代。

## 能支持什么

- 定位需要能力、用户任务、产品和内容长期一致。
- 同一账号可用大众入口解释更深方法，但两层不能互相欺骗。
- 定位会在发布、咨询、交易和交付反馈中修改。
- 账号简介、栏目、证据和行动入口共同形成承诺。

## 不能支持什么

- 三圈交集天然就是好定位。
- 搜索联想词等于真实需求。
- 固定人格类型能决定内容风格和商业结果。
- 发满三十条才能调整，或数据上涨就证明定位正确。

## 进入叁木系统

保留“先建立可验证起点，再用反馈修正”；删除固定数量、人格宿命与单一平台指标判断。
