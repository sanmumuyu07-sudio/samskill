# 用户在具体处境中选择产品以取得进展

## 原始来源

- Clayton M. Christensen 等，`Competing Against Luck`，2016。
- Christensen Institute，`Jobs to Be Done Theory`。
- https://www.christenseninstitute.org/theory/jobs-to-be-done/
- https://hbr.org/2016/09/know-your-customers-jobs-to-be-done

## 能支持什么

- 用户选择产品，是为了在特定处境中取得某种进展。
- 任务同时包含功能、社会和情绪维度。
- 人口属性和产品属性不足以解释用户为什么在此刻购买。
- 现有替代方案、使用阻力与转换焦虑都影响选择。

## 不能支持什么

- 只要问用户“你想要什么”就能得到任务。
- 每个人只有一个稳定任务。
- 情绪任务可以替代真实功能交付。
- 所有用户都会为同一进展付费。

## 进入叁木系统

把“目标人群需要课程”改成“谁在什么触发情境下，需要完成什么进展，为什么现有替代方案不够”。
