# 商业模式必须放进环境中判断

## 原始来源

- Alex Osterwalder, `Navigating Your Business Model Environment`, 2014。
- https://www.strategyzer.com/library/your-business-model-environment
- 官方工作坊卡组：https://assets.strategyzer.com/assets/resources/the-business-model-design-space-card-deck.pdf

## 能支持什么

商业模式不是在真空中设计。

至少要扫描：

- 市场力量。
- 行业力量。
- 关键趋势。
- 宏观经济力量。

观察必须回到商业模式组件，说明它影响谁、改变什么、产生什么假设。

## 不能支持什么

- 环境扫描越长，方案越准确。
- 研究宏观趋势可以替代用户访谈和交易测试。
- 一次扫描可以永久有效。

## 进入叁木系统

所有外部信息都必须写成“变化信号 → 受影响节点 → 风险或机会假设 → 最小验证动作”。
