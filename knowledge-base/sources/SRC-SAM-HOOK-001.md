# 叁木标题、封面与开头项目记录

## 原始材料

标题标准、AI 封面标题课程、叁木脚本样本、外部内容工具 与标题工具结构、四项目内容数据。

## 能支持什么

- 标题、封面和开头承担相关但不同的任务。
- 开头问题常来自选题和正文不完整，不只是句子不够刺激。
- 身份、处境、冲突、结果、证据和信息缺口可作为多种入口。
- 包装必须与正文、目标用户和最终行动一致。

## 不能支持什么

- 所有开头必须在固定三秒或五秒完成同一任务。
- 所有标题必须留悬念、不说答案。
- 话题越宽流量一定越高且商业越好。
- 六种触发至少命中两项才是好标题。
- 标题公式可以绕过内容质量和事实责任。

## 进入叁木系统

保留诊断优先、多版本和变量测试；删除固定秒数、万能公式与“越宽越好”。
