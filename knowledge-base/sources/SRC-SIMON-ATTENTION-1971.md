# 信息丰富环境中的注意力稀缺

原始来源：

- Herbert A. Simon, `Designing Organizations for an Information-Rich World`, 1971。
- 原文：https://gwern.net/doc/design/1971-simon.pdf

## 原文能够支持什么

- 信息增加会消耗接收者的注意力。
- 信息丰富不会自动带来理解丰富。
- 注意力配置本身是一项组织与选择问题。

## 进入叁木原子库的关系

发布工具降低了表达门槛。

但用户一天能够分配的时间、理解力和记忆仍然有限。

所以“人人能发”与“人人能被看见”不是同一个命题。

内容竞争的核心不只是产量。

它还包括相关性、理解成本、可信度和连续价值。

## 不能支持什么

- 所有高注意力内容都具有长期价值。
- 高刺激一定优于低刺激。
- 某个平台的推荐算法必然怎样工作。
- 只要减少信息量就能获得传播。

## 使用边界

该来源用于解释注意力稀缺。

不用于替代具体平台数据与用户研究。
