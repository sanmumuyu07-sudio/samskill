# APQC Benchmarking

网址：

https://www.apqc.org/What-Is-Benchmarking

支持：

- benchmarking 不只比较结果数字。
- 还要比较流程、实践和改进机会。

不能支持：

- 自然流短视频应使用哪一套固定指标。
- 叁木八项审查已经被 APQC 直接验证。
