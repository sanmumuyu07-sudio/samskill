# 叁木个人资产、项目起点与能力边界判断集合

## 已读取材料

- 叁木自我诊断方法。
- IP 调研表与适用人群分析。
- 四阶段职业与项目经历。
- 一人媒体的私人积累与公共证明。
- 项目失败、组织依赖和后端失控复盘。

## 可以支持

- 叁木在内容框架、自然流、矩阵生产、0—1 冷启动和 AI 工作流上有跨项目经验。
- 叁木曾多次负责前端内容，但不总是拥有产品、供应链和商业决策权。
- 经历经过归因以后，可以识别可迁移能力和边界。
- 新手没有成熟案例时，需要真实任务，而不是提前包装身份。

## 不能支持

- 所有项目结果均由叁木造成。
- 一次结果证明跨赛道普遍能力。
- 兴趣、审美和自我认同等于市场资产。
- 四段经历已经形成完成审计的商业方法论。

## 进入叁木系统

每项资产必须登记事实、贡献、条件、证明、可迁移关系、边界和下一次验证。
