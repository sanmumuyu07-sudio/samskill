# 个性化推荐是多信号、动态排序而不是固定流量池公式

## 已核官方来源

### 抖音

- 抖音隐私政策，个性化推荐与自动化决策部分。
- https://www.douyin.com/privacy/

官方页面确认：

- 推荐会使用搜索、点击、关注、收藏、浏览、下载、分享等行为信息。
- 系统会预测偏好并提供个性化内容。
- 推荐结果会根据使用过程中的反馈持续调整。
- 系统还会用多样化技术避免同类内容过度集中。

### TikTok

- TikTok Newsroom, `How TikTok recommends videos #ForYou`。
- https://newsroom.tiktok.com/how-tiktok-recommends-videos-for-you?lang=en

官方页面确认：

- 推荐由用户互动、视频信息、设备与账号设置等多类因素共同决定。
- 不同信号权重不同。
- 推荐会随用户反馈持续调整。
- 系统还需要处理重复、垃圾内容、安全与多样性问题。

### YouTube

- YouTube Help, `YouTube's Recommendation System`。
- https://support.google.com/youtube/answer/16533387?hl=en

官方页面确认：

- 推荐目标包含相关性与长期观看满意度。
- 个性化与内容表现共同影响排序。
- 观看、忽略、停留、搜索、互动与调查反馈都是可用信号。
- 平台建议创作者理解受众，而不是把算法想象成单一口令。

## 进入叁木原子库的关系

平台能看到的是内容特征和用户行为信号。

它不能直接读取创作者的真实动机，也不能替创作者判断商业价值。

因此，内容复盘必须分开：

1. 内容有没有被分发给相关用户。
2. 用户看到以后有没有选择继续。
3. 用户是否形成理解、记忆和信任。
4. 后端是否产生咨询、交易和交付结果。

## 明确排除的行业传言

没有官方依据时，不写入：

- 固定的 200—500 初始流量池。
- 全平台统一的完播率或互动率阈值。
- 永久不变的账号权重等级。
- 一条内容失败会给账号永久降权。
- 任意平台通用的“黄金三秒”硬规则。

## 使用边界

TikTok 与 YouTube 的规则只能支持推荐系统的一般机制。

不能直接外推为抖音、小红书或视频号的具体权重。

国内平台的具体字段、规则和商业规范仍需按平台、页面和日期单独核验。
