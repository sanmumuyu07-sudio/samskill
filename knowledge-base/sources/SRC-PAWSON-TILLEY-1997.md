# 情境、机制与结果

开放资料：

https://pmc.ncbi.nlm.nih.gov/articles/PMC4408605/

支持：

- 复杂结果需要解释情境、机制和结果的组合。
- 同一动作在不同条件下可能产生不同结果。

不能支持：

- 叁木七项机制卡是原理论的原始结构。
- 该方法能够自动完成商业因果证明。
