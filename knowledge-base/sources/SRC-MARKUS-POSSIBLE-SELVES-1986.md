# 可能自我连接当前自我与希望或害怕成为的人

## 原始来源

- Hazel Markus、Paula Nurius，`Possible Selves`，American Psychologist，1986。
- DOI：10.1037/0003-066X.41.9.954。
- https://web.stanford.edu/~hazelm/publications/1986_Markus%20%26%20Nurius_PossibleSelves.pdf

## 能支持什么

- 人会形成对未来可能成为、希望成为和害怕成为的自己的表征。
- 这些表征能为当前自我提供解释背景，并与动机有关。
- 身份相关内容可能同时唤起希望、恐惧和行动方向。

## 不能支持什么

- 想象未来身份就会自动行动。
- 身份许诺可以替代能力、路径与现实任务。
- 所有用户都渴望成为个人 IP 或创业者。

## 进入叁木系统

内容可以帮助用户看见一种可能，但必须把可能自我连接到现实任务、可行路径和证据，防止身份预支代替行动。
