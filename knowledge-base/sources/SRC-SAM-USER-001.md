# 叁木用户研究与认知行动断点记录

## 原始材料

- 用户思维核心方法、完整框架与短视频需求分类。
- 适用人群分析、社群反馈、咨询与项目材料。
- 关于信息过载、认知消费、身份预支、现实任务和知行断裂的连续讨论。
- 知识付费、实体、留学、地产项目中的咨询与成交断点。

## 能支持什么

- 同一人口标签下的用户，任务与阶段差异很大。
- 用户常用表面问题表达更深的功能、情绪和社会任务。
- 认同、收藏和学习可能不产生行动。
- 评论、搜索、咨询、付款与使用提供不同强度的证据。

## 不能支持什么

- 五年经验能替代系统用户研究。
- “高认知穷人”“悬浮人群”等标签是稳定事实分类。
- 每个用户都存在一个不自知的真正需求，等待操盘者揭示。
- 情绪比功能永远更重要。

## 进入叁木系统

保留场景追问、行为证据和多源互证；删除对用户的优越性许诺、单一心理归因和未经证据支持的隐性需求断言。
