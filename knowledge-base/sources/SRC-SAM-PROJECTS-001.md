# 叁木跨项目一手复盘集合

当前包含：

- 微博美食广告 IP。
- 知识付费矩阵。
- 糖水甜品实体 IP。
- 地产与留学自然流获客。

支持：

- 叁木在不同业务中实际参与内容、流量、线索和部分商业链路。
- 同一内容能力进入不同产品与承接系统，会产生不同结果。

不支持：

- 所有后端结果都由叁木前端内容造成。
- 四组项目能够证明全行业普遍有效。
- 未附后台材料的数据可以对外当作审计结果。
