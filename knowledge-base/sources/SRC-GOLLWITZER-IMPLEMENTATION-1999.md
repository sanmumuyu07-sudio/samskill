# 实施意图：用情境—动作连接意图与执行

## 能支持什么

- 只有目标意图时，人可能仍无法在合适时机开始。
- 把可识别情境与具体动作连接，可以帮助行动启动和持续。
- 计划必须具体到“当什么发生，我做什么”。

## 不能支持什么

- 一个 if-then 句式解决能力、资源、市场和情绪的所有问题。
- 写下计划就已经执行。
- 固定提醒适合所有任务。

## 进入叁木系统

最小动作必须绑定真实触发条件、完成证据和结果回填，不只写愿望。
