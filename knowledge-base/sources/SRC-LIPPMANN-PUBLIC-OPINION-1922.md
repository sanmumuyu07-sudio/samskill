# 人通过被选择和压缩的图景理解陌生世界

原始来源：

- Walter Lippmann, *Public Opinion*, 1922。
- 原文：https://www.gutenberg.org/cache/epub/6456/pg6456-images.html

## 原文能够支持什么

- 人不可能直接接触全部现实。
- 人会依据脑中的图景理解远处、复杂和不可见的世界。
- 媒体、符号、既有观念和有限经验共同参与这些图景的形成。
- 图景可以帮助行动，也可能与现实条件发生偏差。

## 进入叁木原子库的关系

陌生用户无法直接观察一个创作者全部的能力、动机和项目过程。

他只能通过标题、内容、案例、评论、产品和外部评价形成暂时判断。

因此，内容不是把完整的“我”搬到网上。

内容是在有限注意力里，帮助相关人群建立一幅足够准确、可以继续检查的认识。

这也是“公共证明”与“稳定预期”的认知基础。

## 不能支持什么

- 用户可以被任意操控。
- 只要重复一个标签就能建立真实信任。
- 情绪比事实更重要。
- 传播者可以为了认知压缩省略关键条件。

## 与叁木方法的对应

叁木不把“认知压缩”理解为一句口号或一个人设标签。

更完整的动作是：

```text
选择一个现实问题
→ 说明判断与条件
→ 提供可检查的证据
→ 允许用户继续验证
→ 用后续结果修正原来的表达
```

压缩降低理解成本。

证据和边界防止压缩变成误导。

## 使用边界

该来源用于解释公共认知为什么需要被组织。

不用于为夸张人设、操控情绪或制造虚假共识背书。
