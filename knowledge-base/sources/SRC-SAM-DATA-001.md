# 叁木内容数据与业务结果复盘记录

## 能支持什么

- 复盘要从平台行为数据连接到具体内容节点和下一次动作。
- 广告 IP、线索 IP、知识付费与实体业务不能用同一最终指标。
- 单条峰值容易掩盖稳定能力，中位表现、分布和跨期变化更适合判断系统。
- 数据假设必须回填到选题、脚本、传播、生产、销售或产品，不只做报表。

## 不能支持什么

- 旧看板中固定及格线、权重排序和因果映射。
- “指标低只可能有三种原因”等封闭归因。
- 发布时间、养号与平台流量池传言。

## 进入叁木系统

保留行为链、业务链和假设回填；清退无官方定义或无本项目基线的阈值，把旧诊断模式降级为待验证假设。
