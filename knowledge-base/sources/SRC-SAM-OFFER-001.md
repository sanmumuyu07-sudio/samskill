# 叁木产品体系与四项目变现边界

## 原始材料

- 微博美食广告 IP、知识付费矩阵、糖水实体培训与地产留学项目复盘。
- 叁木知识库、咨询、线下课、私教与代运营历史产品方案。
- 产品定价策略、变现路径图和最小盈利验证法。

## 能支持什么

- 广告、线索、高客单服务、培训和实体联营的价值链不同。
- 前端内容跑通不代表产品、销售和交付跑通。
- 产品边界不清会把低价标品拖成高强度服务。
- 交付能力与后端承接会限制收入和口碑上限。

## 不能支持什么

- 历史价格适用于当前市场或所有用户。
- 单个项目可以证明通用转化率。
- 叁木曾采用的产品阶梯已经完成市场验证。
- 有客资就一定有可持续商业模式。

## 进入叁木系统

历史数据用作边界案例，不用作定价公式。所有产品先明确结果、用户任务、交付、成本、证据和停止条件。
