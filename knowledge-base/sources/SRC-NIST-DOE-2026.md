# 实验需要先定义目标、因素、响应与不可控变量

## 官方来源

- 实验设计：https://itl.nist.gov/div898/handbook/pri/section1/pri11.htm
- 设计选择：https://www.itl.nist.gov/div898/handbook/pri/section3/pri33.htm
- 异常值：https://itl.nist.gov/div898/handbook/eda/section3/eda35h.htm

## 能支持什么

- 实验应预先定义目的、可控因素、响应指标与不可控变化。
- 设计取决于目标、因素数量、资源和错误决策成本。
- 异常值需要调查，不应自动删除，也不应自动代表规律。

## 不能支持什么

- 自然流内容能达到严格实验室控制。
- 每次只改一个变量就能证明因果。
- 小样本内容数据足以做显著性推断。

## 进入叁木系统

自然流实验以“有记录的比较”而非强因果证明为目标：预先登记假设、主要变化、响应指标、同时变化、观察周期与停止条件。
