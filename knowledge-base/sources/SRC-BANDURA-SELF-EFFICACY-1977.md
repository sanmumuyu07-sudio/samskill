# 自我效能与行动

## 能支持什么

- 对自己能否完成具体行为的判断，会影响选择、努力与坚持。
- 实际完成经验是重要信息来源；任务分级和反馈可以改变效能判断。
- 自我效能是任务相关的判断，不是笼统人格优劣。

## 不能支持什么

- 自信就等于能力或结果。
- 不行动一定是自我效能低。
- 鼓励和口号可以替代技能、资源与反馈。

## 进入叁木系统

用足够小、可完成、能被真实检查的任务积累证据，而不是向用户许诺“你本来就很强”。
