# 价值主张必须对应具体用户任务、痛点与收益

## 原始来源

- Strategyzer，`The Value Proposition Canvas`。
- https://www.strategyzer.com/library/the-value-proposition-canvas

## 能支持什么

- 客户侧应区分任务、痛点和期望收益。
- 产品侧应区分产品服务、减轻痛点的机制和创造收益的机制。
- 同一个画布只处理一个明确客户群，避免把付款者、使用者和受益者混在一起。
- 画布是设计假设，仍需用户证据与购买实验。

## 不能支持什么

- 填完画布就获得产品市场匹配。
- 所有痛点都必须被产品解决。
- 产品功能越多，价值主张越好。

## 进入叁木系统

产品定义必须同时写出谁、在什么场景、要完成什么任务、当前替代方案是什么、交付怎样改变结果。
