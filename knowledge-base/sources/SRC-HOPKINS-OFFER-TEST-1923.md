# 报价与销售主张应在放大前经过小规模测试

## 原始来源

- Claude C. Hopkins，`Scientific Advertising`，1923。
- 《科学的广告》原著精读摘要与实验记录。

## 能支持什么

- 广告与报价是销售过程的一部分，应接受结果检验。
- 在大规模投入前先做低成本可归因测试。
- 具体、可检查的承诺通常比空泛最高级更可验证。
- 降低首次尝试风险可以帮助用户行动。

## 不能支持什么

- 1923年的媒介规则可以直接当作当前平台算法。
- 退款保证适合所有服务。
- 一次广告测试足以验证完整交付与长期留存。

## 进入叁木系统

把产品验证拆成问题、兴趣、承诺、付款、使用、结果和复购多级证据，先验证最危险假设。
