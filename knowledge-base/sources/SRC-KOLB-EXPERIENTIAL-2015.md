# 从经验中学习

## 能支持什么

- 经历本身不是学习的终点。
- 具体经验需要经过观察、概念化和再次实验，才可能形成可迁移的判断。
- 新一轮行动会继续修正旧判断，学习因此是循环而不是一次总结。

## 不能支持什么

- 只要做过就一定学会。
- 所有学习都必须机械遵守同一种四步顺序。
- 一次复盘就能证明规律已经稳定。

## 进入叁木系统

把行动结果写回假设、规则和下一轮实验；经验若没有改变后续选择，只是经历，不是已经沉淀的资产。
