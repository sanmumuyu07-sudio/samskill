# 观点怎样变成完整论证

## 叁木判断

观点是你主张什么；论证是陌生人为什么有理由暂时接受这个主张。强态度不能替代中间这座桥。

## 五个必要部件

1. 主张：你具体认为哪段关系成立。
2. 根据：事实、数据、案例或可核材料。
3. 连接：这些材料为什么能推出主张。
4. 限定：在什么对象、时间和条件下成立。
5. 异议：最强反例是什么，结论怎样收缩。

## 示例

“AI 不能替代内容判断”太宽。可论证为：在地产留学项目中，AI 能稳定辅助生成月度内容，但产品、目标用户与销售承接仍由人决定；因为这些决策需要承担现实后果，并依赖项目内未被模型自动掌握的信息。因此，在当前项目中，AI 更适合作为执行协作者，而不是最终决策者。

案例不是因为“真实”就足够。它只支持特定条件下出现过这一关系，不能自动推出所有行业都如此。

## 输出标准

一张主张—根据—连接—限定—异议表，以及不能被现有证据支持的删减句。

## 验证

让反对者指出最弱连接。如果对方不接受材料仍能理解你的推理，论证至少清楚；若连你从哪里跳到哪里都看不见，先补连接。
