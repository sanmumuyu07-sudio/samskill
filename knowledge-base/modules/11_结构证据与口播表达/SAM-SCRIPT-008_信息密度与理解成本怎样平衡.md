# 信息密度与理解成本怎样平衡

## 叁木判断

信息密度不是单位时间塞进多少知识点，而是每一段对核心理解贡献多少，同时让用户还有能力连接前后关系。

## 两种低质量

低密度内容反复换句式表达同一结论；高负荷内容连续抛出概念、数字和案例，却不给用户建立关系的时间。前者让人觉得空，后者让人听不懂。

## 判断方法

每出现一个新概念，检查用户是否已有前置知识；每出现一组数据，说明它在回答什么；每完成一个复杂关系，用例子、对比或小结建立认知支点。

一条短内容优先只完成一个核心判断。其他有价值的信息可以进入系列内容、评论补充或知识库，不必全部挤在一条里。

## 输出标准

核心任务、必需信息、可选信息、前置概念、认知支点和拆分建议。

## 验证

盲听后让用户复述关系而非关键词。只记住金句说明解释可能不足；只说“很专业”却讲不出结论，说明负荷过高。
