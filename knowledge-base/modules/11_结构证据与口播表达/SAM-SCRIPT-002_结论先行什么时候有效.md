# 结论先行什么时候有效

## 叁木判断

结论先行适合用户已经理解问题、正在寻找判断或决策的内容。它不是所有短视频的固定句法。

## 有效条件

用户知道你在说什么；结论本身能被理解；后文会提供理由；提前知道答案不会毁掉主要体验。避坑、判断、步骤和复盘内容通常符合这些条件。

## 何时不适合

用户还没意识到问题、结论包含陌生概念、核心价值来自发现过程，或故事需要先建立人物与冲突时，可以先提供一个明确问题，而不是完整答案。

## 常见误用

“做 IP 最重要的是定位。”这不是结论先行，而是抽象断言。它没有说明对象、条件和“重要”的比较标准。

更可用的说法是：“如果你的内容每条都在换人群，先别优化开头，先把账号承诺固定下来。”用户能立即知道适用处境和优先动作。

## 输出标准

结论句、用户必须已有的前提、需要补充的证据以及不采用结论先行的理由。

## 验证

分别做结论前置与问题前置两个版本，只改变顺序，不同时改变标题、证据和表达，再比较理解、停留及用户质量。
