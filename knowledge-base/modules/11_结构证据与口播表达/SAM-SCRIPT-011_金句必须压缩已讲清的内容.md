# 金句必须压缩已讲清的内容

## 叁木判断

金句是判断的压缩包，不是判断的替代品。用户先理解展开内容，压缩句才会成为记忆入口。

## 为什么

“流量不是结果”容易记，但如果没有说明不同业务的结果分别是什么，它只是一种姿态。完整展开可能是：广告 IP、线索 IP 和公共表达使用不同结果指标；播放量只能证明内容被分发，不能直接证明成交或交付成立。

## 生成方法

先写清对象、关系、条件与反例，再删掉可由上下文恢复的部分。保留最有区分度的关系，不为押韵改变事实。

金句可以承担标题、小结或转场，但关键限定要在附近出现。被单独截图后可能误导的句子，要主动补上适用范围。

## 输出标准

展开版、压缩版、不可删除的限定、适合出现的位置和可能误读。

## 验证

让用户解释金句。若只能复述原句，不能举例或判断边界，说明内容只制造了记忆，没有制造理解。
