# 口语化不等于大白话

## 叁木判断

口语化是让句子能被一个具体的人自然说出，也能被另一个人一次听懂。它不是把所有专业词换成简单词，更不是故意写得粗糙。

## 四个检查点

1. 句子是否一口气承担太多关系。
2. 指代是否清楚，听众看不见上文时是否仍能跟上。
3. 抽象词后面是否有具体解释或场景。
4. 语气是否来自说话者真实表达，而不是统一“网感”。

必要概念可以保留。例如“供给侧”若与主题有关，应立即解释为“内容能否稳定生产的这一边”，而不是直接删掉。准确和易懂不是二选一。

## 常见误用

机械加入“你知道吗”“说白了”“我跟你讲”；把所有句子切成五六个字；为了接地气牺牲限定；使用与说话者身份不一致的夸张措辞。

## 输出标准

保留概念、解释句、自然停顿、重音句、说话者指纹与不得模仿项。

## 验证

本人不看稿试读并录音。凡是需要临时改词才能说顺的地方，记录真实改法；连续三次出现后再升级为风格规则。
