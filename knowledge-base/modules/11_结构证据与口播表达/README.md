# 模块 11｜结构、证据与口播表达

## 本模块解决什么

把一个已经通过选题与包装判断的命题，写成一条听得懂、信得过、能连续听下去的内容。

## 本模块不解决什么

不替代选题、平台、传播和转化判断；不承诺套模板就能爆；不把语言顺滑误当成观点成立。

## 核心判断

> 结构不是模板名称，而是用户完成一次理解所需要的信息顺序。

> 文案不是把观点说得更像结论，而是让主张、证据、解释、边界和行动能够互相接得上。

## 问题树

1. 这条内容要让用户完成什么理解任务？
2. 核心主张由什么材料和推理支持？
3. 哪种结构最适合当前任务？
4. 每一段为什么必须出现在这里？
5. 写出来以后能否被自然说出、准确听懂并经受核查？
