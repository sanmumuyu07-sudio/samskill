# 模块 14｜数据复盘与增长实验

## 本模块解决什么

把平台行为、用户反馈、线索交易和交付结果放进同一条可追溯链，找到第一个断点，并设计下一轮可检查的比较。

## 不解决什么

不提供万能阈值，不用单条爆款证明规律，不把自然流比较写成严格因果实验，也不把平台相关性直接定位成文案问题。

## 核心判断

> 数据不是答案。数据先说明发生了什么，结合内容版本、项目条件和反馈，才能形成暂时解释。

> 复盘的交付物不是一份报表，而是下一轮只需要验证的一个关键问题。

## 十二张原子

1. SAM-DATA-001_数据不是结果的同义词
2. SAM-DATA-002_平台指标必须先统一口径
3. SAM-DATA-003_曝光停留完播互动和主页访问的关系
4. SAM-DATA-004_线索有效线索成交和交付的关系
5. SAM-DATA-005_单条内容怎样复盘
6. SAM-DATA-006_栏目和账号怎样跨期复盘
7. SAM-DATA-007_中位表现比单条峰值更接近稳定能力
8. SAM-DATA-008_数据异常怎样定位到具体节点
9. SAM-DATA-009_自然流实验怎样建立基线
