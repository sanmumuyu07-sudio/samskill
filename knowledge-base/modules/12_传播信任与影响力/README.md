# 模块 12｜传播、信任与影响力

## 本模块解决什么

解释一条内容为什么值得存在、为什么有人愿意停留、相信、记住、转发，以及这些传播结果怎样连接关系、机会和交易。

## 不解决什么

不预测必爆，不把算法解释成情绪按钮，不把群体潜意识当万能答案，也不把高播放自动换算成商业价值。

## 核心判断

> 传播不是把信息发出去，而是让某一类人在某个处境中获得了值得继续、相信或带给别人的东西。

> 影响力不是一次曝光，而是别人对你形成可调用的稳定判断，并在现实任务出现时愿意采取行动。
