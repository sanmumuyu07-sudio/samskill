# 模块 10｜标题、封面与开头

## 本模块解决什么

让正确用户在特定分发场景中快速确认内容与自己有关、值得继续，并确保包装承诺能被正文兑现。

## 核心判断

> 标题负责命名选择，封面负责降低识别成本，开头负责在内容已经开始后建立继续消费的理由。三者协作，但不是同一句话重复三次。

> 相关性先于刺激，兑现先于技巧。内容本身空洞时，优化包装只会放大失望与错误流量。
