# 用户不是人口标签

## 叁木判断

> 年龄、性别、城市和职业可以帮助找人，却不能单独解释一个人为什么在此刻看、信、买或行动。

人口特征主要回答“在哪里可能找到相似的人”。

用户研究还要回答：

- 发生了什么。
- ta 正在完成什么任务。
- 已经试过什么。
- 受什么限制。
- 害怕失去什么。
- 谁影响或批准决定。
- 什么结果才算更好。

## 一、标签有用但有限

“30 岁、一线城市、女性、月薪一万”可以用于媒介投放和样本描述。

但这些信息不能直接推出：

- 想创业。
- 害怕被淘汰。
- 愿意买课。
- 认同女性成长叙事。
- 有时间执行。

这些都需要单独证据。

## 二、同标签不同任务

两个实体老板都想做短视频。

一个需要给门店导流。

一个需要招商加盟。

一个有团队、预算和产品。

一个只有本人时间。

人口标签相同，内容、产品和指标完全不同。

## 三、同一人也会切换任务

用户早上搜索教程，晚上观看观点，项目失败后寻找诊断，准备付费前检查案例。

人不是固定画像。

ta 在不同阶段会调用不同内容和产品。

## 四、行动步骤

1. 保留人口特征作为样本背景。
2. 用最近一次真实事件替代抽象自述。
3. 记录任务、行为、替代方案和限制。
4. 区分付款、使用和验收角色。
5. 写哪些结论不能由标签推出。

## 五、案例

“想做个人 IP 的创业者”不能直接成为叁木产品人群。

更可研究的版本是：已经有产品、服务或现实项目，正准备通过自然流短视频获得第一批稳定咨询，愿意持续执行，但缺少完整判断和复盘系统的人。

它仍是假设，需要搜索、咨询、付款和使用证据继续校准。

## 六、反例

用“小镇做题家”推断用户一定自卑、渴望阶层跃迁并愿意购买高价成长课程。

标签带来故事，不等于带来个体证据。

## 七、输出标准

- 人口背景。
- 真实触发事件。
- 当前任务与约束。
- 已有行为和替代方案。
- 决策角色。
- 不能由现有信息推出的判断。
