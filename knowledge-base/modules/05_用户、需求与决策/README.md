# 模块 05｜用户、需求与决策

## 本模块解决什么

把模糊人群画像变成可被研究的处境、任务、风险、身份和决策证据。

## 核心判断

> 用户不是一组人口标签，而是在某个处境中承担任务、受资源限制、比较替代方案并作出选择的人。

> 被看见、被承认和成为某种人可以影响选择，但不能替代功能价值、现实路径与行动证据。

> 评论、搜索、咨询、付款和使用回答不同问题。没有一种信号可以单独证明完整需求。

## 原子顺序

1. SAM-USER-001_用户不是人口标签
2. SAM-USER-002_处境比身份更接近决策
3. SAM-USER-003_用户任务的三层结构
4. SAM-USER-004_表面需求与真实任务的区别
5. SAM-USER-005_欲望怎样形成市场
6. SAM-USER-006_痛点不是问题本身
7. SAM-USER-007_风险怎样阻碍第一次行动
8. SAM-USER-008_身份认同怎样影响内容选择
9. SAM-USER-009_社会位置怎样改变同一需求
10. SAM-USER-010_用户认知阶段怎样影响表达
11. SAM-USER-011_评论搜索与咨询怎样互相补证
12. SAM-USER-012_用户假设怎样前向验证
