# 风险怎样阻碍第一次行动

## 叁木判断

> 用户不行动不一定是没有欲望，也不一定是懒。新动作会让ta承担金钱、时间、身份、关系和失败证据，现状即使不好也可能更可预测。

## 一、五类行动风险

- 经济：钱、时间和机会成本。
- 能力：做不好、学不会、无法坚持。
- 身份：公开后显得不专业或失败。
- 关系：同事、家人、客户的评价。
- 不可逆：合同、离职、公开承诺或长期投入。

## 二、四股力量

```text
现状的不满
+ 新结果的吸引
对抗
旧方案的惯性
+ 新方案的焦虑
```

不能只继续放大终点。

有时更有效的动作是降低第一次尝试的不可逆性。

## 三、风险降低不是虚假保证

可以：

- 缩小首次动作。
- 明确退出条件。
- 展示真实过程和失败边界。
- 先用小样本测试。
- 让用户保留原有方案。
- 提供可检查标准。

不可以：

- 承诺不可控制结果。
- 虚构退款无风险。
- 用倒计时和羞耻逼迫。

## 四、案例｜不敢发第一条内容

问题可能不是不会写。

第一条公开内容会产生一份可被熟人评价的身份信号。

更合理的起点可以是：

- 先选低风险真实任务。
- 缩小受众和承诺。
- 用可修改版本发布。
- 提前写评价与删除边界。

## 五、反例

“你不发就是不够想成功。”

它把风险、资源和身份成本压缩成道德判断。

## 六、输出标准

- 目标动作与参照点。
- 五类风险。
- 四股力量。
- 可逆的最小动作。
- 成功、失败和退出条件。
