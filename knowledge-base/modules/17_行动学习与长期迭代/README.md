# 模块 17｜行动、学习与长期迭代

## 本模块解决什么

让知识进入真实项目，把模糊意愿变成可执行路径，把发布、用户、数据和交易反馈变成下一轮判断与数字资产。

## 不解决什么

不把所有不行动归因于懒、自卑或心理问题；不替代心理咨询和医疗；不把打卡、忙碌或购买课程当作行动结果；不承诺七天获得商业成功。

## 核心判断

> 没有现实任务，方法会变成认知消费；没有反馈回填，行动只是在重复劳动。真正的知行合一不是“终于想通”，而是判断进入行动，行动产生证据，证据反过来修改判断。

## 十二张原子

1. SAM-ACT-001_没有现实任务方法会变成认知消费
2. SAM-ACT-002_知道与做到之间断在哪里
3. SAM-ACT-003_认知失调怎样影响项目判断
4. SAM-ACT-004_身份保护怎样包装成方法选择
5. SAM-ACT-005_行动问题先检查路径不先归因意志
6. SAM-ACT-006_最小动作怎样降低启动成本
7. SAM-ACT-007_七天怎样获得第一次真实反馈
8. SAM-ACT-008_失败怎样从情绪变成信息
9. SAM-ACT-009_复盘怎样形成判断力
10. SAM-ACT-010_学习怎样连接项目和作品
11. SAM-ACT-011_经验怎样进入数字资产
12. SAM-ACT-012_长期迭代怎样避免反复重启

## 问题树

先确认现实任务和当前阶段；再区分信息缺口、路径缺口、资源限制、行动阻力和身份保护；设计足够小但能接触现实的动作；把反馈、失败和作品写回项目，形成下一轮可验证判断。
