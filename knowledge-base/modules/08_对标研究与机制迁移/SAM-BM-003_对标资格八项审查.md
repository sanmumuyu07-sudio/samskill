# 对标资格八项审查

## 它解决什么问题

人会天然研究自己喜欢、熟悉或崇拜的对象。

但值得看，不等于值得学。

值得学，也不等于适合当前项目执行。

八项审查的作用，是把“我想学他”拆成一组可以检查的条件。

## 叁木判断

> 一个对象是否值得进入研究，要同时检查结果、证据、阶段、机制、条件和迁移成本。任何一项关键条件不成立，结论都要降级。

八项不是平均分。

它们更像八道门。

有些门不过，直接换对象。

有些门不过，可以保留观察价值，但不能进入执行。

## 一、结果相关

先问：对方拿到的结果，是不是你真正想要的结果。

常见结果包括：

- 播放。
- 涨粉。
- 搜索。
- 广告收入。
- 有效线索。
- 到店。
- 成交。
- 利润。
- 复购。
- 品牌认知。

一个广告IP的高播放，不等于专业服务账号的高质量咨询。

一个知识博主的课程成交，也不等于实体门店的到店与复购。

结果类型不一致，对标只能研究局部动作。

## 二、结果强度

如果要改变数量级，候选对象的结果需要明显高于当前水平。

这能避免把研究时间花在“比自己稍微好一点”的对象上。

但结果强度必须和结果质量一起看。

高播放、低咨询，不一定优于低播放、高成交。

高收入、高退款，也不一定是更好的生意。

利润高出十倍可以成为候选筛选线。

它不是跨业务公理。

## 三、结果可见

公开页面能看到粉丝和播放。

它通常看不到：

- 实付价格。
- 退款。
- 投放。
- 人力。
- 交付成本。
- 税务与合规成本。
- 真实利润。

如果关键结果只来自营销海报或本人自述，要标注来源等级。

看不见利润，就不能假装算出利润。

## 四、阶段可比

成熟账号今天发布的内容，可能只负责维护关系。

冷启动账号需要的，是第一次被看见和第一次建立证明。

至少区分：

- 介入前。
- 第一次验证。
- 放大。
- 组织化。

阶段差距过大时，优先找对方过去的阶段样本。

找不到，就只研究长期方向，不直接复制更新节奏。

## 五、机制可拆

如果结果主要依赖：

- 明星身份。
- 独家牌照。
- 特殊关系。
- 巨额预算。
- 已有渠道。
- 不公开供应链。

这些条件必须被单独标出。

机制可拆，不是要求全部资源都一样。

而是要知道每项资源在结果中完成什么作用。

## 六、条件可映射

映射不是“我也有同样的东西”。

映射是：

> 对方用什么条件完成什么作用，我是否有其他条件能够完成相同作用。

例如：

- 对方用名校身份建立信任。
- 你没有名校身份，但可能有持续项目结果和可检查案例。

作用相同，资源可以不同。

作用无法替代，就不能假装可复制。

## 七、学习成本可承受

复制一个模式需要：

- 研究材料。
- 学习能力。
- 设备和工具。
- 时间与现金。
- 试错次数。
- 失败承受能力。

能做，不等于当前应该做。

如果第一轮验证需要的成本已经超过项目承受能力，应当缩小机制或更换样本。

## 八、证据足够

证据是否足够，取决于研究问题。

研究开头，可能十几条内容就够。

研究长期账号方法，需要跨期、高中低和转折样本。

研究商业模式，还要产品、成交和交付证据。

不存在脱离问题的统一样本数量。

## 九、八项审查的阻断关系

| 审查项 | 不通过时怎样处理 |
|---|---|
| 结果相关 | 换对象，或缩小到局部研究 |
| 结果强度 | 降低研究优先级 |
| 结果可见 | 商业结论降级 |
| 阶段可比 | 只保留方向价值 |
| 机制可拆 | 只记录现象与不可复制条件 |
| 条件可映射 | 不进入当前执行 |
| 成本可承受 | 缩小实验或换样本 |
| 证据足够 | 继续收集，不补全结论 |

## 十、输入标准

- 当前目标结果。
- 当前阶段和基线。
- 候选对象。
- 候选对象可见结果。
- 材料时间范围。
- 当前资源和约束。
- 第一轮可以承受的测试成本。

## 十一、输出标准

```text
候选对象：
研究目标：
结果相关：通过/局部/不通过
结果强度：高/中/低/未知
结果可见：事实/自述/推断/未知
阶段可比：通过/需回溯/不通过
机制可拆：通过/部分/不通过
条件可映射：通过/需替代/不通过
学习成本：可承受/需缩小/不可承受
证据足够：是/需补充
最终资格：执行对标/方向案例/内容样本/淘汰
```

## 十二、完整案例

用户目标是通过自然流获得高客单留学咨询。

候选对象拥有大量泛娱乐播放，但主要商业结果来自品牌广告。

审查结果：

- 结果相关：局部。
- 结果强度：传播很高。
- 结果可见：播放可见，利润未知。
- 阶段可比：成熟账号，不可直接指导冷启动。
- 机制可拆：部分可拆。
- 条件可映射：内容形式可映射，商业链路不可映射。
- 学习成本：可承受。
- 证据足够：只能研究传播。

最终资格：

> 保留为内容传播样本，不能成为留学获客商业对标。

## 十三、反例与常见错误

### 粉丝多，所以值得学

粉丝只证明积累结果。

不能说明结果类型和商业质量。

### 对方赚钱，所以他说的都对

赚钱证明整体组合成立。

不证明当事人对成功原因的每一种解释都正确。

### 每一步都能做，所以应该复制

还要检查成本、时间、风险和机会成本。

### 我没有对方资源，所以完全不能学

先检查资源完成的作用能否被替代。

## 十四、常见问题

### “找不到完全一样的对标怎么办？”

不要找完全一样的人。

分别找：

- 结果对标。
- 内容对标。
- 产品对标。
- 转化对标。
- 组织对标。

不同对象可以解决不同问题。

### “八项都要通过吗？”

进入完整执行对标时，需要关键项通过。

只做局部机制研究时，不需要全部通过。

### “十倍标准还留不留？”

留在候选排序，不放在事实判断。

## 十五、边界

八项审查用于分配研究权限，不是给人物或账号做价值排名。

公开信息不足时，应缩小结论或补材料，不能把“未知”直接判为“不成立”。
