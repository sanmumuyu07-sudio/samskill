# 模块 08｜对标研究与机制迁移

## 本模块解决什么

把“我想学这个账号”变成一项有问题、有样本、有证据、有机制、有迁移边界和结果回填的研究任务。

## 核心判断

> 对标不是复制一个成功者，而是研究某个结果在什么条件下，通过什么机制出现，再判断这段关系能否进入自己的项目。

> 公开内容能证明对方做了什么，通常不能单独证明团队、利润、投流、交付和唯一因果。

> 迁移关系，不迁移人设、原话、镜头和成功者专属条件。

## 十一张原子

1. SAM-BM-001_先定义研究问题
2. SAM-BM-002_区分四种研究材料
3. SAM-BM-003_对标资格八项审查
4. SAM-BM-004_分层取样
5. SAM-BM-005_事实推断未知假设
6. SAM-BM-006_条件机制结果
7. SAM-BM-007_迁移关系不迁移表面
8. SAM-BM-008_最小实验与结果回填
9. SAM-BM-009_结果强度不是万能答案
10. SAM-BM-010_区分现实条件与自我辩护
11. SAM-BM-011_先减少变量再建立差异
