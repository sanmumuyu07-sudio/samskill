# 专家 IP、商业 IP 与生活方式 IP 的区别

## 叁木判断

三种类型不是人格，也没有高低。

它们描述账号主要用什么资产、帮助用户完成什么任务、靠什么关系获得回报。

## 一、三种重心

### 专家 IP

核心资产是特定知识、判断和解决能力。

主要证明是方法、案例、结果和边界。

### 商业 IP

核心资产是产品、组织、交易和行业资源。

内容服务于降低交易成本、建立信任、连接客户与合作。

### 生活方式 IP

核心资产是持续可见的生活选择、审美和关系认同。

用户获得参照、陪伴、想象或消费选择。

## 二、混合是常态

甜品项目既有技能教学，也有实体经营和生活场景。

关键不是强行归一，而是明确哪一种承担账号主承诺，哪一种作为辅助证据。

## 三、类型影响什么

- 需要哪种证据。
- 内容更新靠什么素材。
- 用户为什么关注。
- 商业结果通过产品、广告、线索还是关系产生。
- 什么行为会破坏信任。

## 四、反例

知识博主开始分享日常，就宣布转型生活方式 IP；实体老板讲专业，就自称专家 IP。

单条形式变化不等于资产与商业结构变化。

## 五、输出标准

- 主类型与原因。
- 辅助类型。
- 证据结构。
- 收入结构。
- 转型条件。
