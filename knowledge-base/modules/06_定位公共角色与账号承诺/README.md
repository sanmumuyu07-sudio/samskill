# 模块 06｜定位、公共角色与账号承诺

## 本模块解决什么

把“我是谁、我发什么”变成一套可被内容、产品、证据和用户反馈共同检验的账号承诺。

## 本模块不解决什么

- 不替代行业判断、用户研究和产品设计。
- 不用人格测试决定人设。
- 不承诺一句口号就能形成品牌。
- 不直接生成选题、脚本或视觉包装。

## 核心判断

> 定位不是一句简介，而是一组长期选择：为谁、解决什么、凭什么、以什么公共角色出现、反复交付什么结果，以及主动不做什么。

> 人设不是虚构人格，而是真实能力、经历和价值判断在公共场景中的选择性呈现。

> 账号承诺只有被内容、产品、证据和交付持续兑现，才会变成用户对你的稳定预期。

## 问题树

1. 定位究竟约束什么。
2. 公共角色怎样既真实又清楚。
3. 立场、赛道和差异怎样进入定位。
4. 账号承诺怎样形成品牌预期。
5. 怎样检验、调整并交付定位文档。
