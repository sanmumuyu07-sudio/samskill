# 模块 09｜选题与内容研究

## 本模块解决什么

把零散灵感、搜索词、评论、咨询、经历和行业变化，整理成有对象、有问题、有判断、有内容任务并能回填结果的选题系统。

## 核心判断

> 选题不是一句标题，而是一次公共沟通决策：为哪类处境中的人，提出什么问题，给出什么新判断，并推动什么下一步。

> 流量选题、信任选题、产品理解和行动内容承担不同任务。配比由当前断点决定，不存在所有账号通用的黄金比例。
