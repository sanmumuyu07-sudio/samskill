# 模块 01｜内容时代与一人媒体

> 公开测试模块 01。包含 12 张方法原子。

> 主要关联：`samskill`, `sam-project-diagnosis`。


## 本模块解决什么

这个模块不是先教用户怎么注册账号、追热点和日更。

它先回答五个更前置的问题：

1. 自媒体究竟是什么。
2. 个人为什么需要媒体能力。
3. 有本事为什么不等于有市场认知。
4. 什么时候需要完整个人 IP，什么时候只需要一份公共证明。
5. 影响力怎样进入关系、机会、交易与交付。

本模块不默认人人都要成为 IP。

它要求系统复杂度服从现实任务。

## 本模块的核心判断

> 自媒体不是拥有一个账号，而是个人取得议题、编辑、发布、连接与反馈的选择权，并为这些选择承担持续责任。

> 私人能力不会自动变成公共认知。能力必须经过归因、表达、证明与分发，才有机会被陌生人判断。

> 影响力不是粉丝数字。它是改变相关人群注意、理解、记忆、判断与行动概率的能力。

## 问题树

### 第一层｜先区分基本对象

- 账号与媒体有什么区别。
- “自”与“媒体”分别意味着什么。
- 个人 IP、品牌、一人公司和超级个体有什么区别。

### 第二层｜再处理能力怎样被市场看见

- 发布权开放以后，为什么注意力仍然稀缺。
- 私人积累怎样变成可检查的公共证明。
- 本事、项目结果与市场认知为什么不能混用。

### 第三层｜最后决定投入多少

- 谁需要经营完整 IP。
- 谁只需要最小公共证明。
- 影响力怎样进入现实结果。

## 四个直接使用的工具

读完概念以后，不要停在认同。

按现实情况选择工具：

1. T01_一人媒体能力诊断表
   检查你现在只有账号、只有生产线，还是已经形成媒体闭环。
2. T02_IP系统强度决策树
   决定你暂时不公开、只做最小证明、做专题媒体，还是建设完整 IP。
3. T03_最小公共证明模板
   把经历、项目与能力整理成陌生人可以检查的一页材料。
4. T04_影响力六层漏斗与断点诊断
   区分问题发生在看见、理解、记忆、信任、行动还是现实结果。

## 已处理的冲突

本模块不直接继承以下说法：

- 人人都适合做完整个人 IP。
- 粉丝天然是资产。
- 有能力自然会被看见。
- 有流量自然会有生意。
- 做自己自然形成差异。
- AI 能代替市场、用户与商业判断。
