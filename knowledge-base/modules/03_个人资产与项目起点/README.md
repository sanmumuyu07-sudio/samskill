# 模块 03｜个人资产与项目起点

> 公开测试模块 03。包含 12 张方法原子。

> 主要关联：`sam-project-diagnosis`, `sam-assets`。


## 本模块解决什么

这个模块不负责替用户发现一个高级身份。

它负责把经历、能力、资源、关系、兴趣和特定知识，变成有证据、有权限、有边界、能进入真实任务的个人资产。

## 核心判断

> 经历是发生过的事件。资产是经历留下的、能够被调用、证明、复用并继续增加价值的东西。

> 能力不是形容词。它是在明确条件下通过一组动作较稳定地产生结果，并知道什么时候不会出现。

> 新项目的最小起点不是身份、赛道或账号，而是一项有任务所有者、完成标准、截止和反馈的现实任务。

## 来源入口

- 从现有手段和可承受损失开始。
- 知识与技能投入形成生产能力。
- 资本形式与转换条件。
- 不可见能力与可观察信号。
- 从已发生事件寻找重复动作。
- 特定知识与产品化。
- 叁木个人资产与能力边界。

## 已处理冲突

- 经历很多不等于资产很多。
- 做起来轻松不等于已经形成能力。
- 关系名单不等于可调用资源。
- 特定知识不等于市场会识别。
- 兴趣不等于适合商业化。
- 一个大结果不等于个人能力强。
- 没有案例不等于必须伪装成熟。
- 所有用户不使用同一份调研表。
