# 模块 04｜产品、价值与变现

## 本模块解决什么

把能力、资料或服务变成一套可以被理解、选择、交付和验证的产品。

## 核心判断

> 产品不是一堆交付物。产品是面向特定用户和场景，对一项结果作出的有限承诺，以及实现它所需的交付机制。

> 交易不只交换钱。用户还交换时间、注意力、行动、信任和放弃其他方案的机会。

> 付款证明承诺被选择过。使用、结果、复购和利润，才继续证明产品是否成立。
