# 模块 13｜生产、发布与自然流运营

## 本模块解决什么

把已经通过判断的内容，从素材变成稳定发布、可追踪、可交接的自然流生产系统。

## 不解决什么

不替代定位、用户、选题、脚本和数据判断；不提供万能日更频率；不把养号、账号权重和固定流量池当运营事实。

## 核心判断

> 内容生产不是写稿，而是一组从输入到结果回填的连续状态。

> SOP 可以让正确动作稳定发生，却不能替团队决定下一条内容为什么存在。
