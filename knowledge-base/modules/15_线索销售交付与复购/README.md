# 模块 15｜线索、销售、交付与复购

## 本模块解决什么

让公域内容带来的兴趣进入一条可诊断、可成交、可交付、可复购并能反哺内容的经营链。

## 不解决什么

不把所有用户导入私域，不用话术让不适配者购买，不承诺高客单必然更好，也不把满意和复购当成同一件事。

## 核心判断

> 流量解决“谁来到门口”，销售解决“彼此是否适配”，交付决定“承诺是否兑现”，复购取决于是否还有真实任务值得继续交换。

2. SAM-CONV-002_线索不等于有效客户
3. SAM-CONV-003_内容怎样完成用户筛选
4. SAM-CONV-004_主页与行动入口怎样承接内容
5. SAM-CONV-005_私信和咨询怎样完成问题诊断
6. SAM-CONV-006_销售不是重复产品信息
7. SAM-CONV-007_高客单成交需要降低哪些风险
8. SAM-CONV-008_内容销售和交付承诺必须一致
9. SAM-CONV-009_交付怎样产生下一轮内容与口碑
10. SAM-CONV-010_复购来自持续任务不只来自满意度
11. SAM-CONV-011_前端流量过量为什么会伤害业务
12. SAM-CONV-012_完整经营漏斗怎样复盘
