# 模块 07｜平台、分发与账号基础

## 本模块解决什么

判断内容为什么在特定平台被发现、被选择或停止扩散，并建立账号基础、指标口径、合规与规则时效管理。

## 核心判断

> 平台不是中立管道，而是同时连接用户、创作者、广告主和交易者，并按自身目标持续调整规则的分发环境。

> 创作者能看到行为结果，通常看不到完整排序公式。复盘要用可观察数据改进内容，不能把行业传言写成算法事实。

> 平台成功、内容成功、关系成功和商业成功是四个不同结果。
