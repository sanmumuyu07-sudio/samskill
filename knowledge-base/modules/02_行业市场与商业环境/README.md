# 模块 02｜行业、市场与商业环境

> 公开测试模块 02。包含 12 张方法原子。

> 主要关联：`sam-business`, `sam-project-diagnosis`。


## 本模块解决什么

这个模块不负责预测风口。

它负责把“赛道很火”“用户有痛点”“别人赚到钱”拆成可以检查的市场和商业条件。

完成后应当能够回答：

1. 一个赛道名称下面是否有真实需求链。
2. 需求、欲望、支付意愿和行动时机是否被混用。
3. 行业、赛道、品类和平台分别在限制什么。
4. 总市场怎样经过五道门，才可能成为个人机会。
5. 行业阶段、供需、趋势和商业模式怎样改变内容任务。
6. 线上内容怎样连接广告、线索、实体和专业服务。

## 核心判断

> 市场不是一个热词。市场是一群处在具体情境中的人，正在尝试完成某个任务，并愿意、能够通过交换获得更好结果。

> 总市场说明交换在多大范围内发生。个人机会取决于能否进入具体任务、触达对应用户、提供可信方案，并在成本、交付与竞争之后留下结果。

> 商业模式是参与者怎样共同创造价值，并分配收入、成本、风险、时间与控制权。内容只能改变其中一部分。

## 问题树

### 第一层｜市场是否成立

- 赛道名称下面有没有需求链。
- 用户是认同、行动还是支付。
- 总市场是否能转成当前入口。

### 第二层｜环境怎样限制机会

- 行业、赛道、品类和平台有什么区别。
- 阶段与供需怎样改变竞争和内容任务。
- 趋势、窗口、周期和热点如何分开。

### 第三层｜价值最终怎样进入交易

- 商业模式怎样分配成本、收益和风险。
- 赛道怎样影响粉丝关系与商业上限。
- 广告 IP 与线索 IP 为什么不能混用指标。
- 线上怎样连接原有线下业务。

## 四个直接使用的工具

1. T01_市场机会成立性诊断
   区分市场存在与个人入口，找到五道门中的第一处断点。
2. T02_行业与商业环境扫描表
   把市场、行业、趋势和宏观材料转成一页决策单。
3. T03_趋势窗口周期与热点分类器
   决定变化应该进入长期建设、短期实验、周期准备还是内容语境。
4. T04_交易模型与成本收益风险台账
   分开付款者、价值流、资金流、风险和决策权，找到结构性上限。

## 来源入口

- 需要、欲望、有效需求与市场选择。
- 产业结构怎样分配长期利润。
- 商业模式必须放进环境中判断。
- 新观念通过渠道、时间和社会系统扩散。
- 数字平台怎样改变市场关系。
- 冷启动优先连接既有欲望。
- 叁木市场与商业环境判断集合。
- 叁木跨项目一手复盘。

## 已处理的冲突

本模块不直接继承：

- 人的欲望无限，所以个人市场无限。
- 赛道很大，所以个人一定有机会。
- 行业增长快，所以利润一定高。
- 自然流没有获客成本。
- 流量高，所以商业模式成立。
- 广告 IP 和线索 IP 只能二选一。
- 一个热点出现，就代表长期趋势。
- 固定流量池、统一完播率和永久账号权重。
