# 广告 IP 与线索 IP 的商业差异

## 它解决什么问题

两个账号都在追求播放。

一个靠品牌预算赚钱。

另一个靠咨询和成交赚钱。

如果使用同一套指标和内容逻辑，团队会出现相反误判：

- 广告 IP 有播放和商单，却被说“没有私域闭环”。
- 线索 IP 粉丝很多，却没有有效咨询，仍被说“账号做得很好”。

## 叁木判断

> 广告 IP 把受众注意力和内容环境提供给品牌方；线索 IP 用内容降低潜在客户的发现、理解和信任成本，再把关系交给产品与销售。付款者不同，核心资产、内容任务和结果指标就不同。

二者可以混合。

混合不等于混算。

## 一、广告 IP 的交易结构

### 付款者

品牌、代理商或平台商业系统。

### 使用者

内容受众。

### 核心资产

- 可识别受众。
- 稳定触达。
- 内容风格与品牌适配。
- 粉丝、互动、播放与商业信用。

### 收入方式

商单、植入、品牌合作、平台分成等。

### 内容任务

在不破坏用户关系的前提下，稳定创造品牌可购买的注意力和内容场景。

## 二、线索 IP 的交易结构

### 付款者

最终购买服务或产品的客户。

### 使用者

可能是同一个人，也可能是家庭、企业或组织成员。

### 核心资产

- 对任务的理解。
- 专业证明。
- 有效线索来源。
- 产品、销售和交付能力。
- 结果与转介绍。

### 收入方式

咨询、服务、课程、商品、到店、成交佣金等。

### 内容任务

吸引合适处境的人，帮助其理解问题、判断方案并完成下一步。

## 三、两种模型的核心指标

| 环节 | 广告 IP | 线索 IP |
|---|---|---|
| 受众 | 规模、结构、活跃与品牌适配 | 任务、阶段、资格与购买可能 |
| 内容 | 播放、互动、品牌安全、植入效果 | 主页访问、咨询、有效线索、信任 |
| 交易 | 商单数量、报价、续约与回款 | 成交、毛利、退款、交付、复购 |
| 风险 | 平台、品牌预算、粉丝活跃 | 销售、产品、交付和合规 |

指标不能机械跨用。

## 四、为什么粉丝在广告 IP 中更像筹码

品牌方无法直接观察创作者对每个用户的真实影响。

因此会使用粉丝、播放、互动、内容标签、历史合作和第三方数据作为信号。

不同平台和行业，对这些信号权重不同。

这不表示粉丝永远比播放重要。

只表示交易规则由品牌采购和平台环境共同形成。

## 五、为什么线索 IP 不应迷信粉丝量

一个未关注用户也可以搜索到内容、进入主页并咨询。

线索 IP 更关心：

- 用户是否符合资格。
- 内容是否降低决策不确定性。
- 销售能否识别和推进。
- 产品能否交付结果。

粉丝仍然能降低重复触达和建立信任。

但它不是成交的充分条件。

## 六、混合模式怎样管理

### 分开付款者

品牌预算和客户付费分别记录。

### 分开内容任务

品牌内容、公共内容、获客内容和产品内容设置不同目标。

### 分开用户风险

商业合作不能损害专业承诺和用户信任。

### 分开数据台账

广告报价不能用咨询成交替代，客户价值也不能只用播放证明。

### 建立冲突规则

哪些品牌不接、哪些产品不植入、哪些内容必须披露合作。

## 七、判断步骤

完整填写使用 [[T04_交易模型与成本收益风险台账]]。

1. 谁最终付款。
2. 对方购买的是什么结果。
3. 受众与付款者是否同一方。
4. 核心资产是什么。
5. 内容承担哪一步。
6. 用什么指标计价和复盘。
7. 混合时有哪些关系冲突。

## 八、输入标准

- 最近一年收入来源。
- 品牌与客户分别如何付款。
- 平台、粉丝与播放数据。
- 咨询、有效线索和成交。
- 内容类型与行动入口。
- 商业合作披露和边界。
- 交付与复购数据。

## 九、输出标准

1. 主交易模型与次交易模型。
2. 两类付款者。
3. 核心资产与内容任务。
4. 分开指标。
5. 当前混算造成的误判。
6. 冲突和披露规则。
7. 下一轮分别验证的结果。

## 十、完整案例｜微博美食与知识付费矩阵

### 微博美食 IP

原账号拥有百万级粉丝，品牌方是付款者。

内容重构提高商业播放和接单价值。

这里粉丝基数、平台商业标签和商务资源共同构成交易底盘。

### 知识付费矩阵

内容把目标用户导入私域，再通过直播成交课程。

用户是否关注不是唯一重点。

有效客资、成交和交付更接近商业结果。

### 结论

两者都需要内容能力。

但不能用“私域成交”否定广告 IP，也不能用“粉丝很多”证明线索 IP 成立。

## 十一、反例

一个高客单专业账号既接品牌合作，也销售自己的服务。

这不表示它必须二选一。

只要付款、内容任务、指标和信任冲突被分开管理，混合模式可以成立。

## 十二、常见错误

- 认为所有 IP 最终都要卖自己的课。
- 用粉丝量代替有效线索。
- 用成交额替代品牌传播效果。
- 商业内容不披露，消耗长期信任。
- 接与核心承诺冲突的品牌。
- 把不同收入合并后宣称一种模式成立。

## 十三、常见问题

### 哪一种模式更高级

没有高低。

看项目拥有的资产、客户和经营能力。

### 广告 IP 能不能转线索 IP

可以，但原受众是否有购买任务、账号承诺能否迁移、产品是否成立，都要重新验证。

### 线索 IP 需要追求大传播吗

需要在相关公共问题中建立更大影响力，但不能让吸引对象与产品完全断开。

## 十四、边界

本原子不提供品牌报价、不完成销售流程，也不把所有收入强行归为两类。

电商、订阅、平台分成等模式可以另列，但仍用付款者、核心资产和指标拆解。

## 十五、来源与冲突处理

- OECD 的多边平台研究支持内容受众、广告主和平台可能是不同参与者。
- 叁木微博与知识付费项目为两种交易结构提供直接对照。
- 历史判断“广告 IP 与线索 IP 不能混用”被修正为“判断标准不能混用，商业模式可以组合”。
- 平台和品牌具体计价规则必须按时间核验，不在本原子固定。
