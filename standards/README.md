# Samskill 公开统一标准

本目录保存多个 Skill 共同遵守、适合公开复查的统一协议。

- `evidence-and-atom-rules.md`：知识如何从来源进入方法原子。
- `cross-module-priority.md`：多个问题同时出现时先解决什么。
- `case-evidence.md`：案例能够证明什么，怎样标记证据等级。
- `freshness-and-versioning.md`：平台、市场、AI 与稳定原理怎样分开更新。
- `progressive-loading.md`：原子库、Skill references 与脚本怎样渐进加载。

公开 Beta 中，各 Skill 仍保留必要运行规则，避免单独安装时失效。这里是公开唯一标准候选，真实测试稳定后再减少重复副本。
