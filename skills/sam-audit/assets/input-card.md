# 发布前审计输入卡

## 这个 Skill 帮你解决什么

判断最终内容能否发布，检查事实、逻辑、传播兑现、作者声音、原创、平台、版权、隐私与承诺风险。

## 最少提供这些

1. 最终稿，并确认是不是最终版本。
2. 标题、封面、开头、发布平台和本条主要任务。
3. 哪些是有来源的事实，哪些是个人判断。
4. 是否涉及案例、收益、医疗、法律、金融、版权、隐私或产品承诺。

## 有这些材料会更准确

- 原始来源、授权与引用信息。
- 画面、音乐、素材和资质说明。
- 作者风格卡与原始参考材料。
- 当前平台官方规则或页面。

## 没有材料时会怎样处理

对能核验的部分给结论。

无法核验的高风险事实标为阻断，不用“可能没问题”代替审计。

## 你会得到什么

1. 通过、有条件通过或不通过。
2. 致命问题与返工位置。
3. 事实、逻辑、原创、平台、隐私和承诺风险。
4. 复检清单与发布门。
