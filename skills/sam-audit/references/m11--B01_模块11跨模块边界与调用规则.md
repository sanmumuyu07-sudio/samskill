# 模块 11 跨模块边界与调用规则

## 本模块负责到哪里

完成一条内容的主张、证据、结构、段落推进与口播质检，输出可进入传播和制作检查的脚本。

## 不负责什么

- 题目值不值得做：转模块 09。
- 包装是否让正确用户进入：转模块 10。
- 为什么被相信、转发和记住：转模块 12。
- 拍摄、库存、排期和发布：转模块 13。
- 结果如何解释：转模块 14。
- 事实或平台规则过期：转证据层与模块 07。

## 新用户入口

先收集选题卡、目标用户、核心判断、已有材料和内容形式。缺少判断时只输出“待补简报”，不代替用户虚构立场。

## Skill 调用链

`选题诊断 → 包装任务 → 内容任务与论证简报 → 证据审计 → 段落逻辑检查 → 本人试读与风格校准 → 事实/合规检查 → 传播诊断 → 发布`。

AI 可以提出结构和改写候选，但不得虚构经历、来源、数据或替本人承担观点。

## 停止条件

关键事实未核、选题未通过、标题承诺正文无法兑现、产品或用户前提缺失时停止，不用文案技巧掩盖上游问题。
