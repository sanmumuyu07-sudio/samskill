# 模块 12｜传播、信任与影响力 Skill-ready 运行包

## 一、前置质量门

必须有发布内容或内容方案、目标用户处境、核心判断、传播任务和现实结果入口。

没有下游数据时只诊断到最早可见节点，禁止推断交易失败原因。

## 二、传播链等级

R0被分发；R1正确用户进入；R2理解核心判断；R3暂时相信；R4愿意带走或转发；R5在现实任务中行动；R6形成持续关系、机会或交易。

高R0不自动等于高R6。

## 三、十二张原子的调用合同

| 原子 | 触发／质量门 | 输出 | 路由 |
|---|---|---|---|
| 001 传播非自动扩散 | 发出但无人反应 | 分发、选择、理解、行动分层 | PLAT／DATA |
| 002 内容存在理由 | 内容只为日更 | 用户获得信息、判断、表达、关系或行动价值 | TOPIC |
| 003 停留相信转发 | 指标混为一个“共鸣” | 三种行为各自机制和证据 | HOOK／SCRIPT |
| 004 信息与情绪密度 | 只堆干货或煽情 | 事实变化与情绪变化地图 | SCRIPT |
| 005 集体情绪 | 声称击中“集体潜意识” | 共同处境、目标受阻、对象和异质样本 | USER |
| 006 身份认同 | “这说的是我” | 当前、希望、害怕身份与证据 | USER／POS |
| 007 共识反共识 | 只靠反对制造冲突 | 原共识、失效条件、替代解释、举证 | SCRIPT |
| 008 社会证明 | 粉丝、销量、案例混用 | 证明层级、样本、利益关系 | CONV |
| 009 稳定表达 | 重复同一句口号 | 稳定命题、变化案例、记忆入口 | POS／TOPIC |
| 010 信任三面 | 只展示能力或真诚 | 能力、诚意、一致性证据和反证 | OFFER／CONV |
| 011 影响力行动 | 有播放无现实机会 | 判断—触发任务—行动—承接链 | CONV |
| 012 高传播无商业 | 把问题全归流量 | 正确人群、任务、入口、产品、销售、交付六断点 | OFFER／CONV／DATA |

## 四、判断优先级

先查分发与口径，再查相关性、理解、信任、带走、行动和承接。不得看到低成交就直接修改开头；也不得看到高转发就宣布形成商业影响力。

## 五、工具合同

- T01 记录六节点和首个证据断点；写入 `spread.chain`。
- T02 群体判断至少跨来源；单评论只算线索；写入 `spread.group_hypothesis`。
- T03 能力、诚意、一致性分别审计，社会证明不得跨层；写入 `trust.audit`。
- T04 以内容批次追踪关系、机会、交易和非交易价值；写入 `influence.results`。

## 六、案例矩阵

奔驰销售话术说明身份与希望能形成记忆和互动，不证明直播互动等于购车；催婚内容说明共同处境会形成情绪共鸣，不证明情绪内容都能变现；叁木地产留学说明垂直内容可稳定连接咨询，但销售交付仍是独立系统；高播放泛情绪内容无咨询是传播与商业错位反例。

## 七、金样本

### 输入

> 一条视频一百万播放、十万点赞，但没有咨询，为什么？

### 标准结论

当前只能确认传播上游较强，不能只凭两项数据判断没有商业价值。先补流量来源、用户评论、主页访问、关注、私信、产品入口和观察窗口。

### 六类断点

错误用户、内容任务停在情绪表达、账号承诺不清、没有行动入口、产品不匹配、销售交付未承接。

### 动作

用 T01 找第一断点；若正确用户没有主页行动，查内容与入口；若有咨询无成交，转模块15，不重写爆款本身。
