# 证据角色审计表

| 材料 | 来源 | 类型 | 回答的质疑 | 可支持什么 | 不能支持什么 | 口径/条件 | 核验状态 |
|---|---|---|---|---|---|---|---|
|  |  | 事实/案例/数据/引用/类比 |  |  |  |  |  |

## 审计动作

1. 每个核心主张至少对应一条可追溯材料或明确标记为待验证判断。
2. 每条材料必须写“不能支持什么”。
3. 案例拆开项目条件、操盘者贡献、他人贡献与未知变量。
4. 数字写清时间、分母、平台字段和采集方式。
5. 类比只进入解释列，不进入证明列。

停止项：虚构、来源不可回查、口径混用、案例证明普遍规律、引用断章取义。
