# 群体情绪与身份证据卡

## 必填

- 共同处境：
- 目标受阻：
- 情绪指向什么对象：
- 用户如何自称、被称、想成为、怕成为：
- 评论、搜索、访谈、社群与现实资料：
- 反例与异质用户：
- 内容站在什么位置：
- 可能制造的排斥或羞耻：

## 证据等级

单条评论只算线索；同一评论区重复算局部信号；跨账号、搜索、访谈和现实行为共同出现，才可提升为群体假设。未经抽样不能写“所有人”“大多数人”。

## 输出

处境—情绪—身份关系、证据状态、可表达句、不可越过的代表性边界。
