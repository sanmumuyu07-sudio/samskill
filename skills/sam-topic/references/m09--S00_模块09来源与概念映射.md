# 模块 09 来源与概念映射

## 研究范围

用户任务、顾客语言、广告测试、公共意见、注意力、创新扩散、对标机制、叁木选题池和跨项目咨询记录。

## 核心映射

| 来源 | 支持关系 | 不支持结论 |
|---|---|---|
| JTBD | 选题可围绕用户处境和进展组织 | 每个用户只有一个任务 |
| 科学广告 | 传播主张应接受市场反应测试 | 点击高就证明产品价值 |
| 公共意见 | 人通过可理解的图景认识复杂现实 | 创作者可随意替用户发言 |
| 注意力稀缺 | 相关性与筛选成本重要 | 刺激越强越好 |
| 创新扩散 | 不同阶段需要不同信息与证明 | 所有人严格线性前进 |
| 叁木项目 | 多源选题、系列和结果回填可运行 | 固定分数与配比普遍有效 |

## 历史修正

- 三维打分改为证据卡，不用总分掩盖致命问题。
- “情绪关键词”只能作为表达材料，不能冒充用户需求。
- 流量、专业、核心等分类保留任务差异，比例按阶段动态生成。
- 选题标题与选题研究分开；标题转模块10。
- 热点只有连接长期问题和正确用户才进入选题池。

## 边界

本模块产出选题研究卡、选题池和回填规则。

标题开头转10；论证与脚本转11；传播检验转12；数据实验转14。
