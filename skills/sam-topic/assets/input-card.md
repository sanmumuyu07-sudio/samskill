# 选题判断输入卡

## 这个 Skill 帮你解决什么

判断一条内容为什么现在值得存在，能否支撑传播、信任、关系或业务任务，并形成可以进入写作的选题卡。

## 最少提供这些

1. 写给谁，对方正在经历什么。
2. 希望改变什么理解或行动。
3. 已有事实、案例、数据、亲历或用户语言。
4. 准备提出什么不同于旧解释的判断。

## 有这些材料会更准确

- 人群、定位与内容战略结论。
- 评论、咨询、搜索与对标样本。
- 产品和内容最终承接。
- 作者可公开的经历和证据。

## 没有材料时会怎样处理

给出补证或淘汰结论。

不因话题热门直接放行，不把抽象观点当完整选题。

## 你会得到什么

1. 放行、补证或淘汰。
2. 旧解释、关键缺口和核心判断。
3. 证据、反例与边界。
4. 唯一内容任务。
5. 标题方向和脚本简报。
