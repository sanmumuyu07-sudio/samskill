# 内容创作输入卡

## 这个 Skill 帮你解决什么

把已经成立的选题、证据和作者判断写成结构完整、承诺兑现、能够传播且可以审计的内容初稿。

## 最少提供这些

1. 写给谁，希望改变什么理解或行动。
2. 核心判断、已有证据和最大反驳。
3. 发布载体、预期长度和作者可用经历。
4. 不能改变的事实与表达。

## 有这些材料会更准确

- 已通过的选题卡和研究材料。
- 作者风格卡与正反样本。
- 用户语言、案例、数据和引用来源。
- 产品承接与内容最终行动。

## 没有材料时会怎样处理

先指出缺少的内容决策包。

能暂定时给框架与大纲；核心判断和证据未成立时，不用修辞掩盖问题。

## 你会得到什么

1. 内容决策包检查。
2. 二到三个框架候选与推荐。
3. 完整大纲。
4. 标题、封面和开头。
5. 完整初稿与待确认项。

## 可以直接复制

> 使用 `$sam-write` 完整创作。写给【】，希望改变【理解或行动】，核心判断是【】，证据与案例是【】，最大反驳是【】，发布到【平台／载体】，长度约【】，作者可用经历和风格卡在【】。
