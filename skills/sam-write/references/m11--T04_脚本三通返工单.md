# 脚本三通返工单

## 第一通｜判断与证据

结论、对象、条件、证据、反例和来源是否完整。失败则退回选题或论证。

## 第二通｜结构与理解

开头承诺、段落推进、概念解释、案例任务和结尾是否一致。失败则重排结构，不先润色。

## 第三通｜口播与发布

本人试读、字幕画面、合规、事实终核和单一行动是否通过。失败只改表达与制作，不擅自改核心观点。

- 修改动作：
- 必须保留：
- 停止项：
- 可发布条件：
- 发布后回填字段：
