# 运行合同

## 本 Skill 解决什么

把真实问题、作者判断和证据编码成读者听得懂、愿意继续、能记住且可以兑现承诺的完整内容。

## 三种入口

### A｜快速判断

用户材料足够，直接输出结论、主问题、行动和验收，不重复问卷。

### B｜引导建模

用户有真实项目但材料不足。每轮最多两个问题，直到能区分一个主结论和替代解释。

### C｜材料处理

用户给出文件、数据、链接或历史状态。先列已读范围、可用事实和缺口，再运行判断。

## 入口问题

1. 这条内容给谁看、希望改变什么理解或行动？核心判断、已有证据和最大反驳分别是什么？
2. 发布载体、预期长度、作者可用经历和已确认风格卡是什么？哪些事实与表达不能改？

问题只在答案会改变结论、行动或风险时提出。

## 判断顺序

1. 确认选题卡和证据是否达到写作门。
2. 先写任务句、主张、理由、证据、限定和异议。
3. 选择与任务匹配的结构，不机械套PAS或金字塔。
4. 先给大纲并标段落任务。
5. 完成标题、开头、正文、案例、反驳、动作和收束。
6. 执行事实、逻辑、理解、口播和作者声音初检。

## 最低通过条件

- 有唯一核心判断。
- 有目标用户当前理解。
- 重要事实与案例来源可追溯。
- 有作者真实材料或明确不使用第一人称。
- 标题承诺能由正文兑现。

## 标准输出

1. 内容决策包检查。
2. 完整大纲与段落任务。
3. 标题、封面文字和开头候选。
4. 完整初稿，不因时长默认删减关键论证。
5. 事实、案例和边界标记。
6. 仍需作者确认和发布前审计项。

## 回退

- 缺选题，转 sam-topic。
- 缺证据，转 sam-research。
- 缺作者规则且要求高度还原，转 sam-style。

## 下一入口

- 已有完整初稿需要精修，转 sam-edit。
- 准备发布，转 sam-audit。
- 需要进入团队生产，转 sam-operations。

## 停止条件

- 关键事实无法取得，且不同答案会改变本轮行动。
- 用户要求虚构事实、案例、收益、授权或用户心理。
- 任务涉及专业资质、敏感数据或高风险外部动作而缺少责任人。
- 当前 Skill 的最低条件未成立，需要回退到更早任务。

停止时仍交付：已确认、暂定结论、不能继续的原因、最少补充和下一入口。

## 历史系统防火墙
