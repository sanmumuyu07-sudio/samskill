# 生产与自然流运营输入卡

## 这个 Skill 帮你解决什么

把已经通过审计的内容变成可拍、可剪、可发布、可交接和可复盘的生产任务。

## 最少提供这些

1. 内容当前处于选题、脚本、待拍、待剪还是待发布。
2. 目标平台、频率和完成标准。
3. 负责人、执行者与审批者。
4. 工时、库存、设备、预算和后端承接能力。

## 有这些材料会更准确

- 已通过审计的最终稿与版本号。
- 拍摄场景、人员、素材和授权。
- 剪辑、字幕、标题、封面和简介规范。
- 历史返工、平台异常和产能数据。

## 没有材料时会怎样处理

先建立生产状态与缺口。

未经内容审计不进入最终发布，不在生产阶段静默重写方向。

## 你会得到什么

1. 生产状态与阻塞。
2. 拍摄、剪辑、包装与发布任务单。
3. 质量门、返工责任和异常回退。
4. 库存、产能与复盘字段。

## 可以直接复制
