# 平台业务匹配表

## 输入

业务目标、用户任务、产品路径、内容形态、团队产能、目标周期和风险行业。

## 七项评分

每项必须写证据，不只打分：用户可触达、分发入口、内容适配、信任建立、行动入口、商业承接、持续成本。

## 决策

- 主平台：七项没有致命冲突，且能承担完整验证。
- 次平台：提供不同入口或降低依赖，改编成本可控。
- 暂缓：用户或产品尚不清。
- 放弃：平台限制、合规或成本与目标冲突。

## 标准输出

主平台、次平台、证据、未知、每周资源、业务指标、三十天实验和退出条件。
