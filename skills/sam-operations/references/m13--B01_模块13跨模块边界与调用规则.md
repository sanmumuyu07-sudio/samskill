# 模块 13 跨模块边界与调用规则

## 本模块负责

任务进入、状态转换、角色分工、产能库存、三道质量门、自然流日常动作、交接和异常回退。

## 路由

- 选题、脚本、传播未通过：退模块 09—12。
- 平台规则和异常：模块 07。
- 数据结果和实验：模块 14。
- 销售承接过载：模块 15。
- AI、知识库、Skill 与权限：模块 16。

## Skill 调用链

`生产任务单 → 上游检查 → 脚本三通 → 拍摄登记 → 三道质量门 → 合规检查 → 发布登记 → 数据复盘 → 规则回填`。

新项目输入不足时先建立最小任务和状态，不一次性安装全部工具。团队交接必须包含 Skill 调用链、前置条件、输出格式和停止条件。

## 停止条件

事实、合规、权限或产品承诺存在高风险；产能超过质检和后端承接；无法追溯源文件时停止生产。
