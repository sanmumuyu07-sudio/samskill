# 模块 07 来源与概念映射

## 一、稳定层与时效层

稳定层解释平台为什么连接多边参与者、注意力为何稀缺、个性化推荐为何使用多类信号。

时效层记录当前规则、后台字段、产品功能和合规要求。

两层不能混写。

## 二、本地知识冲突审计

历史材料中以下说法不进入成熟原子：

- 固定冷启动流量池和逐级池人数。
- 全平台统一完播、收藏、铁粉权重。
- 永久不变的账号权重等级。
- 新号必须养号、一机一号或固定时段发布。
- 停更三至七天可以恢复限流。
- 抖音、小红书、视频号分别只有一种分发逻辑。

这些可以作为项目假设测试，不能作为平台事实教学。

## 三、来源映射

| 来源 | 支持关系 | 不支持结论 |
|---|---|---|
| 平台经济 | 平台连接多方并拥有规则与议价能力 | 所有平台算法相同 |
| 注意力稀缺 | 信息增加使筛选和竞争更重要 | 只做更短内容就能赢 |
| 官方推荐说明 | 推荐使用多类内容与行为信号并动态调整 | 可公开推导固定权重公式 |
| 官方规则 | 规则分场景且持续修订 | 电商规则自动适用于全站 |
| 本地项目 | 能比较具体平台、账号和内容结果 | 单一项目可概括全平台 |
