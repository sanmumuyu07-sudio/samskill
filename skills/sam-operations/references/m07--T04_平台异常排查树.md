# 平台异常排查树

## 输入

异常定义、发生时间、至少五条前后样本、流量来源、账号通知、操作记录和历史基线。

## 路径

1. 字段是否延迟、变更或统计错误。
2. 是否只有单条内容异常。
3. 题目、包装、长度或人群是否变化。
4. 是否收到官方审核、违规或权限通知。
5. 账号资料、设备、发布工具或权限是否变化。
6. 是否存在同期平台功能或规则变化。

## 输出

已确认事实、排除项、最可能层级、所需补证、当前动作和复查时间。

有官方处罚时优先官方整改申诉；不提供规避审核方案。
