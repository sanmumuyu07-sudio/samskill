# 模块 07 跨模块边界与调用规则

## 默认 Skill 调用链

```text
定位文档（模块06）
→ 平台业务匹配
→ 账号基础设置
→ 规则与字段登记
→ 冷启动基线
→ 选题和内容生产（模块09—13）
→ 数据实验（模块14）
→ 线索与交易（模块15）
```

## 降级入口

- 只有低播放：先用异常排查树，不重做全平台方案。
- 没有后台数据：建立手工基线，结论标低置信。
- 平台规则无法核验：只给风险清单，不给确定操作。
- 定位和产品未定：转模块04—06。

## 本模块不负责

具体选题、文案、拍摄、销售与交付。

## 标准输出

当前平台结论、数据口径、规则状态、第一断点、动作、停止条件和下一模块。
