# 模块 10 来源与概念映射

| 来源 | 吸收 | 排除 |
|---|---|---|
| 科学广告与奥格威 | 标题应指出相关利益、新闻或具体问题并接受测试 | 历史印刷广告比例直接外推短视频 |
| 信息缺口 | 已知与未知之间的缺口可能激发好奇 | 所有开头都必须隐藏答案 |
| 前景理论 | 损失与参照点可能影响选择 | 恐吓一定有效且合理 |
| 外部标题工具 | 先诊断正文、开头独立、兑现检查 | 固定五秒、必须悬念、越宽越好 |
| 叁木项目 | 身份、处境、冲突和证据可形成入口 | 公式命中数量等于质量 |

## 历史修正

“黄金三秒”改为尽快完成相关性确认，不设统一秒数。

“悬念不说答案”只适合部分内容；教程、风险、公共事实和明确结论可以直接说答案，再解释为什么。

“扩大话题”改为扩大可理解入口，同时保留正确人群和商业边界。

## 边界

本模块只负责包装与开始。选题不成立转09，正文不成立转11，传播与商业错配转12、15。
