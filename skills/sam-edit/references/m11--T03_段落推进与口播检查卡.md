# 段落推进与口播检查卡

## 段落检查

为每段填写：回答什么、与上一段什么关系、引出什么疑问、删掉会损失什么。

只剩“写得很好”却说不出任务的段落，优先删除。

## 口播检查

- 一口气是否承担过多关系。
- 指代是否明确。
- 概念是否马上解释。
- 转场是否靠逻辑而非连接词。
- 本人是否会这样说。
- 画面和字幕承担了什么信息。

## 输出

段落关系图、跳步、重复、口播卡点、真实改词与保留原因。

本人试读后的临时改词不能直接丢弃，应进入风格校准记录；连续出现三次再升级为稳定规则。
