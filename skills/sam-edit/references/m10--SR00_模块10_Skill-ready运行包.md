# 模块 10｜标题、封面与开头 Skill-ready 运行包

## 一、前置质量门

必须输入已通过资格的选题卡、平台展示场景、正文核心判断和目标行动。

选题未通过、核心判断无证据或正文不存在时，不靠包装补救，退回模块09／11。

## 二、包装等级

H0：只追求刺激；H1：相关但承诺模糊；H2：相关、准确、可兑现；H3：三元素分工清楚；H4：经过对照并能稳定吸引正确用户。

## 四、包装放行五门

相关、真实、可兑现、可理解、与行动一致。任一项致命失败不放行。

没有通用“三秒阈值”；优先使用账户基线、同类内容中位数、平台展示方式和正确用户质量。

## 五、工具与案例

- T01 写三元素不同任务；输出写入 `content.packaging`。
- T02 每个承诺必须标正文兑现位置；无位置即删除或补证。
- T03 六类候选按相关、真实、兑现、口播和用户一致性筛 Top3。
- T04 平台无法随机分流时标“顺序对照”，不报严格因果。

案例：奔驰销售话术支持身份与希望能形成记忆入口，不能证明所有产品应靠身份刺激；助眠产品故事支持情绪入口，不能替代产品效果证据；夸张动作获得停留但引来错误用户属于失败案例。

## 六、金样本

### 选题

很多人做个人 IP，第一步就做错了：先想人设。

### 候选标题

“个人 IP 最先做的，不是找人设。”

### 封面

主信息：“别先做人设”。副信息：“先找真实任务”。

### 开头

“个人 IP 和一人公司这两年越来越火，但大多数人一上来就在想：我该演一个什么样的人。这个顺序错了。陌生人不会因为你给自己起了一个身份就相信你，他们先看你能不能解释并解决一件真实的事。”

### 兑现要求

正文必须解释任务、证据、角色如何形成定位，不能只重复“不要做人设”。
