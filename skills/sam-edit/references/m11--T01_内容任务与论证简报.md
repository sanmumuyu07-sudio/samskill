# 内容任务与论证简报

## 输入

选题、用户当前理解、希望形成的判断或行动、已有材料、发布形式。

## 步骤

1. 完成任务句：“让____从____走到____，并完成____。”
2. 写唯一核心主张，不超过两个从属判断。
3. 登记根据、推理连接、限定和最强异议。
4. 选择结构：判断、问题、故事、清单或比较，并说明为什么。
5. 给每段标注信息任务。

## 分支

- 用户不知道问题：先呈现处境与后果。
- 用户知道问题但结论有争议：先明确主张与证据。
- 主要价值来自经历：用故事，但必须落回判断。

## 停止条件

选题未通过；主张无证据；一条内容承担多个独立任务；只能靠夸张成立。

## 标准输出

任务句、论证五件套、结构理由、段落任务表、删减项和下一步。
