# 内容改稿输入卡

## 这个 Skill 帮你解决什么

找到已有稿件第一处实质问题，在保留作者原意、事实和声音的前提下完成有理由的修改。

## 最少提供这些

1. 完整初稿。
2. 目标用户与发布任务。
3. 你最不满意的地方。
4. 必须保留的事实、观点、案例与表达。
5. 是否允许重构大纲。

## 有这些材料会更准确

- 修改前后样本与作者风格卡。
- 原始研究、案例和引用来源。
- 发布平台与时长要求。
- 用户或团队给过的具体负反馈。

## 没有材料时会怎样处理

只对现有文本做可证实的诊断。

不擅自改变作者立场、事实、身份和产品承诺。

## 你会得到什么

1. 稿件结论与第一断点。
2. 保留、删除、补证与重写清单。
3. 结构调整理由。
4. 完整改稿或标记稿。
5. 实质改动与作者待确认。

## 可以直接复制

> 使用 `$sam-edit` 修改这份稿件【文件／正文】。写给【】，发布任务是【】，我最不满意【】，必须保留【】，允许【局部修改／重构大纲】。
