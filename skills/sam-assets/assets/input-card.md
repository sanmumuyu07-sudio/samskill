# AI 与数字资产输入卡

## 这个 Skill 帮你解决什么

把成熟任务、资料、案例、反馈和规则变成 AI 或团队可调用、可更新、可追溯和可交接的数字资产系统。

## 最少提供这些

1. 想让 AI 或团队接手的现实任务。
2. 当前人工流程、输入、输出、错误成本和验收标准。
3. 真源、版本、权限与反馈位置。
4. 哪些发布、承诺和外部动作必须由谁批准。

## 有这些材料会更准确

- 当前 SOP、Brief、模板、正反例和历史返工。
- 文件夹结构、命名、版本与来源。
- 团队角色、权限和审批流程。
- 真实有效输出与失败样本。

## 没有材料时会怎样处理

先诊断任务成熟度和资料缺口。

方法尚不稳定时不急着做 Skill；先保存任务、判断、正反例和反馈。

## 你会得到什么

1. 任务与成熟度诊断。
2. 人机权限表。
3. Brief 与最小上下文包。
4. 真源、索引、版本和资产结构。
5. 反馈规则、回退与团队交接。
