## 使用规则

1. 不因单条爆款升级为稳定框架。
2. 不跨账号、平台、作者和商业任务静默复用。
3. 保留失败版本、异常事件和包装差异。
4. 框架、形式、标题开头和商业承接分别记录。
5. 每次升级或废止必须写证据与生效日期。
