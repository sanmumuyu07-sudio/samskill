# 负反馈转规则卡

记录：原任务、错误输出、具体不满意处、造成后果、错误发生在哪一层、正确样例、反例、适用范围、检查信号、修正动作、是否重复出现、进入提示词／工具／原子／案例的哪一层。

## 晋级规则

偶发偏好先记项目备注；可复现错误写成检查规则；跨项目稳定关系才进入原子；需要固定输入、分支和输出的规则才进入 Skill。

## 停止条件

无法说明“错在哪里”、只有情绪评价、样本互相冲突或原因尚未定位时，不升级成全局规则。
