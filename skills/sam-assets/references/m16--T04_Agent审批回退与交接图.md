# Agent 审批、回退与交接图

## 每个节点登记

输入产物、调用原子、调用工具、AI 可执行动作、人要确认的判断、输出文件、失败信号、回退节点、状态保存位置和下一路由。

## 三道审批门

1. 方向门：定位、产品承诺、目标用户和研究问题由人确认。
2. 发布门：事实、风险、隐私、平台合规和最终表达由人确认。
3. 外部动作门：发布、发送、付款、删除和覆盖真源必须明确授权。

## 交接包

当前状态、规则理由、正反例、未决问题、权限范围、最近失败、下一步和复盘字段。

只有步骤没有判断理由的 SOP，不算完成交接。
