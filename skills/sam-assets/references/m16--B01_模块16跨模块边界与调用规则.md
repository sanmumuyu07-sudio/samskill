# 模块 16 跨模块边界与调用规则

## 本模块负责

人机分工、Brief、上下文、知识资产、规则沉淀、Skill 与 Agent 编排、审批回退和团队交接。

## 不替代的上游判断

市场与业务回模块 02、04；用户与定位回 05、06；平台和对标回 07、08；内容制作回 09—13；数据和交易回 14—15；执行阻力和学习循环转模块 17。

## 新用户入口

先用 `SAM-AI-TOOL-001` 判断任务是否适合交给 AI。输入不足时，只生成缺失清单和最小 Brief，不直接生成最终方案。

## Skill 调用链

`任务识别 → 阶段路由 → 读取项目状态 → 装载相关原子与案例 → 生成 Brief → 调用工具执行 → 人工审批 → 保存产物与状态 → 结果回填 → 负反馈升级规则 → 用固定样本复测`。

这条链按任务动态裁剪，不要求每次跑完 17 个模块。

## 停止条件

真源不明、权限不明、外部副作用未授权、证据不足却要求确定结论、输出不可回退、项目存在冲突版本时暂停。
