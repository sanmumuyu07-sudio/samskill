# 现实任务与阶段诊断表

填写：你要在现实中完成什么；服务谁；最晚何时；已有材料；必须产生什么可检查产物；谁会看到或使用；当前在研究、准备、生产、发布、验证还是迭代；最后一次真实动作；当前断点。

## 四种结论

1. 没有任务：先定义一个作品、一次访谈、一次发布或一次交易实验。
2. 任务存在但输入不足：列最小取证动作。
3. 输入足但路径断：拆下一步和验收标准。
4. 路径清楚仍回避：再检查风险、身份解释和支持条件，不先贴标签。

标准输出必须包含下一动作、完成证据、截止时间和回填位置。
