# 模块 17 跨模块边界与调用规则

## 本模块负责

现实任务、知行断点、最小动作、首次反馈、失败学习、项目复盘、经验入库和长期防重启。

## 路由

目标模糊先回模块 03；市场、产品、用户和定位问题回 02、04—06；不知道内容怎么做回 08—13；已有数据却不会判断回 14；成交交付问题回 15；AI 与知识资产执行回 16。

## Skill 调用链

`现实任务登记 → 阶段判断 → 主要断点审计 → 选择相关原子与工具 → 生成最小动作 → 设置情境触发 → 产出作品 → 接触现实反馈 → 事实与情绪分离 → 更新判断 → 写回项目和原子库 → 设下一次检查`。

## 停止条件

任务并非本人选择、资源约束未解决、专业风险、持续情绪或健康问题影响功能、安全风险、要求以心理诊断代替业务取证时停止并分流。
