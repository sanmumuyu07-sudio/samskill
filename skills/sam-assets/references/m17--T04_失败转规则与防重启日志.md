# 失败转规则与防重启日志

记录：原目标、实际动作、结果、事实、情绪、原假设、主要断点、可控变量、不可控变量、本轮学到的关系、下一轮只改什么、保留什么、停止什么、写回哪个原子或项目文件。

## 防重启四问

这是新证据还是旧焦虑？旧路径失败还是整个方向失败？哪些资产可以保留？达到什么证据才允许换方向？

没有新证据时，不因短期情绪重建整套系统；同一失败重复两次，必须升级规则或改变实验。
