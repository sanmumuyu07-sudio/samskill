# 知行断点审计表

依次检查：不知道做什么；不知道怎样做；任务过大；缺时间、钱、权限或合作；害怕评价或损失；标准冲突；把学习和讨论当作完成；目标并非本人真实选择；持续情绪或健康问题。

## 输出规则

每次只认定一个主要断点和一个次要断点，并列支持事实、反证、需要补的输入、下一动作和停止条件。

无法从行为证据区分时，输出“信息不足”，不能用心理术语补空白。持续痛苦、功能受损或安全风险转专业支持。
