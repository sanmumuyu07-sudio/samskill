# 七天第一次反馈计划

## 七个动作，不固定七种形式

1. 定义现实任务与完成证据。
2. 整理现有资产和缺口。
3. 选一个用户问题并取证。
4. 做出最小内容或产品样本。
5. 让一个真实对象看到、使用或评价。
6. 发布、发送、试卖或执行一次。
7. 回填结果，只改一个主要变量进入下一轮。

每天写：输入、产物、用时、失败分支和明日动作。行业反馈周期更长时，七天只要求完成第一次外部接触，不虚构结果。
