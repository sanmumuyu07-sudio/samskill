# 模块 16｜AI 协作、数字资产与团队交接 Skill-ready 运行包

## 一、质量门

必须有现实任务、方法成熟度、错误成本、责任人、输入位置、验收标准和回退方式。没有这些，不因安装 AI、Agent 或 Skill 自动进入系统化。

## 二、人机权限等级

A0只建议；A1生成候选；A2在沙箱或草稿执行；A3经人审批后外部执行；A4低风险、可回退、规则稳定的自动执行。付款、发布、删除真源、合同、对外承诺和敏感数据不默认A4。

## 四、数字资产最低标准

有稳定名称与唯一位置；能追溯来源；能按任务检索；有版本和状态；有适用边界；能被再次调用；反馈能写回；权限明确。缺三项以上只是文件集合。

## 五、工具合同

- T01按错误成本、外部副作用和可回退性分A0—A4。
- T02只给本轮所需上下文；冲突文件标真源与优先级。
- T03偶发偏好不升全局规则，跨项目稳定关系才进原子。
- T04三道审批门：方向、发布、外部动作；交接必须独立试运行。

## 六、案例矩阵

地产留学支持AI降低搜集、整理和生产成本，不证明AI完成产品销售；叁木知识库说明文件夹经过真源、索引、规则与状态才能成为资产；团队机械模仿失败说明SOP没有传递判断；AI批量生成低质内容是速度放大错误的反例。

## 七、金样本

输入：“把我的知识库全部做成一个Skill，自动帮用户做完整自媒体方案。”

输出：不建议单Skill全量加载。先定义具体使用场景，例如新项目阶段诊断；SKILL.md只保存触发、模式、问卷、分流、输出与状态协议；原子正文按需进入references；固定校验用脚本；高风险结论保留人工审批。知识库当前缺口未补齐时，Skill必须降级而非自由补全。
