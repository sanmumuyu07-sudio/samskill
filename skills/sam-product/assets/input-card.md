# 产品与变现输入卡

## 这个 Skill 帮你解决什么

把能力、经验、资料或服务变成用户能选择、你能交付、双方能验证的产品。

## 最少提供这些

1. 帮谁在什么处境下完成什么变化。
2. 当前产品、价格和交付方式。
3. 已有咨询、预约、付款或交付证据。

## 有这些材料会更准确

- 产品页、付款页与合同。
- 用户咨询、拒绝、退款与反馈。
- 单个用户所需时间、人员和直接成本。
- 交付流程、里程碑与用户责任。

## 没有材料时会怎样处理

形成最低产品假设和验证计划。

不替用户决定价格、结果承诺和真实性。

## 你会得到什么

1. 产品阶段。
2. 有限结果承诺与不承诺。
3. 最低完整产品与交付机制。
4. 价格任务、成本、容量和退款风险。
5. 继续、停止和回退条件。
