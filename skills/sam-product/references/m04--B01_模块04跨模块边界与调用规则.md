# 模块 04 跨模块边界与调用规则

## 本模块负责到哪里

负责：

- 产品结果承诺。
- 人群与场景适配。
- 能力产品化。
- 价格任务与单位经济。
- 产品阶梯和交付边界。
- 最小产品验证。

## 不负责什么

- 市场是否值得进入：模块 02。
- 能力是否真实存在：模块 03。
- 用户语言与深度研究：模块 05。
- 定位与品牌表达：模块 06。
- 销售、私域和成交：模块 13。
- 团队岗位与产能：模块 15。
- 合同、税务、资质与专业法律意见：外部专业审查。

## 新用户入口

### 没有产品，只有能力

先回模块 03 完成能力证据，再调用 `T01`。

### 已有产品但卖不动

先判断：

1. 无真实任务，转模块 05。
2. 承诺不清，调用 `T01`。
3. 价格与成本不清，调用 `T02`。
4. 触达和销售问题，转模块 12—13。

### 有成交但交付失控

调用 `T03` 和 `SAM-OFFER-009`。

### 有多个产品但彼此混乱

调用 `SAM-OFFER-008` 与 `T03`。

## 输入不足时降级

- 没有用户证据：只输出假设，不给确定产品结论。
- 没有成本：不建议定价，只建立成本采集表。
- 没有成交：最高标 P2，不写“产品已验证”。
- 没有使用结果：付款证据保持 P3。

## 默认 Skill 调用链

本原子库目前是 Skill 的知识底座，不直接执行外部 Skill。

后续产品诊断 Skill 必须按以下顺序调用：

```text
阶段入口
→ 个人资产与市场前置检查
→ 结果承诺与价值适配
→ 价格成本与交付边界
→ 最小验证实验
→ 保存项目状态
→ 根据断点路由到用户、销售或团队模块
```

禁止跳过前置输入，直接生成产品矩阵与价格。

## 停止条件

- 高风险业务缺少资质和专业审查。
- 用户要求虚构案例、收入或稀缺。
- 产品结果主要由不可控第三方决定却要求保证。
- 数据口径不明仍要求确定利润判断。
