# 价格、成本与单位经济账

## 使用目的

防止只看标价、流水和同行价格，忽略用户总成本、交付容量与真实利润。

## 一、用户账

```text
实际支付：
学习／使用时间：
必须投入的行动：
主要风险：
放弃的替代方案：
预算与审批约束：
```

## 二、单客交付账

```text
制作与更新分摊：
答疑／咨询工时：
工具与平台：
场地／材料：
售后与退款预期：
第三方成本：
```

## 三、经营账

```text
获客成本：
销售成本：
渠道分成与支付费用：
税费：
固定成本分摊：
坏账与异常成本：
```

## 四、计算

```text
单客贡献 = 实收
- 获客与销售分摊
- 渠道和支付成本
- 边际交付成本
- 预期售后退款
```

经营者本人时间必须折算，不以“我自己做所以免费”处理。

## 五、容量压力测试

分别计算 10、50、100 位用户时：

- 峰值工时。
- 必须本人处理的问题。
- 回复时限。
- 质量下降点。
- 是否需要人员、工具或边界调整。

## 六、价格实验

每次只测试主要变量：

- 不同价格同一交付。
- 同一价格不同承诺。
- 同一承诺不同服务深度。

记录人群、来源、版本和时间，禁止混在一起得结论。

## 标准输出

- 价格承担的首要任务。
- 三本账。
- 单客贡献。
- 容量上限。
- 最大经营风险。
- 下一轮测试变量。
