# 最小产品验证实验卡

## 使用目的

让一次测试只回答一个主要问题，并提前写清成功、失败和停止条件。

## 实验卡

```text
本轮产品版本：
目标场景与用户：
主要假设：
为什么它最危险：
当前证据等级 P0—P5：
要取得的下一等级证据：
测试动作：
价格与交付：
样本来源：
时间窗口：
成功阈值：
失败阈值：
停止条件：
本测试不能证明什么：
```

## 可选测试

| 要验证的关系 | 合适动作 | 不能证明 |
|---|---|---|
| 问题是否发生 | 访谈、行为记录、搜索与替代方案 | 会购买 |
| 承诺是否被理解 | 页面测试、复述测试 | 能交付结果 |
| 是否愿意行动 | 预约、提交资料、候补 | 会付款 |
| 是否愿意付款 | 真实预售 | 会使用、会满意 |
| 是否能交付 | 小批付费试点 | 可规模化 |
| 是否可经营 | 多批次成本与留存 | 永久稳定 |

## 结果回填

```text
观察到的事实：
未观察到的事实：
与预期的差异：
可以保留的关系：
需要删除或修改的关系：
下一轮只改什么：
```

## 停止条件

- 为测试伪造稀缺、案例或订单。
- 把熟人支持混入自然购买不做标记。
- 高风险业务没有资质与伦理审查。
- 结果出来后才修改阈值。
