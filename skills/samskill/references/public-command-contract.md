# Samskill V2.3 用户命令与路由合同

用户无需记 Skill 名。以下短句既可以单独使用，也可以附带材料。

| 用户命令 | 目标 |
|---|---|
| 诊断项目 | 判断阶段、首个断点与当前优先任务 |
| 判断市场 | 判断赛道、需求、交易和进入条件 |
| 设计产品 | 设计产品任务、价格、交付与边界 |
| 明确定位 | 收束用户、公共角色、账号承诺与内容边界 |
| 深描人群 | 分析人群的现实处境、社会心理、决策、市场、内容和产品 |
| 人群图谱 | 按同一证据字段拆分多类人群，比较关系、市场价值与服务边界 |
| 拆解对标 | 研究账号、内容或商业案例的条件与机制 |
| 全景拆号 | 按人群、定位、内容、分发、承接、产品、商业、团队和结果完整拆解账号 |
| 研究问题 | 核验事实、概念、用户语言、案例与证据 |
| 规划内容 | 建立长期命题、栏目、内容组合与更新节奏 |
| 判断选题 | 判断一条内容为什么存在、是否值得做 |
| 选择框架 | 比较二到三个写作框架并推荐一个 |
| 完整创作 | 从大纲、包装到完整初稿 |
| 只做标题开头 | 只处理标题、封面文字和开头，审计正文兑现 |
| 参考改写／洗稿／原创重构 | 先判断是保留原稿内容与逻辑的参考型改写，还是借题建立新问题的独立原创重构 |
| 保留原稿改写 | 保留问题、核心判断、重点、功能结构和开头机制，适配当前作者真实材料 |
| 借题原创 | 研究参考机制，建立当前项目的新问题、新论证和独立贡献 |
| 快速判断参考 | 一屏内判断能不能参考、保留什么、改变什么和下一步 |
| 共创成稿 | 先确认对象、作者、独立材料和内容去向，再给大纲与新稿 |
| 研究审计重构 | 展开来源分层、差异矩阵、框架取舍和十维原创审计 |
| 修改文案 | 诊断已有稿并返工，不改变已确认事实 |
| 发布审计 | 审事实、逻辑、声音、原创、平台、隐私与承诺 |
| 安排生产 | 进入拍摄、剪辑、包装、排期、发布与互动 |
| 检查承接 | 检查主页、私信、线索、销售、交付与复购 |
| 数据复盘 | 找最早异常，设计下一轮单变量实验 |
| 沉淀资产 | 保存有效框架、版本、正反例、AI规则与团队交接 |

命令不改变质量门。

例如“只做标题开头”仍需正文核心判断；“洗稿”不自动等于从零原创，也不等于逐句换词。系统先判断任务模式，再执行相应权利与质量边界。

用户不需要每次先选菜单。系统根据用户想保留什么、权利状态和已有修改意见判断参考型改写或独立原创重构；只有选错会导致整篇返工时，才问一个模式问题。

已有项目状态和上游对标研究直接继承。只有内容对象、作者位置、独立材料或内容去向存在会改变稿件的歧义时，才最多追问两个问题。

多项命令同时出现时，先判断最早断点，只执行一个当前任务。
