# 路由合同

| 不知道项目阶段、多个问题混在一起、从零启动 | `sam-project-diagnosis` |
| 赛道、行业、市场、商业模式、线上线下增长 | `sam-business` |
| 产品、价值、价格、交付边界、知识库社群课程 | `sam-product` |
| 用户、定位、公共角色、账号承诺 | `sam-position` |
| 对标账号、商业案例、机制迁移，只做研究不需要成稿 | `sam-benchmark` |
| 陌生问题研究、事实核验、证据和案例 | `sam-research` |
| 长期命题、栏目、内容组合、更新节奏 | `sam-strategy` |
| 具体选题、角度、立场、选题池 | `sam-topic` |
| 建立作者风格卡、AI不像本人、团队表达漂移 | `sam-style` |
| 已有选题和材料，需要大纲与完整初稿 | `sam-write` |
| 已有初稿，需要诊断和修改 | `sam-edit` |
| 最终稿能否发布、事实逻辑承诺风险审计 | `sam-audit` |
| 生产、拍摄、剪辑、平台适配、发布和自然流运营 | `sam-operations` |
| 有流量没咨询、有咨询不成交、销售交付复购 | `sam-relationship` |
| 发布后数据、字段、异常、归因和下一实验 | `sam-retro` |
| AI协作、数字资产、Skill、Agent和团队交接 | `sam-assets` |
