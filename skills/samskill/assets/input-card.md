# Samskill 总入口输入卡

## 它帮你解决什么

当你不知道该先做市场、产品、定位、内容、运营还是复盘时，先找出当前最值得处理的一步，并立即开始。

## 最少提供这些

1. 你正在做什么项目。
2. 最近发生了什么结果，或眼前卡在哪里。
3. 你希望这次得到什么。

材料不完整也可以。

## 有这些材料会更准确

- 账号、产品页、内容、后台截图或数据。
- 用户咨询、成交、交付与退款记录。
- 之前已经确认的结论和不能改变的条件。

## 没有材料时会怎样处理

先形成暂定路由。

只问一个能决定入口的问题，不让你填写整套表。

## 你会得到什么

1. 当前先处理的任务。
2. 选择它的依据。
3. 随即进入对应专项 Skill 的第一步。

## 可以直接复制

> 使用 `$samskill` 帮我判断下一步。我正在做【】，最近发生【】，现在最卡【】，希望得到【】。已有材料是【】。
