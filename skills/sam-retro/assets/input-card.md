# 数据复盘输入卡

## 这个 Skill 帮你解决什么

核对平台和业务数据口径，找出最早异常，区分事实与解释，并设计下一轮单变量实验。

## 最少提供这些

1. 平台与时间窗口。
2. 内容版本、发布来源和本轮目标。
3. 后台字段名称、官方定义、截图或导出。
4. 同账号同类内容基线，以及相邻线索、成交或交付数据。

## 有这些材料会更准确

- 每条内容的框架、形式、包装和发布时间。
- 账号历史中位数与异常样本。
- 内容到线索、成交和交付的对应关系。
- 同期平台、预算、团队和产品变化。

## 没有材料时会怎样处理

只核对事实并建立基线。

没有字段定义、版本与可比窗口时，不做确定归因。

## 你会得到什么

1. 数据口径与可比性。
2. 事实层复盘与最早异常。
3. 候选解释、反证和置信度。
4. 下一轮单变量实验。
