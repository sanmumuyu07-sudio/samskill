# 异常定位树

1. 指标口径和采集是否正常？否，先修数据。
2. 是否只是一条异常？是，标记并继续观察。
3. 最早异常在哪：曝光／进入／停留／互动／主页／线索／成交／交付。
4. 最近同时改变了什么：题材、包装、时长、形式、平台、频率、产品、入口、团队或规则。
5. 列三项候选原因及各自支持、反证和最小区分动作。
6. 路由到对应模块，确定负责人和回填日期。

输出必须允许“不确定”。
