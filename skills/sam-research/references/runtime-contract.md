# 运行合同

## 本 Skill 解决什么

让内容的判断从证据和问题中长出来，而不是先写结论再搜索支持材料。

## 三种入口

### A｜快速判断

用户材料足够，直接输出结论、主问题、行动和验收，不重复问卷。

### B｜引导建模

用户有真实项目但材料不足。每轮最多两个问题，直到能区分一个主结论和替代解释。

### C｜材料处理

用户给出文件、数据、链接或历史状态。先列已读范围、可用事实和缺口，再运行判断。

## 入口问题

1. 这次研究最终要帮助谁改变什么理解或行动？你现在的候选判断和最大不确定是什么？
2. 已有材料有哪些？哪些事实必须核验，时间、地区、平台和来源要求是什么？

问题只在答案会改变结论、行动或风险时提出。

## 判断顺序

1. 把模糊话题拆成可核验子问题。
2. 先记录已有判断与证据责任，不把它当结论。
3. 按原始来源、官方资料、同行评议、一手用户材料和公开案例取证。
4. 建立F/O/I/H/U证据账本。
5. 寻找最强反例、适用边界和无法确认项。
6. 形成命题候选、证据角色与写作前缺口。

## 最低通过条件

- 研究对象和输出用途明确。
- 来源层级与时间范围明确。
- 重要数字有分母、口径和日期。
- 强主张至少有直接来源或降级为假设。

## 标准输出

1. 研究问题树。
2. 来源清单与证据等级。
3. 用户语言、案例和反例。
4. 事实、观察、解释、假设和未知。
5. 可写命题候选与成立边界。
6. 交给 sam-topic 或 sam-write 的内容决策包。

## 回退

- 研究目标服务哪个项目不清，回 sam-project-diagnosis。
- 需要拆特定账号，转 sam-benchmark。

## 下一入口

- 材料足够后判断选题，转 sam-topic。
- 选题已经确认且材料齐备，转 sam-write。
- 研究改变了市场或定位假设，回 sam-business 或 sam-position。

## 停止条件

- 关键事实无法取得，且不同答案会改变本轮行动。
- 用户要求虚构事实、案例、收益、授权或用户心理。
- 任务涉及专业资质、敏感数据或高风险外部动作而缺少责任人。
- 当前 Skill 的最低条件未成立，需要回退到更早任务。

停止时仍交付：已确认、暂定结论、不能继续的原因、最少补充和下一入口。
