# 内容研究输入卡

## 这个 Skill 帮你解决什么

把陌生问题研究成有来源、有反例、有边界，并能进入选题与写作的可靠命题。

## 最少提供这些

1. 想研究的问题。
2. 研究最终要帮助谁改变什么理解或行动。
3. 当前候选判断与最大不确定。
4. 时间、地区、平台和来源要求。

## 有这些材料会更准确

- 已有文章、论文、书籍、视频或数据。
- 用户原话、案例、争议与反例。
- 必须核验的事实和不能使用的来源。

## 没有材料时会怎样处理

先建立问题树与来源计划。

不把二手总结冒充原文，不用一个评论代表群体。

## 你会得到什么

1. 研究问题树。
2. 来源与证据等级。
3. 用户语言、案例、反例与边界。
4. 可写命题和内容决策包。

## 可以直接复制

> 使用 `$sam-research` 研究【问题】。这项研究要帮助【对象】改变【理解或行动】，我当前的判断是【】，最大不确定是【】，时间／地区／平台／来源要求是【】。
