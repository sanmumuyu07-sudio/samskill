# 公开输入输出

第一次使用、用户问“要提供什么”或材料不足时，完整读取 `assets/input-card.md`。

最终用户版交付完整读取 `assets/output-template.md`。

默认只展示用户可读结果，不把 `state_delta`、`handoff` 或 YAML 拼在报告正文后。

只有用户授权保存、跨 Skill 继续、团队交接或版本审计时，才生成机器状态。

先判断任务模式：参考型改写或独立原创重构。

参考型改写按 `reference-adaptation-contract.md` 选择快速判断、成稿或研究审计。

独立原创重构按 `output-contract.md` 选择快速判断、共创成稿或研究审计。

简单任务不得强行展开完整差异矩阵，也不得为了显得原创主动改掉原稿有效的内容任务与重心。
