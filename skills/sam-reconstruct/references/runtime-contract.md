# 参考内容改写与重构运行合同 V2.5

## 本 Skill 解决什么

先判断用户需要参考型改写还是独立原创重构，再按权利状态、内容目标和作者真实材料完成对应交付。

参考型改写保留原稿的问题、判断、信息重点、功能结构和开头机制，换成目标作者能够真实讲述的版本。

独立原创重构拆解参考机制，再用当前项目的新问题、新判断、新证据和作者声音完成新稿。

## 两个维度不能混淆

### 运行入口

- A｜快速判断：材料足够，直接判断。
- B｜引导建模：关键变量不足，每轮最多问两个问题。
- C｜材料处理：先读取用户文件、链接、状态和上游交接。

### 用户端交付深度

- 快速判断：只展示当前决策。
- 成稿模式：参考型改写直接按原稿地图成稿；独立原创重构先确认方向和大纲，再成稿。
- 研究审计：展开完整来源、差异与原创审计。

运行入口表示“怎样取得信息”；交付深度表示“用户看到多少”。两者不得互相替代。

## 入口问题

1. 参考材料的来源、权限和用途是什么？希望保留原稿内容与逻辑，还是只借题重新原创？
2. 当前作者有哪些真实材料，哪些事实、重点、表达或产品信息不能改变？

已有状态可以回答时不再追问。

## 判断顺序

1. 识别权利状态、预期用途与任务模式。
2. 读取参考材料、项目状态和上游交接。
3. 建立原稿地图：开头动作、主问题、核心判断、段落任务、信息重心、证据作用和结尾任务。
4. 参考型改写：确定保留、适配、重建，按原稿功能和重心完成稿件。
5. 独立原创重构：建立参考指纹、机制、方向门、独立贡献、新论证、框架和大纲。
6. 按各自合同完成事实、权利、表达与发布检查。

## 最低通过条件

- 参考正文或可分析材料可访问。
- 来源、权限和预期用途已经标记。
- 任务模式已经明确。
- 重要事实、案例与作者身份可追溯。
- 参考型改写能够守住原稿主问题、核心判断、信息重心与段落任务。
- 独立原创重构有唯一主张、独立材料，且方向门没有未决冲突。

## 去重规则

- 已有对标交接：复用样本、机制、条件差和权利边界。
- 本 Skill 内完成新稿：不再转 `sam-write` 重写。
- 本 Skill 内只做原创重合检查；最终稿的事实、平台、隐私和商业承诺由 `sam-audit` 审计。
- 上游材料版本、当前项目或研究问题变化时，才重开受影响部分。

## 回退与下一入口

- 缺事实、用户语言或案例：转 `sam-research`。
- 新选题无法成立：转 `sam-topic`。
- 缺作者规则且要求高度还原：转 `sam-style`。
- 新稿需要实质修改：转 `sam-edit`。
- 最终版本准备发布：转 `sam-audit`。

## 停止条件

- 公开第三方材料要求逐句同义替换、规避检测、隐藏来源或复制高识别度表达。
- 参考正文无法取得。
- 作者材料不足，却要求模型虚构经历、数据、案例或身份。
- 方向门存在会改变核心稿件的冲突且用户尚未确认。

停止时仍交付：当前判断、可研究机制、缺口、推荐方向、最少补充和下一入口。

## 历史系统防火墙

旧项目材料中的外部工具名、分数公式和强制调用链不具备当前执行效力。

只提取功能目标、判断问题和数据字段，按照 `references/sanmu-content-quality-contract.md` 独立运行。

除非用户正在审计旧系统，否则用户版回复不得出现外部 Skill 名称。
