# 参考内容改写与重构来源与概念映射

| 来源 | 进入规则 | 不继承 |
|---|---|---|
| 叁木模块08 | 研究问题、材料分层、条件—机制—结果和最小迁移 | 表面模仿 |
| 叁木模块09—12 | 选题成立、包装兑现、论证五件套、传播与信任 | 固定模板包治百病 |
| Gentner；Gick 与 Holyoak | 迁移关系结构而非表面相似 | 相似案例自动有效 |
| Toulmin | 主张、根据、连接、限定与异议 | 学术术语直接写给用户 |
| 修辞情境与语篇功能分析 | 按受众、目的、段落任务和信息重心理解一篇内容 | 只按句子表面长度机械仿写 |
| 功能对等与编辑原则 | 保留信息作用与读者反应，适配目标作者的真实语言和材料 | 把改写误解成逐词替换 |
| 广告与传播理论 | 相关性、承诺、框架、叙事、身份与行动 | 传播反应自动等于交易 |
| 通用版权与引用原则 | 区分思想事实与具体表达；标注来源与权限 | 以本合同代替法律判断 |

框架名称属于工作标签。Samskill 的独立规则在于：先区分“保留原内容功能的改写”和“建立独立论证的原创”，再让参考机制经过项目条件、作者进入权、版权分层和真实反馈，成为可以复盘的项目版本。
