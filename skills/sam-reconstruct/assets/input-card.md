# 参考内容改写与重构输入卡

## 这个 Skill 帮你解决什么

先判断这次需要保留原稿内容与逻辑的“参考型改写”，还是借参考材料建立新问题与新论证的“独立原创重构”，再按对应边界完成交付。

## 最少提供这些

1. 参考材料正文、转录或可分析片段。
2. 材料是自有、已授权、公开第三方还是来源不明，以及准备内部使用还是公开发布。
3. 这次更希望：保留原稿的内容和逻辑来改写，还是只借它的题重新写一篇原创。
4. 目标作者是谁，哪些身份、经历、案例、数据和产品信息是真实可用的。

## 有这些材料会更准确

- 当前项目的人群、定位、产品和风格卡。
- 作者自己的用户语言、失败经验和反例。
- 已完成的对标研究交接包。
- 希望保留的开头、观点、步骤、案例作用或结尾任务。
- 不能改变的事实、表达、重点和权利边界。

## 没有材料时会怎样处理

先判断任务模式并交付可开展的部分。

参考型改写缺少作者材料时，先标出需要替换的位置，不冒用原作者身份、经历或数据。

独立原创重构没有独立贡献时，不进入完整成稿。

不执行逐句同义替换、标志性表达复制和规避检测。

## 你会得到什么

1. 任务模式判断：参考型改写或独立原创重构。
2. 原稿地图与保留、适配、重建判断。
3. 参考型改写稿，或原创重构的方向、大纲和新稿。
4. 只列会影响发布的事实、引用、授权与风险。
