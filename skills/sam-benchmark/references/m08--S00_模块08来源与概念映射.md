# 模块 08 来源与概念映射

## 本地读取范围

叁木对标拆解流程、脱敏业务案例、专业服务街采案例、APQC 对标流程、类比迁移研究、现实主义评估和增长实验材料。

## 来源进入规则

| 来源 | 吸收 | 不继承 |
|---|---|---|
| APQC | 对标是识别与采用更好实践的结构化过程 | 企业流程可原样套个人账号 |
| Gentner、Gick 与 Holyoak | 类比迁移依赖关系结构，不只表面相似 | 找到相似案例就能迁移成功 |
| Pawson 与 Tilley | 条件—机制—结果解释 | 公开材料足以证明完整因果 |
| dbs-benchmark | 研究问题、资格过滤和证据谨慎 | 外部原创口吻、命名与产品结构 |
| 叁木项目 | 从内容到业务的完整研究节点 | 把单次成功写成普遍规律 |

## 输出边界

本模块产生研究任务、证据分级、机制假设和迁移实验。

不代替选题生产、脚本创作和数据实验；分别转模块09—11与14。
