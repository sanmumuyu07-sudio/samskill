# 运行合同

## 本 Skill 解决什么

从成功样本中提取可检验机制和成立条件，让用户少走弯路，但不把形式复制当成学习。

## 三种入口

### A｜快速判断

用户材料足够，直接输出结论、主问题、行动和验收，不重复问卷。

### B｜引导建模

用户有真实项目但材料不足。每轮最多两个问题，直到能区分一个主结论和替代解释。

### C｜材料处理

用户给出文件、数据、链接或历史状态。先列已读范围、可用事实和缺口，再运行判断。

## 入口问题

1. 你研究这个对象是为了回答什么项目问题？希望迁移内容、用户、产品、渠道还是商业机制？
2. 请提供对象材料、时间范围与可核验结果；你的项目在用户、资源、产品、平台和阶段上分别是什么条件？

问题只在答案会改变结论、行动或风险时提出。

## 判断顺序

1. 先定义研究任务和排除噪音。
2. 审查对象是否在目标、用户、业务阶段和结果上可比。
3. 把事实、推论、未知与公开来源分开。
4. 拆情境、机制、结果、资源和必要条件。
5. 比较当前项目的条件差与不可迁移项。
6. 设计一个不复制表达的最小机制迁移实验。

## 最低通过条件

- 研究问题明确。
- 至少三项可核验公开材料。
- 结果口径和时间范围已说明。
- 用户当前项目条件可比较。

## 标准输出

1. 对标资格结论。
2. 事实、推论与未知表。
3. 用户、内容、产品、商业和资源机制图。
4. 成立条件与反例。
5. 可迁移、不可迁移和需要改造。
6. 最小迁移实验与版权边界。

## 回退

- 不知道为什么找对标，转 sam-project-diagnosis。
- 市场和用户方向未定，转 sam-business 或 sam-position。

## 下一入口

- 迁移到栏目和内容组合，转 sam-strategy。
- 迁移到具体选题，转 sam-topic。
- 迁移到产品，转 sam-product。

## 停止条件

- 关键事实无法取得，且不同答案会改变本轮行动。
- 用户要求虚构事实、案例、收益、授权或用户心理。
- 任务涉及专业资质、敏感数据或高风险外部动作而缺少责任人。
- 当前 Skill 的最低条件未成立，需要回退到更早任务。

停止时仍交付：已确认、暂定结论、不能继续的原因、最少补充和下一入口。
