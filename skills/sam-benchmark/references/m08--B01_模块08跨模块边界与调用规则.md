# 模块 08 跨模块边界与调用规则

## 默认 Skill 调用链

```text
当前项目诊断
→ 研究任务卡
→ 对标资格审查
→ 材料分层与取样
→ 事实/推断/未知/假设
→ 条件—机制—结果
→ 迁移卡
→ 最小实验
→ 数据复盘（模块14）
→ 回填原子库
```

## 路由
