# 对标与机制迁移输入卡

## 这个 Skill 帮你解决什么

判断一个账号、内容、产品或商业案例是否值得研究，拆出成立机制，并转成当前项目能验证的动作。

## 最少提供这些

1. 对标链接、正文、截图或转录。
2. 想回答的项目问题。
3. 研究单条内容、单账号全景还是多账号比较。
4. 自己项目的用户、资源、产品、平台和阶段。

## 有这些材料会更准确

- 明确时间窗口内的近期、常态、高表现与商业样本。
- 对标产品、价格、主页、私域和交付材料。
- 可核验的数据、公开采访与团队信息。
- 自己项目的基线与约束。

## 没有材料时会怎样处理

只做资格筛选与取样计划。

单条内容不能外推账号全貌，粉丝与播放不能直接证明利润。

## 你会得到什么

1. 对标资格与取样质量。
2. 人群、定位、内容、分发、承接、产品、商业和资源机制。
3. 成立条件、替代解释和不可推出项。
4. 可迁移、需改造与不可迁移。
5. 最小实验。

## 可以直接复制

> 使用 `$sam-benchmark` 【全景拆解／单条拆解／多账号比较】这些材料【链接或文件】。我要回答的问题是【】，研究窗口是【】，我的项目条件是【用户／产品／平台／资源／阶段】。
