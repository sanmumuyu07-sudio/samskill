# 运行合同

## 本 Skill 解决什么

把作者真实且稳定的表达选择变成可以执行、举反例、验证和持续更新的规则。

## 三种入口

### A｜快速判断

用户材料足够，直接输出结论、主问题、行动和验收，不重复问卷。

### B｜引导建模

用户有真实项目但材料不足。每轮最多两个问题，直到能区分一个主结论和替代解释。

### C｜材料处理

用户给出文件、数据、链接或历史状态。先列已读范围、可用事实和缺口，再运行判断。

## 入口问题

1. 请提供至少3份你认可的真实样本和1—3份你不认可或修改过的样本，并说明用途。
2. 你最希望保留的判断方式是什么？哪些AI常见表达、词语、结构或语气必须禁止？

问题只在答案会改变结论、行动或风险时提出。

## 判断顺序

1. 区分内容思想、论证结构和表面口吻。
2. 从正样本提炼稳定选择，从负样本提炼错误信号。
3. 用词、句法、段落、解释、案例、金句和边界分别建规则。
4. 每条规则配正例、反例和适用范围。
5. 用未参与提炼的新样本做盲测。
6. 把新反馈写成候选规则，不立即污染全局。

## 最低通过条件

- 至少3份同类型正样本。
- 至少1份负样本或修改记录。
- 样本确属作者本人且用途可比较。
- 规则能由第三方执行并检查。

## 标准输出

1. 作者声音与写作任务说明。
2. 七类可执行风格规则。
3. 正例、反例和禁用模式。
4. 事实与理论的表达方式。
5. 不同载体的稳定项与适配项。
6. 盲测、更新和废止规则。

## 回退

- 只有外部作者样本，不能建立用户本人风格。
- 内容观点与方法尚未形成，先转 sam-research 或 sam-topic。

## 下一入口

- 写新内容，转 sam-write。
- 修改已有稿件，转 sam-edit。
- 发布前检查风格一致性，转 sam-audit。

## 停止条件

- 关键事实无法取得，且不同答案会改变本轮行动。
- 用户要求虚构事实、案例、收益、授权或用户心理。
- 任务涉及专业资质、敏感数据或高风险外部动作而缺少责任人。
- 当前 Skill 的最低条件未成立，需要回退到更早任务。

停止时仍交付：已确认、暂定结论、不能继续的原因、最少补充和下一入口。
