# 表达标准输入卡

## 这个 Skill 帮你解决什么

从作者真实样本和修改反馈中，建立可执行、可举反例、可盲测和持续更新的表达标准。

## 最少提供这些

1. 至少 3 份认可的真实样本。
2. 1—3 份不认可或修改过的样本。
3. 样本用途与载体。
4. 想保留的判断方式和必须禁止的表达。

## 有这些材料会更准确

- 修改前后对照。
- 作者聊天、口播、长文与课程样本。
- 用户明确给过的负反馈。
- 不同平台上作者仍希望保持的部分。

## 没有材料时会怎样处理

只有一篇样本时，只形成暂定观察。

不凭单篇文章定义人格，不模仿其他作者声音。

## 你会得到什么

1. 作者声音与写作任务说明。
2. 可执行风格规则。
3. 正例、反例和禁用模式。
4. 载体稳定项与适配项。
5. 盲测与更新规则。

## 可以直接复制

> 使用 `$sam-style` 建立我的表达标准。认可样本在【】，不认可或修改样本在【】，主要用于【载体／任务】，我最想保留【】，必须禁止【】。
