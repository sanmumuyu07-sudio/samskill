# 定位约束画布

## 输入

- 当前项目与目标。
- 行业和商业模式。
- 用户任务与证据。
- 个人能力、项目结果和限制。
- 已有内容、产品和咨询记录。

## 七格画布

| 约束 | 必答问题 | 证据 |
|---|---|---|
| 市场 | 需求在哪种交易结构里成立 | 行业、付款和替代数据 |
| 用户 | 谁在何时因何事行动 | 访谈、咨询和行为 |
| 问题 | 第一断点是什么 | 失败记录和任务链 |
| 角色 | 你承担什么责任 | 行为与结果证据 |
| 结果 | 用户能检查什么变化 | 验收和交付记录 |
| 产品 | 什么承接承诺 | 产品、价格、成本 |
| 内容 | 反复研究什么，主动不做什么 | 历史样本和栏目 |

## 判断分支

- 用户不清：转模块 05。
- 能力无证据：转模块 03。
- 结果无法交付：转模块 04。
- 市场不成立：转模块 02。
- 七格一致：进入公共角色和账号承诺。

## 停止条件

- 关键经历不真实。
- 产品与用户任务无关。
- 承诺可能造成合规或重大交付风险。

## 标准输出

定位约束句、三项证据、三项未知、主动舍弃项、下一次最小验证。
