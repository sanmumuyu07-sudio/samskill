# 运行合同

## 本 Skill 解决什么

建立一套能持续产生内容、服务当前业务阶段并允许用数据调整的内容组合，而不是固定比例的选题清单。

## 三种入口

### A｜快速判断

用户材料足够，直接输出结论、主问题、行动和验收，不重复问卷。

### B｜引导建模

用户有真实项目但材料不足。每轮最多两个问题，直到能区分一个主结论和替代解释。

### C｜材料处理

用户给出文件、数据、链接或历史状态。先列已读范围、可用事实和缺口，再运行判断。

## 入口问题

1. 未来30—90天账号最重要的现实结果是什么？目标用户目前处于什么理解和行动状态？
2. 现有定位、产品、平台、稳定栏目、内容数据和生产能力分别是什么？哪些不能改变？

问题只在答案会改变结论、行动或风险时提出。

## 判断顺序

1. 锁定阶段结果、非目标和护栏。
2. 从用户状态和业务任务确定长期命题范围。
3. 区分识别、理解、传播、信任、关系和行动内容任务。
4. 设计栏目职责、素材来源和系列关系。
5. 用产能与平台条件制定节奏原则。
6. 建立30天内容实验、淘汰和回填规则。

## 最低通过条件

- 定位和账号承诺基本清楚。
- 至少一类核心用户任务。
- 业务阶段和产品承接可说明。
- 生产能力和平台边界已知。

## 标准输出

1. 阶段目标与非目标。
2. 长期命题地图。
3. 栏目与内容任务分工。
4. 内容组合原则，不机械给固定比例。
5. 30天更新节奏与素材需求。
6. 验证指标、淘汰和回退条件。

## 回退

- 定位不清，转 sam-position。
- 产品与商业目标不清，转 sam-product 或 sam-business。

## 下一入口

- 研究外部样本，转 sam-benchmark。
- 形成具体选题，转 sam-topic。
- 需要落地生产流程，转 sam-operations。

## 停止条件

- 关键事实无法取得，且不同答案会改变本轮行动。
- 用户要求虚构事实、案例、收益、授权或用户心理。
- 任务涉及专业资质、敏感数据或高风险外部动作而缺少责任人。
- 当前 Skill 的最低条件未成立，需要回退到更早任务。

停止时仍交付：已确认、暂定结论、不能继续的原因、最少补充和下一入口。
