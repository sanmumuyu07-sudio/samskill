# 选题研究卡

## 必填

来源、用户处境、现实问题、旧解释、叁木判断、支持证据、反向证据、内容任务、希望发生的下一步、不能承诺。

## 状态

F 已知事实；I 解释；H 待验证；U 未知。

## 标准输出

一段完整选题说明，而非标题列表；之后才进入模块10生成标题、封面和开头。
