# 模块 06 来源与概念映射

## 一、本模块真正解决什么

定位不是替项目寻找一个更高级的名字。

它要把市场选择、用户任务、个人能力、产品结果和公共表达收束成同一套选择约束。

## 二、本地读取范围

- 三圈定位、人格底色、一句话定位历史课程。
- 叁木、德国留学、菌子、瓷砖等项目定位文件。
- 一人媒体、个人资产、用户任务与产品模块。
- 叁木语言风格、品牌定型、内容生产系统。
- `positioning`、营销管理、个人商业模式等本地蒸馏材料。

## 三、理论怎样进入叁木系统

| 来源 | 支持关系 | 不支持结论 |
|---|---|---|
| 定位理论 | 定位处理用户如何在已有分类和竞争参照中理解一个选择 | 抢一个词就能永久占领心智 |
| 顾客品牌资产 | 稳定、强且相对独特的联想会改变用户反应 | 品牌等于视觉或口号 |
| 自我呈现 | 公共互动必然包含信息选择和角色管理 | 人设等于欺骗或必须暴露全部生活 |
| 信号理论 | 可观察且有成本的证据帮助陌生人判断不可见能力 | 包装越精致，能力越强 |
| 顾客价值与用户任务 | 公共承诺必须落在具体任务和结果 | 创作者喜欢什么就能形成市场 |
| 行业竞争 | 赛道结构、付款方式和替代方案限制上限 | 选大赛道一定赚更多 |
| 叁木项目记录 | 定位必须在内容、咨询、交易和交付里检验 | 单个平台数据上涨就证明定位正确 |

## 四、历史内容必须修正

### 三圈定位

保留：能力、需求与变现必须互相约束。

修正：三者交集只产生候选方向，仍需加入行业结构、用户任务、竞争参照、证据和交付能力。

### 人格类型

保留：表达方式要与本人长期状态相容。

修正：人格类型只是呈现假设，不是命运分类，也不能代替用户为什么选择你。

### 一句话定位

保留：定位最后必须能被清楚复述。

修正：一句话是压缩结果，不是研究过程。没有前置判断，口号越顺，误导可能越大。

### 发满三十条再调整

保留：不能因为几条内容波动就频繁换方向。

修正：没有统一数量。判断窗口由发布频率、样本质量、平台分发、咨询周期和错误风险决定；若已出现错误客群、违规或交付冲突，应立即停止。

## 六、输出边界

本模块负责定位假设、公共角色、账号承诺、差异参照和调整条件。

行业不清转模块 02；个人证据不清转模块 03；产品承诺不清转模块 04；用户任务不清转模块 05；内容落地转模块 09—13。
