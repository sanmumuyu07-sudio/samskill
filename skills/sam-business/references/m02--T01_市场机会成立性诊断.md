# 市场机会成立性诊断

## 这张表解决什么

把“赛道很火”“用户有痛点”“别人赚到钱”变成对当前项目可检查的机会判断。

它不输出“能做／不能做”的空结论。

它要找出第一道尚未通过的门，并给一轮最低成本验证。

## 使用前必须提供

1. 一类用户的具体处境。
2. 一个可完成的现实任务。
3. 用户现有三种替代方案。
4. 真实语言、行为或支付材料。
5. 当前触达渠道。
6. 项目已有能力、证明和交付。
7. 客单、成本与风险的粗略范围。

只有赛道名称时，不进入评分。

先输出“需求研究问题清单”。

## 第一部分｜需求链七格

每格只写事实和来源。

| 节点 | 必填问题 | 最低通过证据 |
|---|---|---|
| 处境 | 用户何时必须处理 | 真实场景或时间节点 |
| 任务 | 什么结果算完成 | 可观察的完成标准 |
| 不满 | 当前哪里不够 | 重复原话、退出或损失 |
| 替代 | 现在怎样解决 | 真实使用、比较或不行动 |
| 交换 | 愿意付出什么 | 时间、预约、试用或支付 |
| 触达 | 何时在哪里找到 | 可重复渠道或关系入口 |
| 交付 | 项目怎样完成 | 能力、案例、流程与边界 |

第一处没有最低证据的节点，就是需求链断点。

## 第二部分｜需要、欲望与交易条件

分别填写：

```text
基础需要：
具体欲望：
当前行为层级：认同／搜索／比较／预约／支付／复购
支付能力：有证据／待确认／不足
支付意愿：有证据／待确认／不足
决策权：本人／共同决策／非决策者
行动时机：现在／明确日期／不确定
```

规则：四项交易条件中有两项待确认，只能标“待验证市场”。

## 第三部分｜个人机会五道门

### 需求门

是否出现行为或支付证据。

### 可达门

是否能在决策期稳定接触。

### 竞争门

是否存在未被充分解决的任务。

### 能力门

是否有对应能力、资源和可信证明。

### 经济门

是否能在获客、销售和交付后留下可接受结果。

每道门标记：

- 已通过。
- 部分通过。
- 未通过。
- 无法判断。

不要计算总分。

第一道未通过的门决定下一步。

## 第四部分｜证据等级

| 等级 | 证据 |
|---|---|
| M0 | 只有创作者想象 |
| M1 | 重复用户语言 |
| M2 | 搜索、比较、预约或替代行为 |
| M3 | 真实支付或签约 |
| M4 | 重复交易、结果、复购或转介绍 |

市场等级和个人机会分开写。

市场可到 M4，个人仍可能卡在可达门或能力门。

## 第五部分｜分支规则

### 只有 M0—M1

不做完整产品和规模化内容。

先完成访谈、搜索、评论和替代方案研究。

### 达到 M2，没有支付

设计最小承诺、预约、评估或低风险试用。

### 达到 M3，个人五门未通过

市场成立，当前项目入口不成立。

修入口，不宣称赛道无需求。

### 达到 M4，经济门不成立

停止扩量，转模块 04 与 15 修产品、销售或交付。

## 标准输出

```text
决策问题：
需求链：
市场证据等级：M0—M4
个人机会：旁观／假设／可测试／初步可经营
第一道未通过的门：
支持证据：
关键未知：
未来 7—14 天实验：
继续条件：
停止条件：
下一模块：
```

## 使用边界

本工具不是投资建议、市场规模预测或财务审计。

所有平台、政策和行业时效事实必须附来源与日期。
