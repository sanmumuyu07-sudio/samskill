# 趋势、窗口、周期与热点分类器

## 使用目的

判断一个变化应该进入长期能力建设、短期实验、周期准备，还是只作为内容语境。

## 输入

- 变化事实。
- 原始来源与日期。
- 过去可对照材料。
- 预计持续时间。
- 受影响参与者。
- 具体业务节点。
- 当前可执行动作。

## 四类检查

### 热点 H

- 注意力是否短期集中。
- 起点是否来自单一事件。
- 衰减是否很快。
- 即使热度消失，用户任务是否仍存在。

### 窗口 W

- 是否存在暂时供需差、规则差或时间节点。
- 哪种动作在窗口内更有利。
- 开始、结束和容量是什么。
- 谁已经具备利用条件。

### 周期 C

- 变化是否曾重复出现。
- 与季节、预算、库存、信心或政策节奏是否相关。
- 上行和下行分别影响什么。

### 趋势 T

- 是否有多个独立来源。
- 是否持续改变成本、技术、人口、制度或文化。
- 是否跨过单次事件和短期波动。

一个变化可以多选。

必须标主分类和次分类。

## 业务映射

每个分类都要回答：

| 节点 | 影响 |
|---|---|
| 用户任务 | 新增、增强、减弱还是不变 |
| 支付 | 能力、意愿、时机怎样变化 |
| 渠道 | 触达成本和规则怎样变化 |
| 竞争 | 新进入、替代和议价怎样变化 |
| 产品 | 承诺与形式怎样变化 |
| 交付 | 成本、产能和风险怎样变化 |

## 动作规则

### 主分类为 H

只连接长期问题，不因单次热度改变核心产品。

### 主分类为 W

设置预算、周期和退出条件，快速做可逆实验。

### 主分类为 C

建立阶段预案，不把波动解释成永久结论。

### 主分类为 T

逐步调整能力、产品和系统，并设置季度复查。

## 标准输出

```text
变化事实：
主分类：H／W／C／T
次分类：
支持证据：
反向证据：
影响节点：
内容动作：
商业动作：
最大投入：
失效条件：
复查日期：
```

## 停止条件

- 只有一个未核验传言。
- 无法说明影响哪个业务节点。
- 需要不可逆高投入，却没有最低证据。
- 变化超出团队资质和风险承受范围。
