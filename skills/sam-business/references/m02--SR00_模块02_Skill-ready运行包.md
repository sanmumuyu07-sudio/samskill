# 模块 02｜行业、市场与商业环境：Skill-ready 运行包

## 这个模块解决什么

它负责判断：用户想做的事情，是否存在具体需求、可触达的人、可承受的交易方式，以及当前值得进入的机会。

它不负责预测宏观经济，也不要求普通用户填写行业研究报告。

行业判断只占前置决策的一部分；一旦足够支持行动，就必须进入产品、用户与内容验证。

## 最小输入

1. 想进入的行业或正在经营的业务。
2. 具体产品、能力或服务。
3. 用户现在用什么方式解决问题。
4. 交易价格、频率、决策周期与交付方式。
5. 三类证据：搜索／讨论、交易／询价、已有供给／替代方案。

## 判断顺序

### K0｜需求是否存在

寻找正在发生的任务、付费、搜索、抱怨和替代行为，不从赛道名称倒推需求。

### K1｜有效需求

检查想要、支付能力、决策权和行动时点是否同时存在。

### K2｜行业利润结构

检查获客成本、交付成本、供应限制、议价权、复购与替代压力。

### K3｜个人进入条件

行业有机会不等于用户有机会；必须比较用户的经验、证据、资源和切入方式。

### K4｜时间属性

区分长期需求、行业周期、短期窗口、平台热点和偶发事件。

### K5｜验证动作

形成一项低成本前向验证，不用完整起号代替市场验证。

## 十二张原子的调用合同

| 原子 | 核心判断 | 标准输出 |
|---|---|---|
| SAM-MKT-001 | 市场是否来自可观察需求而非赛道名称 | 需求证据表 |
| SAM-MKT-002 | 需要、欲望和有效需求是否被混用 | 有效需求判定 |
| SAM-MKT-003 | 参与者、利益链和决策者分别是谁 | 市场角色图 |
| SAM-MKT-004 | 成本、收益与风险怎样分配 | 交易结构图 |
| SAM-MKT-005 | 行业规模与个人机会是否混同 | 个人进入条件表 |
| SAM-MKT-006 | 供给、替代和竞争怎样影响利润 | 结构压力诊断 |
| SAM-MKT-007 | 平台怎样改变连接与议价 | 平台关系说明 |
| SAM-MKT-008 | 趋势、周期、窗口和热点属于哪一类 | 时间属性分类 |
| SAM-MKT-009 | 赛道怎样影响粉丝质量与变现上限 | 赛道质量评估 |
| SAM-MKT-010 | 广告、线索、交易等模式如何区分 | 变现模式初判 |
| SAM-MKT-011 | 线上增长如何连接原有线下业务 | 线上线下连接图 |
| SAM-MKT-012 | 行业研究何时可以停止 | 一页机会判断单 |

## 证据要求

合格判断至少包含：

- 一项用户行为证据。
- 一项交易或替代证据。
- 一项供给与竞争证据。
- 时间与地区边界。
- 反例或不成立条件。

公开平台规则、市场价格和行业数据必须标注抓取日期与来源。

## 冲突处理

- 市场大但个人无证据：先做窄入口，不给“大赛道”结论。
- 用户喜欢但不付费：标记为注意力需求，不直接标记有效需求。
- 内容数据好但交易差：转入模块 04、15，不回推市场必然成立。
- 线下业务成立但线上表达弱：保留原业务逻辑，只重建线上连接。
- 新热点与长期能力冲突：热点只作为试验，不改长期定位。

## 标准金样本

输入：“AI 很火，我想做 AI 赛道。”

不合格输出：“AI 是趋势，可以做。”

合格输出必须把它拆成：

1. 哪一类人正在为什么任务寻找 AI。
2. 当前替代方案是什么。
3. 用户凭什么进入这段价值链。
4. 用什么内容或小产品验证询价、留资或付费。
5. 哪个信号出现后继续，哪个信号出现后停止。

## 验证边界

本模块只能提高市场判断质量，不能保证市场预测准确。

真实需求、价格与成交仍必须通过当期市场验证。
