# 线索、成交与交付输入卡

## 这个 Skill 帮你解决什么

连接内容、主页、私信、线索、销售、付款、交付、复购和推荐，找到最早的承接断点。

## 最少提供这些

1. 本轮目标是咨询、成交、合作还是职业机会。
2. 什么算有效结果。
3. 过去 30—90 天各层数量与来源。
4. 产品、价格、销售、交付、退款和复购实际情况。

## 有这些材料会更准确

- 内容到主页、私信、表单、社群的路径。
- 线索定义、来源、拒绝原因和跟进记录。
- 销售话术、合同、付款与退款数据。
- 交付容量、结果、投诉、复购与推荐。

## 没有材料时会怎样处理

先建立口径和漏斗基线。

不把所有私信算有效线索，不用销售问题掩盖产品和交付问题。

## 你会得到什么

1. 结果链与漏斗。
2. 有效线索和适配标准。
3. 最早断点与替代解释。
4. 销售、承诺、交付和容量风险。
5. 七天修复与回填规则。

## 可以直接复制

> 使用 `$sam-relationship` 检查承接。目标结果是【】，有效结果定义是【】，过去【时间】各层数量和来源是【】，产品、价格、销售、交付、退款与复购情况是【】。
