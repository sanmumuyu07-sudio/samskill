# 用户证据三角表

## 使用目的

防止用评论、访谈或单次购买独立证明完整用户需求。

## 证据表

| 用户假设 | 表达证据 | 行为证据 | 交易／结果证据 | 反证 | 样本与时间 | 当前强度 |
|---|---|---|---|---|---|---|
|  | 搜索、评论、访谈 | 点击、提交、试用、执行 | 付款、使用、结果、复购 |  |  | U0—U4 |

## 用户证据等级

- U0：团队猜测。
- U1：有用户原话。
- U2：有重复表达或搜索行为。
- U3：表达与非金钱行动一致。
- U4：表达、行动与交易／结果互相支持。

等级不代表普遍性。

必须同时记录样本来源、数量、时间和产品条件。

## 冲突处理

### 说需要但不行动

检查时机、风险、任务强度和表达成本。

### 点击很多但咨询错位

检查内容吸引的人与产品用户是否一致。

### 付款但不使用

检查身份消费、使用成本、产品承诺和交付路径。

### 使用但不续费

检查任务是否一次性完成、结果不足或后续产品错位。

## 标准输出

- 当前最强用户关系。
- 最大证据冲突。
- 不可推出的结论。
- 下一项补证动作。
