# 模块 05 跨模块边界与调用规则

## 本模块负责

- 用户处境与任务。
- 功能、情绪和社会任务。
- 风险、身份和行动断点。
- 社会位置条件。
- 认知阶段与用户证据。
- 假设前向验证。

## 不负责

- 临床心理与人格诊断。
- 产品承诺与定价：模块 04。
- 定位：模块 06。
- 选题：模块 09。
- 传播机制：模块 12。
- 销售与成交：模块 15。

## 入口

### 只有抽象人群

调用 `T01`，还原最近事件。

### 有大量评论但不知道需求真假

调用 `T02`，补行为和交易证据。

### 用户说想做却不行动

调用 `T03`，不直接贴拖延或认知标签。

### 已有人群结论准备做内容或产品

调用 `T04`，先写可观察预测。

## 输入不足时降级

- 没真实事件：只保留人群线索。
- 没行为证据：最高 U1。
- 没交易结果：不写有效需求已验证。
- 涉及心理健康、安全、法律和歧视：停止并转专业支持。

## 默认 Skill 调用链

```text
阶段入口
→ 处境任务访谈
→ 用户证据三角
→ 风险身份诊断
→ 前向验证
→ 保存用户假设版本
→ 路由到产品、定位、选题或销售
```

后续 Skill 不得直接输出“精准画像”，必须保留证据、反证和未知。
