# 运行合同

## 本 Skill 解决什么

建立能被证据支撑、能约束内容和产品、并能通过现实信号验证的定位，而不是包装一句人设口号。

## 三种入口

### A｜快速判断

用户材料足够，直接输出结论、主问题、行动和验收，不重复问卷。

### B｜引导建模

用户有真实项目但材料不足。每轮最多两个问题，直到能区分一个主结论和替代解释。

### C｜材料处理

用户给出文件、数据、链接或历史状态。先列已读范围、可用事实和缺口，再运行判断。

## 入口问题

1. 最近一次真实用户为什么在那个时刻搜索、咨询、购买或放弃？请提供原话、行为或材料。
2. 你能提供什么结果、凭什么、准备通过什么产品承接？当前账号主要讲什么，实际吸引了谁？

问题只在答案会改变结论、行动或风险时提出。

## 判断顺序

1. 从真实事件拆功能、情绪和社会任务。
2. 区分观看者、使用者、付款者和决策者。
3. 建立用户证据等级与冲突记录。
4. 检查市场、用户、问题、角色、结果、产品、内容七项一致性。
5. 形成内部定位、公共角色、账号承诺和不做清单。
6. 设计局部定位实验，不一次重做全部账号。

## 最低通过条件

- 至少一个真实用户事件。
- 至少一种行为、咨询、购买或使用证据。
- 个人贡献和产品边界可说明。
- 定位必须能够排除内容与客户。

## 标准输出

1. 用户处境与决策链。
2. 证据等级和关键未知。
3. 七项定位约束。
4. 内部定位工作句、公共角色与账号承诺。
5. 三项不做与证据边界。
6. 七天定位验证和回退条件。

## 回退

- 市场是否存在不清，转 sam-business。
- 产品承诺和交付不清，转 sam-product。
- 个人经历无法归因，回 sam-project-diagnosis。

## 下一入口

- 定位成立后需要内容组合，转 sam-strategy。
- 需要外部样本检验定位，转 sam-benchmark。
- 只需形成一批选题，转 sam-topic。

## 停止条件

- 关键事实无法取得，且不同答案会改变本轮行动。
- 用户要求虚构事实、案例、收益、授权或用户心理。
- 任务涉及专业资质、敏感数据或高风险外部动作而缺少责任人。
- 当前 Skill 的最低条件未成立，需要回退到更早任务。

停止时仍交付：已确认、暂定结论、不能继续的原因、最少补充和下一入口。
