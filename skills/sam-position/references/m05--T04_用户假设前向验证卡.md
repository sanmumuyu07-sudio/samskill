# 用户假设前向验证卡

## 假设句

```text
在【触发处境】下，
具有【必要条件】的人，
为了完成【当前任务】，
会优先处理【关键阻力】，
并愿意采取【可观察行为】。
```

## 实验设置

```text
最危险关系：
目标样本：
内容／访谈／产品动作：
只改变的变量：
预期行为：
支持阈值：
反对阈值：
时间范围：
隐私与伦理：
```

## 结果回填

- 发生了什么。
- 哪些人行动。
- 哪些人没有行动。
- 表达与行为是否一致。
- 出现什么替代解释。
- 假设保留、修改还是删除。

## 停止条件

- 需要欺骗、羞辱或制造虚假稀缺。
- 样本与目标用户不一致。
- 同时改变多项关键变量。
- 事后重写阈值只为宣布成功。
