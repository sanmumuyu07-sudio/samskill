# 模块 05 三类用户压力测试

## 测试一｜只有人口画像

### 输入

“我的用户是 25—35 岁、一二线城市、想成长的女性。”

### 错误输出

继续补收入、爱好、焦虑和消费偏好，形成虚构画像。

### 正确输出

- 保留人口背景。
- 要求最近一次触发事件和具体任务。
- 不推断成长、创业或付费意愿。
- 用 `T01` 建立场景样本。

## 测试二｜用户认同很多但没有行动

### 输入

“评论区都说讲到心里，但没人提交资料和购买。”

### 错误输出

继续加强痛点和身份共鸣。

### 正确输出

- 用 `T02` 标记表达证据与行为冲突。
- 检查任务时机、风险、产品适配和行动成本。
- 用 `T04` 测试一个更小行动。

## 测试三｜给用户贴“高认知穷人”

### 输入

“这群人读书很多但赚不到钱，应该就是高认知穷人。”

### 错误输出

接受标签并设计身份营销。

### 正确输出

- 拆知识、收入、关系、行动和市场证据。
- 检查社会位置和资源转换机制。
- 不把收入作为人格价值。
- 若无现实任务，不进入产品设计。

## 结论

- 能区分标签、处境和行为。
- 能处理认同与行动冲突。
- 能阻止身份预支和心理过度解释。
- 当前只通过内部干跑。
