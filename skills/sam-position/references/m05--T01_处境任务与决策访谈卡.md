# 处境、任务与决策访谈卡

## 原则

问最近一次真实事件。

不要用“你是不是因为……”诱导答案。

## 访谈顺序

### 1. 触发

- 最近一次什么时候意识到要处理这件事。
- 当时发生了什么。
- 谁在场或受影响。

### 2. 原有方案

- 以前怎样解决。
- 这次为什么没有继续。
- 还比较过什么。

### 3. 三层任务

- 功能上要完成什么。
- 希望减少或获得什么感受。
- 希望别人怎样看待这件事。

### 4. 约束

- 钱、时间、技能和关系。
- 谁付款、使用、批准和验收。
- 最担心失去什么。

### 5. 行动

- 已经做过什么。
- 做到哪一步停下。
- 下一步准备什么时候做。

### 6. 结果

- 怎样才算解决。
- 可以接受什么取舍。
- 什么结果会让ta停止。

## 记录格式

所有内容标为：

- 用户原话。
- 可观察行为。
- 研究者解释。
- 待验证假设。

## 标准输出

- 决策时间线。
- 三层任务。
- 替代方案。
- 风险和参照点。
- 决策角色。
- 三项仍未知问题。
