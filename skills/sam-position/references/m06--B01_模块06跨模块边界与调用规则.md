# 模块 06 跨模块边界与调用规则

## 本模块负责到哪里

交付定位假设、公共角色、账号承诺、内容边界、验证窗口和标准定位文档。

## 新用户入口

先提供：项目目标、产品或能力、目标用户、已有内容、已有结果、当前卡点。

输入不足时不硬做完整定位，先输出缺口清单。

## 默认 Skill 调用链

```text
阶段诊断
→ 市场判断（模块02）
→ 资产审计（模块03）
→ 产品检查（模块04）
→ 用户研究（模块05）
→ 定位约束画布
→ 公共角色证据审计
→ 账号承诺一致性审计
→ 定位文档
→ 平台与选题（模块07、09）
```

不是所有用户都走全链。

- 已有成熟产品与用户证据，可直接进入定位审计。
- 没有现实项目，先回模块03建立最小证明。
- 只有流量问题但定位稳定，转模块07、09—14。

## 停止与转路由

- 市场不成立：模块02。
- 证据不足：模块03。
- 产品无法承接：模块04。
- 用户只是想象：模块05。
- 要做具体内容：模块09—13。
- 要判断数据：模块14。

## 标准输出

当前阶段、定位结论、证据、未知、第一断点、修正动作、下一模块。
