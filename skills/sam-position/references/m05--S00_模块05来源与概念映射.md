# 模块 05 来源与概念映射

## 一、本模块真正解决什么

不是替用户发明一个有优越感的人群名称。

而是回答：

1. 谁在什么处境下要完成什么进展。
2. 用户说出来的问题与实际行为之间有什么差异。
3. 功能、情绪、社会和身份任务怎样共同影响选择。
4. 风险、参照点、现有习惯和决策权限怎样阻碍行动。
5. 社会位置怎样改变资源、代价和可行路径。
6. 怎样用评论、搜索、咨询、付款和使用行为互相补证。

## 二、本地知识读取范围

- 用户思维核心方法与完整框架。
- 短视频六种需求分类与市场认知五阶段。
- JTBD 用户任务理论。
- 福山身份政治、荣格人格面具等本地概念卡。
- 知识库适用人群分析。
- 叁木关于认知消费、身份预支、现实任务和知行断裂的讨论。
- 四项目咨询、线索、成交和交付记录。

## 三、理论怎样进入叁木系统

| 来源 | 支持关系 | 不支持结论 |
|---|---|---|
| JTBD | 用户在特定处境寻求功能、情绪与社会进展 | 人口特征无用、用户只有一个任务 |
| 认知失调 | 认知与行为不一致可能引发不适和解释调整 | 知道不做都由失调导致 |
| 可能自我 | 希望或害怕成为的人能进入当前动机 | 身份想象会自动产生行动 |
| 风险前景理论 | 参照点、损失和概率感知影响风险选择 | 所有购买都能用损失厌恶解释 |
| 社会认同 | 群体归属进入自我概念和选择 | 给用户贴标签就能造群体 |
| 承认理论 | 被承认与被轻视具有社会关系意义 | 共鸣内容能替代现实承认和能力证明 |
| 资本形式 | 经济、文化和社会资本分布影响选择条件 | 用阶层标签推断个体全部行为 |
| 注意力稀缺 | 信息增加会提高筛选和判断成本 | 信息越少越好或用户没有主动选择 |

## 四、历史内容必须修正

### 1. “隐性刚需”

保留：用户表达可能没有完整说出情绪、社会任务和处境。

修正：创作者不能声称比用户更了解其“真正需求”。隐含任务必须由具体事件、行为和多源证据支持。

### 2. “痛点是说不出口的委屈”

保留：问题带来的情绪和社会后果会影响注意与选择。

修正：痛点不总是委屈。它也可以是成本、风险、失败、冲突、延误或机会损失。

### 3. “痒点就是成为谁”

保留：可能身份能影响动机。

修正：身份许诺若不连接路径、能力和现实任务，就会变成身份预支。

### 4. “爽点是确定感”

保留：清晰解释能降低认知负担。

修正：确定感可能是错的。高质量内容要同时提供证据和不确定边界。

### 5. “用户认知三阶段”

保留：不同阶段需要不同信息。

修正：用户阶段应按对问题、方案、产品和行动的已知状态判断，不用高低认知评价人格。

### 6. “高认知穷人”

可以作为传播话语研究，不作为原子库人群事实。

它混合了知识储备、收入、行动、社会资源和自我评价，不能直接决定产品路径。

## 六、输出边界

本模块负责用户假设、任务、风险、身份与证据。

不负责：

- 为用户做临床心理诊断。
- 用阶层、人格和病理标签替代研究。
- 完成产品定价，转模块 04。
- 完成账号定位，转模块 06。
- 直接生成选题与脚本，转模块 09—11。
