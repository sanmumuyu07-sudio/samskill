# 风险、身份与行动断点诊断

## 第一步｜目标动作

```text
用户下一步具体要做什么：
必须在什么时候完成：
谁会看到：
不做会怎样：
```

## 第二步｜五类风险评分

0 为几乎没有，4 为足以停止行动。

| 风险 | 0—4 | 证据 |
|---|---:|---|
| 经济 |  |  |
| 能力 |  |  |
| 身份 |  |  |
| 关系 |  |  |
| 不可逆 |  |  |

## 第三步｜四种身份

```text
当前身份：
希望身份：
害怕身份：
希望公开展示的身份：
```

## 第四步｜不一致处理

记录用户怎样降低“想做但没做”的不适：

- 改变行动。
- 改变目标。
- 改变解释。
- 寻找支持信息。
- 回避相反证据。

这里是行为线索，不做临床诊断。

## 第五步｜最小可逆动作

设计一个：

- 真实。
- 小范围。
- 可撤回。
- 有截止。
- 有检查结果。

的动作。

## 标准输出

- 最大行动断点。
- 风险与身份冲突。
- 当前维持现状的机制。
- 最小可逆动作。
- 需要转专业支持的问题。
