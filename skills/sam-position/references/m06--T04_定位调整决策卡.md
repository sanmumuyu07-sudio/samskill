# 定位调整决策卡

## 输入

- 定位版本及启用日期。
- 内容样本和平台分发数据。
- 正确用户占比、咨询问题、交易和交付。
- 外部市场、产品和团队变化。

## 先排除

- 样本过少或内容质量不可比。
- 单条异常波动。
- 平台故障、违规或发布中断。
- 产品临时缺货和销售执行断裂。

## 四种决策

| 决策 | 证据条件 | 动作 |
|---|---|---|
| 保持 | 正确用户和承诺一致 | 继续积累 |
| 微调 | 任务成立但复述偏差 | 改简介、案例、表达 |
| 调整承诺 | 用户正确但产品或交付冲突 | 收缩结果、重做产品 |
| 重定位 | 用户、任务、证据或商业结构根本不成立 | 回模块02—05 |

## 停止条件

造假、合规、声誉和不可逆交付风险立即停止，不等待样本窗口。

## 标准输出

决策、依据、反向证据、保留资产、被放弃假设、下一实验和复查时间。
