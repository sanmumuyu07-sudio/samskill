# 用户与定位输入卡

## 这个 Skill 帮你解决什么

从真实处境、社会心理、行为决策和市场价值理解用户，并把它收束成定位、公共角色和账号承诺。

## 最少提供这些

1. 一次真实用户搜索、咨询、购买或放弃事件。
2. 本轮要决定定位、内容、产品还是市场优先级。
3. 你能提供什么结果、凭什么、准备怎样承接。

## 有这些材料会更准确

- 用户原话、评论、私信、访谈和咨询记录。
- 竞品内容、产品、成交与拒绝材料。
- 使用者、付款者、批准者和影响者信息。
- 现有定位、内容数据、产品与交付结果。

## 没有材料时会怎样处理

只输出待验证的人群假设与补证计划。

不把年龄、性别、收入或“高认知”等标签直接当成用户事实。

## 你会得到什么

1. 快速定位诊断，或十层人群深描／人群图谱。
2. 观看、使用、付款、决定和影响关系。
3. 公共角色、账号承诺和不做清单。
4. 最小验证与回退条件。
