# 诊断规则卡

## 使用规则

叁木方法论决定诊断顺序。

外部理论只在相应节点提供检查尺。

每张规则卡都要回答：对象、变量、通过、失败、证据、反例、边界、下游影响。

不得在最终报告中堆作者名字。

除非用户询问来源，否则直接给经过叁木流程重写后的判断。

## S01｜目标结果先于问题清单

- 对象：整个项目。
- 变量：对象、可观察结果、窗口、边界。
- 通过：目标能被时间和行为检查。
- 失败：“做好账号”“扩大影响力”“多变现”。
- 证据：目标字段、历史基线、责任人与截止时间。
- 反例：探索期可以把“得到哪条证据”作为结果，不强求营收。
- 边界：不能把用户不可控的最终结果写成交付承诺。
- 下游：决定需要检查哪些节点、选择什么指标。

## S02｜事实、解释与决定必须分开

- 对象：诊断中的所有信息。
- 变量：F/O/I/H/D/U。
- 通过：每条关键判断能回到事实，未知不会被补造。
- 失败：用户自述直接升级为因果；用一个案例证明规律。
- 证据：原始文件、后台、合同、访谈、时间线、公开页面。
- 反例：时间紧时可用暂定假设，但必须给出低置信度和补证动作。
- 边界：标记不等于事实自动真实，只说明信息在当前诊断中的身份。
- 下游：影响置信度、实验和风险。

## S03｜三种结果不能互相替代

- 对象：内容和经营结果。
- 变量：传播、关系、交易与交付。
- 通过：指标与内容职能、项目阶段一致。
- 失败：爆款等于商业成立；成交等于交付成立。
- 证据：曝光到结果的分层字段。
- 反例：品牌、职业机会和公共表达项目可以不以成交为目标，但仍需关系或机会结果。
- 边界：非交易结果也必须可观察。
- 下游：防止在错误节点优化错误指标。

## S04｜最近可干预断点

- 对象：目标链中的候选问题。
- 变量：必要性、失败证据、上游条件、权限、反馈速度、风险。
- 通过：一个主断点、一个替代解释、一个区分实验。
- 失败：把所有不完整处同时列为优先级；追着症状改。
- 证据：节点状态、变化前后、上下游数据。
- 反例：合规、现金流或交付风险可越过一般顺序，优先止损。
- 边界：断点是阶段性裁决，不是永久归因。
- 下游：决定七天动作和下一 Skill。

## S05｜先保留，再修改，再暂缓

- 对象：诊断方案。
- 变量：支持证据、主变量、连锁影响。
- 通过：明确哪些不动，避免为了修一个问题破坏已有结果。
- 失败：全盘重做；每周换定位；同时改对象、内容和产品。
- 证据：历史稳定结果、回访、成交、交付和团队能力。
- 反例：存在欺骗、侵权、高风险承诺时，不以“保留”为先。
- 边界：保留不表示永不调整。
- 下游：提高实验可归因性。

## S06｜单变量不是只改一个字

- 对象：一轮实验。
- 变量：主要假设、保持条件、同时变化、窗口。
- 通过：结果能支持或反对一个明确判断。
- 失败：平台、对象、价格、产品、脚本同时变化。
- 证据：实验前卡、实际版本和异常记录。
- 反例：零到一阶段可以测试一个完整提案，但必须把它作为整体变量，不事后归因到某个细节。
- 边界：单变量不等于统计上严格隔离，必须记录干扰。
- 下游：决定规则能否晋级。

## S07｜SOP 复制动作，判断系统处理变化

- 对象：内容、运营、销售、交付和 Agent 工作。
- 变量：稳定输入、选择依据、反例、异常、权限、写回。
- 通过：新人遇到新案例能选择动作，或知道何时升级。
- 失败：只给模板；离开核心操盘手后质量持续下降。
- 证据：非核心人员前向任务、异常处理和版本记录。
- 反例：纯机械任务只需 SOP，不必强行增加复杂判断。
- 边界：判断系统也不能替代明确责任人。
- 下游：决定能否交接、Skill 化和规模化。

## S08｜状态写回才产生项目复利

- 对象：每次诊断和实验。
- 变量：新事实、被反对假设、决定、动作、版本、下次检查。
- 通过：下一次可以从状态继续，不重新讲一遍。
- 失败：只有报告，没有写回；多个最终版冲突。
- 证据：状态增量、资产卡和版本历史。
- 反例：一次性匿名咨询可只提供增量预览，不要求保存。
- 边界：未经授权不写入用户文件。
- 下游：支持后续 Skill 路由和资产治理。

## R01｜用顾客需要定义市场，而不是用行业名

- 来源：科特勒等《营销管理》5C；原书关键段落与蒸馏 Skill 已核对。
- 吸收节点：市场需求。
- 对象：目标市场与竞争范围。
- 变量：顾客、公司、竞争者、合作者、环境。
- 通过：竞争者包含满足同一需要的跨品类替代；公司与合作者能交付所需价值。
- 失败：只列同行账号；赛道名就是市场。
- 证据：用户现有替代、支出、搜索和合作结构。
- 反例：需要严肃行业利润结构时，5C 不替代产业分析。
- 边界：5C 是市场定义工具，不证明商业可行。
- 下游：影响人群、定位、产品和渠道。

## R02｜三方价值同时可持续

- 来源：科特勒等《营销管理》3V；原书关键段落与蒸馏 Skill 已核对。
- 吸收节点：产品、销售、经营。
- 对象：用户、合作者、项目主体。
- 变量：各自获得的功能、心理、货币或战略价值。
- 通过：三方都有继续关系的理由，且没有一方长期负担不可承受的成本。
- 失败：用户满意但交付方亏损；渠道没收益；主体无利润或无战略价值。
- 证据：选择、留存、成本、利润、合作稳定性。
- 反例：短期试点可暂时补贴，但必须写期限和退出条件。
- 边界：三方价值为正不保证市场竞争胜出。
- 下游：影响产品形态、价格、组织和规模化。

## R03｜商业模式是耦合系统，不是收钱方式

- 来源：奥斯特瓦德、皮尼厄《商业模式新生代》九模块；原书与蒸馏 Skill 已核对。
- 吸收节点：市场、产品、销售、组织、经营。
- 对象：客户、价值、渠道、关系、收入、资源、活动、合作、成本。
- 变量：九个模块及其连锁影响。
- 通过：修改任何一格时，能指出至少两条跨模块影响。
- 失败：只改价格或渠道，却假设交付、成本和关系不变。
- 证据：业务流程、合同、岗位、成本和交易记录。
- 反例：单点问题已经明确时，不必每次重画九格。
- 边界：画布描述“如何运作”，不证明“能不能活”；必须补单位经济和真实测试。
- 下游：防止局部优化制造新的断点。

## R04｜外部观察必须变成设计假设

- 来源：《商业模式新生代》环境扫描；蒸馏 Skill 对原框架增加了平台规则和到期日检查。
- 吸收节点：市场、经营。
- 对象：市场、行业、趋势、宏观条件。
- 变量：外部条件、受影响模块、设计动作、到期日。
- 通过：每条趋势都能写成“若条件成立，哪一格怎样变化，因此做什么”。
- 失败：做了一份行业报告，却不改变任何选择。
- 证据：原始政策、平台规则、技术与经济数据。
- 反例：本周现金流危机不先做三年趋势研究。
- 边界：设计假设仍需访谈或实验验证。
- 下游：影响市场进入、渠道依赖和风险。

## R05｜顾客购买的是目的能否达成

- 来源：杰弗里·摩尔《跨越鸿沟》的整体产品规划；原书主题与蒸馏 Skill 已核对。
- 吸收节点：产品、销售、交付。
- 对象：核心产品、配套服务、非本方条件。
- 变量：目标细分、购买目的、缺口、归属、最简完整线。
- 通过：没有某项时，顾客仍有充分理由购买；所有必需项都有责任主体。
- 失败：功能不差却卖不动；每单靠人力硬扛；忽略客户流程与第三方条件。
- 证据：交付工时、客户推迟原因、上线障碍、使用和推荐。
- 反例：早期共创者可能愿意接受不完整产品。
- 边界：未选定具体细分时，不画通用整体产品。
- 下游：影响定价、交付负荷、合作和放大条件。

## R06｜顺应已存在的需求，先算教育成本

- 来源：克劳德·霍普金斯《科学的广告》；原书关键判断与蒸馏 Skill 已核对。
- 吸收节点：市场、定位、内容。
- 对象：新产品、新习惯和传播诉求。
- 变量：旧欲望、替代支出、教育成本、挂靠方式。
- 通过：能指出用户已经在焦虑、行动或花钱的对象，新方案是更优路径。
- 失败：内容反复告诉用户“你应该需要”，却没有现实行动信号。
- 证据：搜索、咨询、替代购买、现有习惯。
- 反例：内容和社区可能降低教育成本，因此不把“不能改变习惯”绝对化。
- 边界：这是立项先验，不替代真实测试。
- 下游：影响市场选择、内容入口和获客成本。

## R07｜先测试，再规模化

- 来源：克劳德·霍普金斯《科学的广告》；原书小规模试验原则与蒸馏 Skill 已核对。
- 吸收节点：传播、产品、销售、经营。
- 对象：准备放大的内容、渠道、产品或营销动作。
- 变量：最小单元、追踪、真实行为、成本、回本、观察窗口。
- 通过：小样产生真实行为或交易，能估算单位成本和失败风险。
- 失败：用问卷喜欢度代替购买；还没验证就全渠道上。
- 证据：专用链接、来源字段、预约、支付、使用和交付数据。
- 反例：零成本常规内容发布可以作为探索，不要求交易才发布。
- 边界：小样不自动可外推，必须检查人群、渠道和时间是否变化。
- 下游：决定停止、调整或放大。

## R08｜先量出链路，再决定优化哪里

- 来源：埃利斯、布朗《增长黑客》的 AARRR 与增长实验；原书框架和蒸馏 Skill 已核对。
- 吸收节点：传播、关系、销售、交付。
- 对象：从进入到结果的行为链。
- 变量：各层绝对量、转化、流失、切分、修复可行性。
- 通过：每层有可查询事件，按渠道/平台/用户类型做必要切分，主断点有数据依据。
- 失败：先想点子再找地方用；只看总平均；把获客问题与激活问题混淆。
- 证据：后台、CRM、订单和交付记录。
- 反例：B2B 长周期、早期低样本或非线性关系不强套 AARRR。
- 边界：漏斗告诉“哪里”，不单独告诉“为什么”。
- 下游：决定下一个专项诊断与实验。

## R09｜主指标需要护栏

- 来源：《增长黑客》北极星指标；护栏是蒸馏补充，不冒充原书原话。
- 吸收节点：所有节点的验证。
- 对象：本轮目标与指标。
- 变量：用户价值、可影响性、业务相关性、质量和风险。
- 通过：一个主指标代表当前价值交付，一个护栏防止局部优化。
- 失败：累计粉丝、注册数等虚荣指标；指标涨但退款、差评或交付崩坏。
- 证据：行为与结果数据。
- 反例：探索期可以用证据获得量作为主指标。
- 边界：一个指标不能代表所有利益相关者，必要时增加约束而非增加多个主目标。
- 下游：统一实验和团队取舍。

## R10｜越靠近真实交易，数据通常越难伪造

- 来源：杨飞《流量池》的效果溯源；原书关键段落与蒸馏 Skill 已核对。
- 吸收节点：传播、关系、销售。
- 对象：曝光、点击、留资、潜客、订单、成交和结果数据。
- 变量：数据离交易的距离、来源、利益关系、三端身份对齐。
- 通过：任取一笔结果能追溯来源；终审以自有交易或交付系统为准。
- 失败：投放方、渠道或代运营自报曝光和留资作为唯一依据。
- 证据：UTM/口令、表单来源、CRM、订单和交付。
- 反例：品牌曝光和多触点影响不能只用末次成交归因，应使用增量测试和品牌指标。
- 边界：越靠近交易不等于绝对真实；内部口径也可能被粉饰。
- 下游：影响预算、渠道与诊断置信度。

## R11｜流量能否留下并降低下一轮成本

- 来源：杨飞《流量池》的存储、运营与发掘；蒸馏 Skill 已核对。
- 吸收节点：关系、资产、经营。
- 对象：内容、投放、活动和渠道支出。
- 变量：存储、再调用、老带新、长期成本趋势。
- 通过：至少有关系入口、运营责任和下一轮调用机制。
- 失败：停更或停投就完全归零；只建群不运营；名单权利不清。
- 证据：回访、直接访问、复购、老带新和获客成本趋势。
- 反例：短生命周期品类可能只需要转介绍，不需要长期私域运营。
- 边界：可沉淀不等于值得沉淀，还要看隐私、合规和运营成本。
- 下游：影响内容资产、关系和预算分配。

## R12｜定位先从外部心智取证

- 来源：里斯、特劳特《定位》的心智阶梯；原书关键主题与蒸馏 Skill 已核对。
- 吸收节点：定位。
- 对象：用户如何把主体、品类和替代方案联系起来。
- 变量：自发提及、品类入口、相对位置、认知冲突、聚焦词。
- 通过：定位利用已有认知，且能排除内容与客户选择。
- 失败：只说产品更好；内部定义与用户心智冲突；同时占多个互相排斥的位置。
- 证据：目标用户无提示提及、搜索词、咨询原话和比较对象。
- 反例：深度定制 B2B、多角色采购和低卷入品类不强套单一心智阶梯。
- 边界：心智诊断不替代产品事实和商业可行性。
- 下游：影响命名、内容承诺、竞争坐标和产品选择。

## R13｜高不确定阶段先从现有手段与可承受损失开始

- 来源：创业研究中的效用逻辑与可承受损失原则；同行评议论文已核。
- 吸收节点：项目起点、市场、产品、行动。
- 对象：目标和回报都不能精确预测的新项目。
- 变量：真实能力、已有材料、现有关系、时间预算、可承受损失和可控制动作。
- 通过：不依赖虚构远期结果，也能启动一次会接触市场的试验。
- 失败：信息越少，方案写得越完整；把全年规划当成开始行动。
- 证据：过去任务、客户问题、可使用材料、现有关系入口和明确投入上限。
- 反例：成熟项目和高合规行业仍需要目标、预算、计划和专业审核。
- 边界：从现有手段开始不等于永远困在现有资源里，也不等于不用研究市场。
- 下游：决定 S0—S2 阶段先做哪条七天验证链。

## R14｜不可见能力必须变成陌生人可检查的信号

- 来源：信息不对称与信号理论；同行评议论文已核。
- 吸收节点：一人媒体、个人资产、定位、传播和信任。
- 对象：能力存在于本人、熟人或组织内部，但陌生市场无法判断。
- 变量：信号与真实能力的联系、获得成本、可模仿性、细节、第三方验证和连续性。
- 通过：作品、案例、过程或评价能够降低目标对象的判断风险。
- 失败：发过内容就等于形成证明；粉丝量自动证明专业能力。
- 证据：过程材料、贡献归因、前后变化、第三方记录和可复核结果。
- 反例：高成本信号也可能被包装，低成本公开样本也可能很有信息量。
- 边界：公开证明提高被判断的可能，不保证获得机会或交易。
- 下游：决定用户需要长期 IP、项目型账号，还是一份最小公共证明。

## R15｜用户是在具体处境中选择方案以取得进展

- 来源：待办任务理论的功能、情绪和社会任务；官方研究说明与管理著作已核。
- 吸收节点：市场、产品、用户、定位和内容。
- 对象：用户为什么在某个时刻选择、推迟或拒绝一项方案。
- 变量：触发处境、希望取得的进展、现有替代、转换阻力、焦虑与选择成本。
- 通过：能解释谁在什么时刻为什么行动，并能从真实行为或语言中取证。
- 失败：年龄、性别和职业就是需求；用户说喜欢就会购买。
- 证据：咨询、比较、替代支出、使用过程、拒绝原因和购买后的实际进展。
- 反例：同一个人可能在不同处境中承担不同任务，不能把任务写成终身身份。
- 边界：发现任务不等于用户愿意为当前方案支付，也不等于项目能交付。
- 下游：影响内容入口、承诺、产品形态、销售与交付。

## R16｜不要把任务受阻写成人格缺陷

- 来源：自我效能的任务相关判断；同行评议心理学论文已核。
- 吸收节点：个人资产、行动、学习和长期迭代。
- 对象：用户说“我没执行力、我不适合做内容、我总是坚持不了”。
- 变量：具体任务、完成经验、能力、难度、资源、反馈和风险。
- 通过：先还原最近一次行为事实，再判断是目标、路径、动作大小、能力、风险还是反馈断点。
- 失败：把没开始归因懒惰；用鼓励、自信或身份许诺替代现实任务。
- 证据：最近动作、完成记录、失败位置、反馈周期和可使用支持。
- 反例：持续功能受损、显著痛苦或安全风险不能由项目 Skill 诊断，应建议专业支持。
- 边界：完成一个小任务只提供能力证据，不证明整个商业项目成立。
- 下游：决定七天动作的大小、支持结构和停止条件。

## R17｜把意愿接到可识别情境和具体动作

- 来源：实施意图研究；同行评议心理学综述已核。
- 吸收节点：生产、发布、实验和行动。
- 对象：用户目标明确，却总在准备、推迟或忘记执行。
- 变量：触发情境、具体动作、完成证明、反馈位置和异常处理。
- 通过：能写出“当什么发生，由谁完成什么，并留下什么证据”。
- 失败：只写“坚持更新”“提高执行力”“每天努力”。
- 证据：日程、任务状态、产物、发布时间和结果写回。
- 反例：缺能力、资源、权限或真实需求时，行为提示不能解决结构问题。
- 边界：计划不是执行结果，仍需现实接触和结果回填。
- 下游：把七天方案从愿望变成可启动动作。

## R18｜案例只能迁移机制，不能复制表面结果

- 来源：现实主义评价中的情境—机制—结果关系，以及类比迁移研究；同行评议或方法学来源已核。
- 吸收节点：对标、市场、内容、产品和实验。
- 对象：用户想复制一个成功账号、商业模式或课程。
- 变量：原案例情境、起作用的机制、结果、必要条件、当前差异和可控变量。
- 通过：明确什么条件相同、什么不同，并把机制改写为最小迁移实验。
- 失败：复制标题、人设、视觉或价格，就预测相同结果。
- 证据：原案例时间线、平台、资源、用户、产品、渠道和交付材料。
- 反例：标准化机械任务可以直接复用 SOP，不需要过度解释机制。
- 边界：案例提供候选机制，不提供因果证明；当前项目必须前向验证。
- 下游：决定哪些经验进入方案，哪些只保留为假设。

## R19｜“知道很多但不行动”可能是在维持原有解释

- 来源：认知不一致与降低不适的动机；经典社会心理学专著已核。
- 吸收节点：行动、学习和长期迭代。
- 对象：用户反复学习、换方法、重建系统，却长期不接触市场。
- 变量：自我理解、公开承诺、真实行为、既有投入、相反证据和回避方式。
- 通过：区分缺知识与回避现实反馈，安排足够小但无法用学习替代的动作。
- 失败：继续补充理论；或把所有拖延都叫认知失调。
- 证据：学习投入、发布或销售行为、遇到反证后的解释变化和项目重启记录。
- 反例：资源、健康、能力、权限和安全问题也会阻碍行动，必须先排除。
- 边界：这是项目行为假设，不是心理诊断。
- 下游：决定停止新增资料，转入最小现实任务。

## R20｜公共内容可以扩展机会边界，但关注不等于关系

- 来源：弱关系的跨群体桥接研究；同行评议论文已核。
- 吸收节点：一人媒体、传播、关系和长期资产。
- 对象：非交易型表达、职业机会、合作、招聘、介绍和咨询。
- 变量：信号质量、触达的新群体、关系入口、后续互动和现实机会。
- 通过：内容让原本不认识的人获得判断材料，并有可追踪的联系或机会结果。
- 失败：粉丝天然等于弱关系；高曝光必然带来高质量合作。
- 证据：有效介绍、邀请、合作、回访、直接联系和机会来源。
- 反例：隐私高、关系封闭或高度线下信任行业，公开内容可能只承担辅助证明。
- 边界：内容扩大连接概率，不替代关系经营、专业能力和现实交付。
- 下游：支持非交易目标链，也限制“所有内容都必须立即成交”的判断。

## 规则冲突的裁决

按以下顺序裁决：

1. 用户安全、法律、隐私和授权。
2. 当前项目可核验事实。
3. 叁木完整链与最近断点。
4. 适用边界明确的原书规则。
5. 蒸馏 Skill 的解释和补充。
6. 类比、案例和经验性建议。

规则若与当前事实冲突，不硬套。
