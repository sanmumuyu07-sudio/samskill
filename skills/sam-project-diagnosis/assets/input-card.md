# 项目阶段诊断输入卡

## 这个 Skill 帮你解决什么

判断项目处于什么阶段、已经具备什么、最先解决什么，并给出能执行和验证的启动方案。

## 最少提供这些

1. 这是你的项目，还是你替别人负责。
2. 未来 30—90 天最希望先发生什么现实结果。
3. 已有能力、产品、账号、动作与最近结果。

## 有这些材料会更准确

- 账号主页与近期内容。
- 产品、价格与交付说明。
- 平台后台与线索成交数据。
- 用户咨询、拒绝和退款原因。
- 团队分工、权限与产能。

## 没有材料时会怎样处理

只给暂定阶段、关键未知和最小取证动作。

不虚构完整定位、用户画像和长期方案。

## 你会得到什么

1. 当前阶段与白话解释。
2. 已经具备的部分。
3. 一个主问题与一个替代解释。
4. 保留、修改、暂不处理。
5. 7 天动作；需要时再给 30 天验证。

## 可以直接复制

> 使用 `$sam-project-diagnosis` 诊断这个项目。我是【本人／操盘手／运营】，未来 30—90 天希望【】，已有【能力／产品／账号／结果】，最近一次动作和结果是【】。请判断阶段、主问题和下一轮验证。
